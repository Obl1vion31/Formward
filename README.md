# Formward

Formward 是一个 AI 原生的个人健康与训练助理。名称由 `Form` 与 `Forward` 组合而成，表达体型塑造、自我管理与持续向前。

项目从饮食、运动和身体指标记录开始，逐步连接训练器材、健康平台和其他个人数据来源。网页与外部 AI 助手共用同一套业务功能：用户既可以在 PC 页面中操作，也可以授权外部 AI 查询、记录、分析并提出需要用户确认的计划调整。

## 为什么做 Formward

MacroFactor 已经很好地覆盖营养记录、趋势体重、能量消耗估算、周期性目标调整和训练追踪。Formward 不以复制这些功能为目标，而聚焦三个差异：

- **AI 原生操作**：AI 通过正式 API 使用系统能力，而不是只在页面上增加一个聊天框。
- **统一个人数据生态**：饮食、训练、身体指标、健康平台和器材数据进入统一模型，并保留来源与可信度。
- **跨领域教练**：长期将营养、训练、恢复、目标和实际执行情况结合起来，生成可解释、可确认、可追溯的建议与计划。

新会话先读 [项目交接](handoff.md)，了解最新用户要求、已完成工作与接手顺序。当前实现和验证结果见 `docs/status.md`。详细定位见 `docs/product.md`，首版交付顺序见 `docs/milestones.md`，页面方案见 `docs/interface.md`，MacroFactor 的产品参考见 `docs/design-reference.md`。

## 首版范围

- 少量内部账号和独立数据归属。
- 手动饮食、运动和身体指标记录；可记录的测量字段按实际来源逐步确定。
- 每日汇总与阶段趋势。
- 现有 Excel 历史数据导入。
- 面向 AI 的查询与记录 API。
- AI 访问令牌、数据来源和基本操作记录。

个性化训练计划、营养策略、器材连接和外部健康平台同步属于后续阶段，但首版数据必须保留扩展所需的时间、单位、来源和外部标识。

## 技术方向

计划采用轻量的 Next.js 模块化单体：

- Next.js、React、TypeScript
- PostgreSQL、Neon、Drizzle ORM
- Better Auth
- Tailwind CSS、shadcn/ui
- Vitest、Playwright

首页、PostgreSQL 数据库和内部账号登录已接入。登录后的身体记录展示六项实测摘要、体重与体脂双图，以及最近 10 个日历日的晨晚记录；漏记日期只在展示层推导，完整历史每批展示 50 个日期。网页支持四项独立录入、历史编辑与逐项显式估算，晨间仅接受空腹测量，页面不自动弹窗。

每行保留“查看”，另按日期和实测状态显示“录入／补录／编辑”；桌面同排、手机上下排列。具体日期的 Inspector 顶部常驻晨晚概览，查看时展开时段详情，编辑时显示四格表单。晨晚分别填写数据来源，可自由输入或选择本账号最近使用的历史来源；成功实测才更新建议。设备与连接应用合成名称快照，BMI 已从列、业务模型、录入和展示移除，旧四列 TSV 仍兼容，原文件与既有输入／审计保留。准确测量时间保持，未知时间显示“无”。

普通保存不自动估算；实测只替代对应指标的估计，其他依据和初始化冻结范围保持。来源修正、估计重建、软删除／恢复与审计已有维护入口，网页归属纠正、删除／恢复、导入和正式 AI API 尚待接入。规则见 [身体指标记录](docs/measurements.md)，完整字段与关系见 [数据库字典](docs/database.md)，账号接入见 [接入指南](docs/auth-setup.md)。

## 查看首页

如果开发服务已经启动，在运行项目的同一台电脑上打开浏览器，访问 [http://localhost:3000](http://localhost:3000) 或 [http://127.0.0.1:3000](http://127.0.0.1:3000)。`next.config.ts` 已允许这两个本地地址加载开发资源。如果项目运行在远程工作区，在编辑器的「端口 / Ports」面板找到或转发 `3000` 端口，再打开面板给出的地址。`localhost` 指的是运行浏览器的电脑；远程工作区不能直接用自己电脑的 `localhost` 访问，除非已经做了端口转发。使用其他转发域名时，把它的主机名加入 `next.config.ts` 的 `allowedDevOrigins`，并重启开发服务，否则页面可能显示但客户端动画无法执行。

当前首页采用“数字雕塑 + 编辑式界面”：深石墨色中央人物舞台，人物背后有微弱暖金环境光和宽幅暖色层次，侧下方叠加极淡 petrol 环境色。第一屏显示左上角 Logo、居中人物，以及桌面左下角的 `SCROLL TO ENTER` 与细线滚动提示；停在第一屏时持续显示，鼠标移动或未触发播放的滚轮操作不会隐藏，倒放回第一屏后重新显示，触屏与窄屏不显示提示。人物有极弱的反向鼠标视差，停止后缓慢回中。转身后，Email、Password 和 `ENTER` 从液态尾部前方浮出；烟色衬底边缘渐隐，没有外框，肩背与腰线保持露出。首次聚焦输入框后人物回中，整个登录阶段保持固定。输入底线默认隐藏，只有可操作字段悬停或聚焦时显现；键盘保留清晰焦点框，触屏点击标签即可聚焦。ENTER 使用哑金文字及短下划线；键盘用户可通过聚焦时才显示的“进入登录”入口进入表单。

素材就绪后，封面显示三组同级、单行概念词：Discipline / NUTRITION、Drive / BUILD YOURSELF、Effortless / AI LOGGING。主词采用本地 Newsreader 正体 400、0.035em 字距与暖灰白，桌面字号为 `clamp(20px, 1.68vw, 26px)`；副标签使用本地 IBM Plex Mono 与哑金，Logo 和表单沿用系统 sans serif。桌面节点、引线与文字沿倾斜椭圆轨道随人物同步转动 150°，以轻微缩放和明暗表现纵深。节点与棕金引线位于文字上方，左侧标注向右对齐、右侧向左对齐，转动途中平滑改变对齐；文字始终朝向读者，不随人物鼠标视差移动。登录终点为 Discipline 右上、Drive 右下、Effortless 左侧；标题与轨迹减弱，微标签保持可读。手机保留 14px 主词、底部三列与细轴，登录后位置不变。认证阶段停留终点，失败保留，成功后随最终人物动画淡出；reduced motion 在 180ms 内交叠首尾静态构图。概念词表达饮食自律、自驱力与 AI 记录方向，业务记录和 AI API 仍按里程碑实现。

一次明确下滚或手指上滑后，页面自动以 2 倍速播放 v6 转身视频，完整时长为 0.5 秒；上滚或手指下滑以同样时长倒放，播放途中可立即从当前进度反向。静态首尾保留原来的 `1.png` 与 `12.png`，两端各 40ms 与经过大小及位置校准的视频交叠；视频黑底通过透明 Canvas 合成，背景与人物外层鼠标联动保持原设计。登录表单在最后 200ms 同步显现，倒放同步隐藏。三张静态图及视频就绪后才播放，加载期间的最近方向会自动执行。停在 12.png 且 Email、Password 非空后，点击 `ENTER` 先验证账号；认证过程中保持第 12 张并禁止重复提交和方向变化。验证成功后从居中姿态播放原来的 700ms 的 12.png → 13.png，实际动画结束后进入 `/dashboard`。reduced motion 使用 180ms 静态首尾淡入淡出，最终过渡为 240ms。错误密码或网络失败留在表单并显示中文提示。账号与会话通过 Better Auth / Drizzle 保存在 PostgreSQL；主页验证当前会话并提供退出登录，未登录不能直接访问。视频素材见 [视频目录](public/videos/README.md)，页面与校准见 `docs/interface.md`、`docs/frame-calibration.md`。

## 自己启动开发服务

1. 在终端进入本仓库根目录：`cd /home/obl1vion/projects/Formward`。
2. 安装 `.nvmrc` 指定的 Node.js `24.21.0`。可从 [Node.js 官方下载页](https://nodejs.org/en/download)安装；安装后打开新终端，运行 `node --version` 确认显示 `v24`。当前共享环境自带的 Node.js 18 不满足本项目要求。
3. 运行 `pnpm --version`，确认 pnpm 9 可用。如果没有 pnpm，在 Node.js 24 环境下运行 `npm install -g pnpm@9.15.9`。
4. 首次使用或依赖变化后，运行 `pnpm install`。
5. 运行 `pnpm dev`。终端显示 `Ready` 后，按上一节的地址打开首页。这个终端需要保持运行。

如果提示 `3000` 端口已被占用，通常是已有开发服务正在运行；先尝试打开首页，不要同时启动第二个实例。

## 关闭开发服务

- 如果 `pnpm dev` 正在你自己的终端里运行，切回该终端按 `Ctrl+C`。终端返回命令提示符后，服务就已停止。
- 如果服务由其他终端或工具启动，先运行 `ss -ltnp '( sport = :3000 )'`，确认显示的是本项目的 `next-server`，再运行 `kill 进程号`，把“进程号”换成上一步显示的 PID。若看到的是其他程序，不要关闭它。
- 关闭后再次访问 `http://localhost:3000`，浏览器应无法连接；下次查看重新运行 `pnpm dev`。

## 私有文件

用户上传文件不能放在 `public/`。原始 Excel 位于本地 `data/imports/`，并被版本控制忽略。`public/` 中的文件会由网站公开提供，只能保存允许任何访问者读取的图标、图片等静态资源。
