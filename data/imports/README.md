# Imports

本目录保存私有的待导入原始文件，包括历史 Excel、体脂秤导出、用户在对话中提供的饮食／运动 TSV 原文快照及用于字段核对的截图。TSV 使用 UTF-8 编码，保留原始列、数值、空白字段、备注和计划状态。除本 README 外的内容被 Git 忽略，不放入 `public/`，不作为真实数据测试样本提交。

原文件内容和名称保持不变，解析以只读方式进行。导入程序通过稳定来源标识或文件摘要、工作表、来源行等识别重试；重新导出和同日多次测量的重复规则按实际来源确定。写入前先展示预览并由用户确认账号与内容。

现有 Excel 规则见 [Excel 导入](../../docs/excel-import.md)，身体指标样本与测量语义见 [身体指标记录](../../docs/measurements.md)。

饮食初始化按原表一行一餐保存整餐估算，食物描述保留在备注。维护脚本仅创建账号预览，网页登录确认后写入；原TSV与Excel保持不变，参考资料和核对报告存私有data/exports。
