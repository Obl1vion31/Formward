# tutorials

公开的虚构账号教程、短预览、封面及浏览器播放器。没有真实用户资料、原始录屏或内部报告。影片和步骤来自隔离实录；文件名带内容版本，按需加载。

身体与补录的手机、电脑影片随当前录入交互重新实录：手机晨晚切换保留草稿、一次保存两时段；更早补录先选日期再点查看。使用390×640／1280×800原片，一行字幕、固定取景、连续必要滚动，保留既有导出节奏。另六段经核对保留；清单始终选择十段当前影片，旧带哈希资产暂留以免已打开页面的旧清单失效。脚本与原始录屏、剪辑时间点、数据库证据仅在私有制作目录，不进入public。

身体影片按紧凑录入界面重录，原片帧同步缓存使用源文件SHA校验后才能复用；公开哈希媒体先打包，再build并启动production预览，避免运行中新增路径尚未被服务器登记。片中继续使用虚构资料、一行字幕和既有播放速度。
