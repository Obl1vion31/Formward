# tutorials

使用说明页的操作视频、封面、主题文字和播放器。操作视频共八项，覆盖总览、食材库记餐、身体录入、消耗估算、拍照核对、设备同步、历史补录和外部 AI 确认。每项都有手机与电脑实录，使用虚构资料并保留正常速度。网页局部「使用指引」直接打开高光，视频在使用说明页按任务播放。

`media-manifest.js` 登记视频、封面、尺寸、时长及章节标记。`player.js` 按设备选择实际素材，提供播放、文字版、章节定位和失败重试。切换章节或设备后应核对同一主题中的真实控件和起始帧。旧带哈希资产保留供已打开的页面继续播放。

制作使用隔离测试账号。原始截图、录屏、时间标记和数据库证据存放在本机私有验收目录。公开目录只包含虚构示例和播放器资源。
