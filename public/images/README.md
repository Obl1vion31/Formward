# 页面图片

## 目的

保存允许公开访问的产品图片和脱敏演示素材。用户食物照片、体型照片和健康附件属于私有数据，不进入本目录。

## 内容与关系

人物素材共 13 张 PNG，按顺序命名为 `1.png` 至 `13.png`。首页配置位于 `src/app/frame-config.ts`：`PRE_LOGIN_FRAMES` 包含 1–12，支持手势触发的双向自动播放；`FINAL_FRAME` 是 13，仅由 Enter 触发并保持最终状态。全部 13 张图片提前加载并解码。

图片尺寸和宽高比存在差异：当前 1–4、6–9、13 为 1024×1536，第 5 帧为 793×1983，10–12 为 887×1774。每张图的桌面、移动端 scale / x / y 都在 `FRAME_CONFIG` 独立配置；1–12 的人工测量标记和离线校准方法见 `docs/frame-calibration.md`，优先稳定头顶和躯干。静态导入读取实际宽高，并在图片替换后生成随内容变化的地址。

## 维护约定

图片使用连续整数编号。替换图片时保留编号，重新测量标记并复核对应对齐值；增加中间帧时同步导入、加入 `PRE_LOGIN_FRAMES` 并配置对齐值。当前 12 帧使用显式分段节奏，其他长度采用等间隔兼容映射，需要特定节奏时同步调整时间线参数及测试。最终帧不加入滚动序列。图片或动画配置改变后同步更新页面说明。
