# 页面图片

## 目的

保存允许公开访问的产品图片和脱敏演示素材。用户食物照片、体型照片和健康附件属于私有数据，不进入本目录。

## 内容与关系

人物素材共 13 张 PNG，原图均保留。首页运行时使用 `1.png`、`12.png` 和 `13.png`：前两张是转身两端的静态停留画面，保留鼠标联动；第 13 张仅在登录认证成功后进入最终过渡。中间转身来自 `public/videos/` 的一秒源视频，页面按 2 倍速在 0.5 秒内完成转身，2–11 不再加载。

`src/app/frame-config.ts` 保存这三张图的静态导入与桌面、移动端 scale / x / y，原有对齐值不变。1、13 为 1024×1536，12 为 887×1774。静态导入读取实际尺寸并生成随内容变化的地址。静态端点与视频的校准说明见 `docs/frame-calibration.md`。

## 维护约定

替换图片时保留编号，重新测量标记并复核静态图与视频的对齐值。第 13 张保持独立，不加入转身时间线。公开素材及动画配置改变后，同步更新页面说明并检查正倒放、首尾交叠和登录成功后的过渡。
