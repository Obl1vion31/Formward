# 首页转身视频

## 目的与内容

保存允许公开访问的装饰性人物动画。`golden-turn-1s-v6.mp4` 是当前接入的原始素材：1280×1920、60fps、1 秒、无音轨；原始文件保持不变。`golden-turn-1s.mp4` 是由它生成的播放文件，960×1440，保留全部 60 帧和一秒源时长，使用逐帧关键帧与 faststart。页面按 2 倍速播放，完整转身为 500ms；素材地址携带 `v=6`，避免继续使用旧视频缓存。

## 与页面的关系

`src/app/turn-video.ts` 根据同一进度正向或反向寻帧，以 WebGL 将黑色背景转为透明画面；不使用负播放速率。原来的 `1.png`、`12.png` 负责首尾停留及鼠标联动，视频在两端各 40ms 与原图混合。登录成功后的 `12.png` → `13.png` 保持独立。

## 维护约定

通过 `bash scripts/prepare-turn-video.sh` 重新生成播放文件，需要本机安装 FFmpeg。更换原始素材时同步修改脚本的输入、视频帧数与帧率、端点校准及说明，复核正放、倒放、中途反向、透明背景、移动端和最终衔接。其他未接入的视频保留为素材，不自动切换页面引用。

本目录会公开提供文件，只能保存公开页面素材，不保存用户健康视频或私有附件。
