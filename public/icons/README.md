# 品牌图标

保存允许公开访问的 Formward 品牌资产，不放健康数据或内部报告。

- `formward-mark.svg`：用户选定的 F＋手臂标志，两个原始黑色矢量路径、透明背景、正方形画布和至少约 8% 的安全边距。它是所有图标的母稿，不以 PNG 反向描摹。
- `formward-mark.png`：母稿导出的 1024×1024 黑色透明 PNG，供外部平台使用。
- `src/app/icon.svg`、`favicon.ico`（16／32／48px）及 `apple-icon.png`（180px）由同一母稿导出，采用石墨底和暖白图形，供标签页与手机主屏使用。

网页通过共用 `BrandLogo` 的 CSS mask 将母稿显示为当前文字颜色，不另外维护一套轮廓。调整品牌时先改 SVG，再导出 PNG 和应用图标，检查透明度、边缘、小尺寸留白与深浅背景。

来源为 Recraft V4.1 Vector，图像 ID `e9481012-5304-45be-9f7b-904eabf529f3`，用户于 2026-10-30 选定。保留原始下载与导出记录在被忽略的 `.codex/brand/`；生成时免费方案界面提示图像归 Recraft 所有，本仓库不声明独占权利。不复制其他产品的品牌图标。
