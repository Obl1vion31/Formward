# Public Assets

## 目的

本目录只保存允许通过公开 URL 访问的静态资源。

## 内容

- `privacy.html`、`terms.html` 与 `legal.css`：用户已确认的个人运营者隐私政策、服务条款和独立阅读样式，生效日期为2026年11月10日；正式地址和发布核对见 [豆包资料](../docs/doubao-onboarding.md)。
- `icons/`：Formward 品牌图形、透明导出及应用图标，来源记录见目录 README。
- `fonts/`：首页英文排版使用的本地字体及完整许可证。
- `images/`：公开页面图片和不含个人数据的演示素材。
- `videos/`：公开首页转身视频与用于双向寻帧的播放文件。

## 安全边界

Next.js 会公开提供本目录内容。用户上传、Excel、健康照片、导入报告和任何私有文件必须进入受控存储或本地 `data/`，不能放在这里。


tutorials/只包含虚构账号实录的公开教程、短预览、封面和播放器。原片、测试报告与数据库备份不公开；完整视频按需加载。
