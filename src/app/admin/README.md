# 全站管理

`/admin`默认进入用户管理（账号、邀请），另有用量分析、规则设置三个主栏目；安全与操作记录为独立辅助入口。旧总览、档位、邀请链接分别进入对应新栏目。页面与Server Actions检查owner及5分钟内的管理验证；管理员动态码当前按服务器配置暂时关闭，表单仅要求密码。已启用MFA的账号保留动态码要求。

`/admin/users/[id]`默认只展示用户概况与三个跳转：`view=account`管理档位和账号访问，`view=policy`调整个人AI限制，用量跳至`/admin?tab=usage&userId=...`。账号列表的搜索、状态、页码及位置、用量分析的日期和筛选随返回保留。统计与AI策略在admin feature，原账号／邀请规则在auth feature，不读取健康正文；验证到期保留草稿。完整规则见[安全与全站管理](../../../docs/security-admin.md)。

后台 layout 持有顶栏、导航及首次读取边界。切换到其他栏目时保留已呈现的内容至目标就绪，慢读提示和失败重试均在正文内。每个入口及操作分别复核管理身份。
