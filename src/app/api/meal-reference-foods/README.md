# 公共参考食材读取

供已登录的独立食材库与餐次选择器读取公共规格、实际目录数量及来源。`view=summary` 单独请求各食物组的数量与图示。`q` 搜索名称、别名和做法，`family` 读取食物组的食用态、熟食和原料。结果每次最多 40 条，用返回的 `nextOffset` 继续请求 `offset`。`id` 单独读取一个现行公共参考，用于关联整餐和恢复草稿。返回分项的稳定版本、实际计量基准、来源和参考份量。日常鸡腿查询返回熟食。响应仅在当前页面内存使用。AI 客户端沿用 `GET /api/v1/foods` 或 MCP `search_foods` 和它们已有的候选上限。
