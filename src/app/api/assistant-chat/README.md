# 站内聊天入口

GET读取本人会话、分页消息、模型、下一次发送的上下文基础估算及共享额度。POST在有效会话、来源、资格和参数检查后持久化任务；SSE仅订阅数据库进度，不执行模型，不因连接取消而停止任务。独立worker复用assistant feature执行，恢复前台读取原任务。GET runId 只订阅本人当前对话的运行。站内浏览器用 `Formward-Chat-Stream: delta-1` 协商初末快照、正文及进度分片。该请求头与回源鉴权头独立。发送已写入时先回传本次请求和运行编号，长时间无正文时发送保活注释。发送仍接收一条消息的完整imageIds，由worker分批和汇总。continue复用原回复与服务端已绑定的照片证据，历史手动分批可沿用imageSubset。

模型Key、地址、账号和任务领取信息不能由浏览器指定。响应private/no-store，订阅持续核对会话与归属；没有正式健康确认保存入口。

GET增加view=history及严格JSON cursor读取本人20条会话，conversationId只读查看本人chat用途历史；饮食任务不混入历史。读取不激活旧会话、不调用模型、不创建收费任务。

停止请求匹配本人当前会话和具体运行编号，已结束或旧版空编号只读回状态。网页手动重新读取用 conversationId 固定当前会话，接回同一运行。
