# 登录后的主页

本目录提供 `/dashboard` 和退出按钮。页面每次请求从认证 feature 验证当前账号，未登录或会话失效时返回登录入口。退出调用正式认证接口，撤销会话后完整导航回登录页，清空上一账号的客户端缓存。

页面按已验证 user_id 查询本账号记录，将可序列化的指标、时间精度、真实性、录入入口、设备和预测区间传给 measurements feature。有数据时先显示仅实测的最新空腹与 7 日摘要，再显示正常纵轴的晨晚折线、7D／30D／90D／全部／自定义和最近 10 个日期；晚间和估计默认显示，估计点与线段明确标记。日期详情按需出现，完整历史、来源、占位时间和模型详情进入抽屉。无记录时显示简短空状态。业务和界面规则位于 feature，页面不直接写 SQL、计算差值或生成补全数据。

后续报表将区分 D 日晨晚差对照 D 日盈余、D+1 日空腹变化对照 D 日盈余；饮食、训练计划和全天消耗尚未接入。当前界面只呈现已实现的身体记录，具体方向见 [页面方案](../../../docs/interface.md)。
