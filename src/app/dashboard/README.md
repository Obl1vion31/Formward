# 登录后工作区

持久layout按账号挂载确认、主题同步、小助手、ChartTransitionProvider、DashboardHeader与WorkspaceFrame；固定标题、五项导航、主题及快捷记录不等待健康查询。页面与Server Actions各自校验身份，业务读取和写入委托features。

RecordGuidanceProvider按账号挂载首次录入高光和助手重播，沿真实入口、填写、保存说明定位；只观察已有页面和面板，不改查询或业务动作。页面离开清理引导，原生弹层、保存和草稿保护优先。

主导航顺序为总览、饮食、训练、消耗、身体。手机五项共用漂浮暖雾导航，右侧是独立助手；电脑左侧同步五项。选中态、普通导航方向及页面标题按真实路由计算，不再将消耗归为训练，也不重复显示训练／消耗标题切换。

头像菜单包含系统外观开关、外部接入、账号管理，owner另有管理与测试。分组在同一容器内进入下一层，Escape先返回分组；实际动作再关闭菜单。设备来源与AI接入归外部接入；个人资料、安全和退出归账号管理，管理员维护入口称用户管理。手机来源、资料和安全沿用底部面板，独立URL仍可直达；权限规则不因菜单改变。

三类卡片携带实际日期、区间及指标进入趋势。关联趋势页不再另放返回按钮；主导航、Logo和浏览器后退共用图形返回与滚动／焦点恢复。总览骨架和真实卡片均有图形接管槽位，返回测量当前槽位，不依赖旧坐标或等待全部健康查询。无匹配来源正常导航，保存、区间与指标变化使旧配对失效。

各主页面使用自己的loading.tsx与目标结构，不叠套总览骨架；总览的独立loading边界可预取，身份和健康查询在该边界内，页面不再另设重复fallback；已知固定文字、图例及操作槽首帧显示，仅未知数据等待，失败原位重试。WorkspaceFrame只为普通模块切换播放一次短位移，图形转场、日期详情及录入不叠加。

饮食、消耗、身体沿用查看／编辑分离。普通日期默认查看，intent=edit打开编辑，entry兼容快捷录入；同地址再次打开仍生效。表单、保存、草稿、版本、幂等与完整历史继续复用原feature。三类记录成功后刷新真实事实及助手摘要，不缓存旧健康读数来伪装已保存。

助手说明与提醒规则见features/assistant/README.md；设备试运行保持固定账号服务端校验，其他账号只显示未开放。公开AI确认入口继续保留目标，国服未登录时正常登录后返回原审核；原OAuth与海外后台保持。

AI接入手机页由顶栏提供唯一24px／600字重页面标题，正文只保留说明及两条AI行；其他页面标题规则保持各自语义。
