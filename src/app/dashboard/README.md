# 登录后的主页

本目录提供 `/dashboard`、录入 Server Actions 和退出按钮。页面每次请求从认证 feature 验证当前账号，未登录或会话失效时返回登录入口。退出调用正式认证接口，撤销会话后完整导航回登录页，清空上一账号的客户端缓存。

页面按已验证 user_id 顺序查询本账号记录与日期状态，兼容本地 PGlite 的单连接多路复用，并传入账号创建时间。measurements feature 同时呈现六项实测摘要、独立纵轴的体重与体脂双图及五列最近记录，共用日期、晚间、估计和集中规则入口。日历空行从账号、记录或已保存日期的最早日补到今天，最近展示 10 日、完整历史每批 50 日，可补记，不批量写库。统一 Inspector 承担录入、详情、编辑与历史，滑入／退出结束后恢复滚动和焦点。无记录账号仍可从四格表单开始录入，业务计算留在 feature。

`actions.ts` 对保存和逐项估算分别验证当前会话，账号来自服务端身份；调用 measurements feature 后返回本账号最新记录／日期，并刷新 `/dashboard`。页面正文居中，所有日期行统一用“编辑”进入表单，没有独立今日入口、自动弹窗、新增日期或停止提醒 Server Action；已有日期状态与提醒继续保留，空行由展示层推导。晨间仅接受空腹写入，旧非空腹／未知记录只读。表单错误保留输入，不向浏览器暴露数据库报错。页面传入操作函数，feature 界面不依赖 app 路径。未知值保持空白，网页与后续 AI API 共用 feature 规则。
