# 登录后工作区

持久layout按账号挂载确认、主题同步、小助手、WorkspaceCacheProvider、ChartTransitionProvider、DashboardHeader与WorkspaceFrame；固定标题、五项导航、主题及快捷记录不等待健康查询。页面与Server Actions各自校验身份，业务读取和写入委托features。

主导航顺序为总览、饮食、训练、消耗、身体。手机五项共用漂浮暖雾导航，右侧进入独立助手页。已登录工作区直接显示助手并同步浏览器历史，保留已挂载的来源业务页，返回时同一个底栏随来源正文同帧露出，路由恢复后接回入口焦点。底栏和助手输入区在同一个常驻视口内定位，底部安全区由 CSS 提供，正文留位沿用同值。直接访问助手地址继续校验登录。电脑左侧同步五项，右下使用助手浮窗。选中态、普通导航方向及页面标题按真实路由计算。关联趋势的选中态和标题随新正文露出更新。

头像菜单一级包含系统外观开关、外部接入、账号管理及“更多信息”，owner另有管理与测试。更多信息先完成菜单退出，再打开共用只读面板；关闭恢复账号按钮焦点和原草稿。分组在同一容器内进入下一层，Escape先返回分组；实际动作再关闭菜单。设备来源与AI接入归外部接入；个人资料、安全和退出归账号管理，管理员维护入口称管理后台。手机来源、资料和安全沿用底部面板，独立URL仍可直达；权限规则不因菜单改变。

三类卡片携带实际日期、区间及指标进入趋势。关联趋势页不再另放返回按钮；主导航、Logo和浏览器后退共用图形返回与滚动／焦点恢复。总览等待布局和真实卡片共用定位槽位。返回按当前槽位恢复滚动和卡片焦点。无匹配来源正常导航，保存、区间与指标变化使旧配对失效。

各主页面使用自己的loading.tsx与目标结构，同条件本人真实视图可只读保留并后台更新，首次未知区域局部等待，不叠套通用骨架；总览的独立loading边界可预取，身份和健康查询在该边界内，页面不再另设重复fallback；已知固定文字、图例及操作槽首帧显示，仅未知数据等待，失败原位重试。WorkspaceFrame为普通模块切换或总览关联趋势播放一次正文过渡。日期详情和录入使用各自容器，真实数据接管时沿用当前布局。

饮食、消耗、身体沿用查看／编辑分离。普通日期默认查看，intent=edit打开编辑，entry兼容快捷录入；同地址再次打开仍生效。表单、保存、草稿、版本、幂等与完整历史继续复用原feature。三类记录成功后刷新真实事实及助手摘要，不缓存旧健康读数来伪装已保存。

助手说明与提醒规则见features/assistant/README.md；设备试运行保持固定账号服务端校验，其他账号只显示未开放。公开AI确认入口继续保留目标，国服未登录时正常登录后返回原审核；原OAuth与海外后台保持。

手机顶栏统一正常52px高度、20px／600页名及对称操作占位。工作区以屏幕中线对齐顶栏、内容和底栏，根层为占宽滚动条对称留位；覆盖式滚动条直接覆盖内容。AI接入正文不重复页面标题。200%文字允许增高。
