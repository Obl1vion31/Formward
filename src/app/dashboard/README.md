# 登录后的主页

本目录提供 `/dashboard`、录入 Server Actions 和退出按钮。页面每次请求从认证 feature 验证当前账号，未登录或会话失效时返回登录入口。退出调用正式认证接口，撤销会话后完整导航回登录页，清空上一账号的客户端缓存。

页面按已验证 user_id 顺序查询本账号记录与日期状态，兼容本地 PGlite 的单连接多路复用；将可序列化的指标、时间精度、真实性、录入入口、设备和估计依据传给 measurements feature。有数据时先显示仅实测的最新空腹与 7 日摘要，再显示正常纵轴的晨晚折线、7D／30D／90D／全部／自定义和等宽四列的最近 10 个日期；晚间和估计默认显示，估计点与线段明确标记。日期详情按需出现，完整历史、来源和占位时间进入抽屉。估计值直接打开对应指标的数值、依据与真实样本日数，技术元数据保留在内部审计；历史初始化与日常估计统一在“估算规则”说明。无记录时显示今日空行、空趋势和四项录入入口。业务和界面规则位于 feature，页面不直接写 SQL、计算差值或生成补全数据。

`actions.ts` 对保存、逐项估算、新增空白日期和停止当天提醒分别验证当前会话，账号来自服务端身份；调用 measurements feature 后返回本账号最新记录／日期，并刷新 `/dashboard`。表单错误保留输入，不向浏览器暴露数据库报错。页面传入操作函数，feature 界面不依赖 app 路径。无记录账号仍可通过今日四格表单开始记录，未知值保持空白。后续报表将区分 D 日晨晚差对照 D 日盈余、D+1 日空腹变化对照 D 日盈余；饮食、训练计划和全天消耗尚未接入。当前界面只呈现已实现的身体记录，具体方向见 [页面方案](../../../docs/interface.md)。
