# 登录后工作区

layout持续挂载身份对应的确认、小助手、主题同步及DashboardHeader，业务页面只挂载实际内容。导航与账号菜单不再放在各页Suspense内。手机四个目的地使用漂浮玻璃导航和可中断指示器，助手位于页头；桌面使用左侧导航与右下助手。账号菜单“设置”统一提供外观及既有账号／数据入口，跟随系统仅在显式选择时生效，保留已存深浅偏好。

工作区异步任务显示非模态状态，表单继续管理自己的pending、防重复提交、失败保留及确认；助手显式避让工作区pending与既有弹层。此批仍复用完整饮食、消耗、身体及AI功能。手机总览提供同色完整记录动作、B横向真实数据卡与关联图。摄入／晨重通过ChartTransitionProvider在真实目标就绪后等比交接；各专页顶部可直接记录，原表单及历史保持。visual-review仅在显式本地开关下展示相同虚构数据的材质对照，不提供产品设置。

`account/` 提供本人账号设置：邮箱只读、修改密码、登录设备和 AI 入口。右上角账号菜单增加账号设置，owner 另可进入站内 `/admin`；角色来自服务端验证身份。所有网页写入由会话上下文覆盖，feature 在账号行锁内再次验证，撤销后旧请求不能继续保存。

/dashboard为统一总览；measurements、meals、energy、ai、export分别管理身体、饮食、消耗、AI连接与Excel导出。Logo返回总览，电脑84px暖雾左栏、64px页头、正文左右112px对称留白；手机64px页头、漂浮四栏及独立助手。右下角助手电脑展开400px非模态窗口，手机沿页头按钮锚定展开的模态面板，无底部把手，稳定高度不超过640px和可视区减88px，AI／导出页也提供入口；审核、授权、首次使用与教程不提供。header仅管理入口与账号菜单，独立助手由features/assistant提供，layout按账号挂载并重置。常用功能迁入助手，旧禁用占位退出。layout、页面与Server Action分别校验会话。

page.tsx 顺序读取当前账号饮食、身体与消耗快照，委托 dashboard feature 汇总；单连接 PGlite 不并发查询。身体 actions.ts 复用 measurements，饮食 actions 调用 meals，消耗actions调用activities；保存和确认刷新对应详情及总览。工作区异步状态共用非模态反馈，表单管理自己的忙碌和失败状态；登录等工作区外流程保留原反馈。

独立身体入口保留六项实测摘要、双折线图、最近记录及 Inspector；首屏实际宽度和默认区间就绪后显示图表。详细规则见各 feature README，页面不实现 SQL、营养计算或估算规则。

四主页面的loading.tsx与内部Suspense复用对应业务骨架，error.tsx保留导航并提供重试／返回。手机账号菜单中的设置、资料及安全使用底部面板；独立URL仍可直达。电脑左侧为整块暖雾玻璃导航及纵向选中胶囊，不挤压正文。

四主页面共用持久WorkspaceFrame，固定入口不依赖健康快照；loading.tsx是唯一页面骨架边界，不再嵌套相同Suspense。页面和Actions身份校验继续有效，非主页面沿用独立外壳。

手机趋势返回并入顶栏左侧，身体标题与其他模块一致，主卡标题旁打开身体设置；移除独占返回栏。账号菜单、助手与后续记录按退出完成顺序交接，固定导航层级高于共享图形过渡层。
