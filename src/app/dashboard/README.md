# 登录后的主页

本目录提供 `/dashboard`、录入 Server Actions 和退出按钮。页面每次请求从认证 feature 验证当前账号，未登录或会话失效时返回登录入口。退出调用正式认证接口，撤销会话后完整导航回登录页，清空上一账号的客户端缓存。

`layout.tsx` 在开始页面流之前校验身份，首次未登录保留正常重定向。每个页面继续使用 auth/server 的 currentPageUser 逐请求验证，不只依赖被复用的布局；同次 Server Component 渲染复用身份查询，不跨请求缓存。身体记录与 AI 设置页在身份校验后通过 Suspense 显示数据后备；审核页先核对 operation 归属，保留不存在或跨账号的 404。站内链接使用共享 LoadingLink，路由后备、退出、保存与估算接入根布局的统一加载层：按钮立即反馈，等待超过 200ms 显示背景虚化和居中动作提示，完成或失败后恢复。

页面按已验证 user_id 顺序查询本账号记录与日期状态，兼容本地 PGlite 的单连接多路复用，并传入账号创建时间。measurements feature 同时呈现六项实测摘要、独立纵轴的体重与体脂双图及五列最近记录，共用日期、晚间、估计和集中规则入口。日历空行从账号、记录或已保存日期的最早日补到今天，最近展示 10 日、完整历史每批 50 日，可补记，不批量写库。统一 Inspector 承担录入、详情、编辑与历史，滑入／退出结束后恢复滚动和焦点。无记录账号仍可从四格表单开始录入，业务计算留在 feature。

`actions.ts` 对保存和逐项估算分别验证当前会话，账号来自服务端身份；调用 measurements feature 后返回本账号最新记录／日期／来源历史，并刷新 `/dashboard`。页面正文居中，日期行按实测状态显示录入／补录／编辑，没有独立今日入口、自动弹窗、新增日期或停止提醒 Server Action；已有日期状态与提醒继续保留，空行由展示层推导。晨间仅接受空腹写入，旧非空腹／未知记录只读。表单错误保留输入，不向浏览器暴露数据库报错。页面传入操作函数，feature 界面不依赖 app 路径。未知值保持空白，网页与 AI API 共用 feature 规则。

页面和操作返回值均从 `sources.ts` 查询本账号最近使用的历史来源。晨间、晚间各自填写数据来源，只回显已保存来源，未知来源保持空白；点击后提供按最近使用排序的历史建议，支持自由输入及本账号历史建议的鼠标、触控和方向键／Enter／Escape。来源随实测成功事务保存，草稿与失败不更新历史；来源必填不约束估算。已有实测允许只改来源或时区，晨晚各有 GMT 时区选择与采用系统时区按钮。新记录默认当前设备偏移，已有记录回显原值；修改时携带开始编辑时的记录版本，只改时区无需重输数值。保留原录入入口、当地测量时间与原始输入，准确时间重新计算 UTC，未知钟点继续为空，并保存修改审计。设备与连接应用合成 `device_label` 名称快照，修改某条记录不影响其他记录。 有具体日期的查看与编辑 Inspector 顶部常驻晨间、晚间概览，每时段分别显示体重、体脂和逐指标实测／估计标识。查看时下方为晨间／晚间详情折叠区；图表或数值入口展开所点时段、记录与指标。实测与估计共存可分别查看，多候选必须明确选择代表，查看候选不改变代表。编辑时概览下方直接显示四格表单。空日期查看打开空概览，完整历史先显示日期索引，进入日期后复用此结构；返回恢复展开、滚动与焦点。记录信息集中显示来源、时区、设备与测量时间，未知时区显示“未指定”，其他未知显示“无”，不把保存时间或占位钟点当准确测量时间。

页面采用最新服务端快照，保存结果提供即时反馈；新服务端快照抵达后接管，避免长期保留首次加载的数据。干净表单随新快照更新；未保存草稿保持原编辑版本，成功保存才更新基线，并发冲突保留草稿。

`header.tsx` 在邮箱右侧提供“AI 接入”。`ai/` 为受保护令牌设置与确认页面，Server Actions 验证会话后调用 feature，不接受客户端指定账号。令牌原文只在创建结果展示，确认前后值和估计依据由已保存预览读取。
