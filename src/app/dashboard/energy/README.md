# 消耗记录页面

page.tsx验证登录并读取本账号消耗、运动与来源建议，调用activities/presentation生成服务端展示读数。浏览器只保留输入、模式选择和绘图。actions.ts调用共享预览／确认事务，支持同日记录与多项运动一起保存，返回重新计算的展示数据并刷新总览。

录入为分开记录／只记总数，运动明细可保留；有总数／活动合计时逐项明确已包含或额外增加，纯运动累计直接相加，未知不补0。静息与活动来源分开，来源编号不在网页编辑。公式计算／资料与日常默认值已停用，消耗页面和查询不再读取身体记录；旧资料与审计保留，未录日期不自动产生消耗。保留历史、软删除恢复、版本与审计，AI正式写入继续通过统一网页审核。

消耗来源使用独立于身体的账号建议池，静息、活动合计、总数与运动共用。输入仅回显已保存值，点击展开全部历史，输入筛选，支持键盘和触屏；“×”只软移除建议，保留草稿和历史快照。正式保存成功才更新建议，普通编辑保留旧来源不会恢复已移除项；新记录或明确更换来源并保存后恢复。统一AI审核共用相同输入与事务，来源仍可留空。
