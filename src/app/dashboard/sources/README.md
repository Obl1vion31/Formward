# 设备与数据来源入口

提供经会话认证的来源设置页和私有 Server Actions。绑定、设置、同步、采用及冲突处理统一由 data-sources 校验开放模式与当前账号；personal 模式下每个已登录账号可填写本人密钥，pilot 模式仍只指定账号。读取不返回已存密钥、密文或来源 JSON；业务与凭据管理不在路由内实现。独立loading与手机首次打开共用正式连接布局，仅状态值局部占位；默认页无七日对照或来源选择表单。首次显示“输入个人密钥”，已有连接显示“更换个人密钥”，填写区位于状态下方且按需展开，站点选择与密钥同行，中国站／国际站密钥分别使用；已有连接回显站点但不回显密钥。私有Actions保存并立即读取，返回settingsSaved区分配置成功和上游失败；历史入口接收起始日，其余身份、租约及版本控制由feature处理。
