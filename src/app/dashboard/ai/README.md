# ai

AI 接入设置与会话验证的 Server Actions；提供令牌管理、加载审核、逐行／批量更新预览与确认／取消。令牌逻辑在 auth，身体操作、版本和事务规则在 measurements；API 不提供审核写入入口。

站内导航、令牌与审核请求共用全站加载提示。按钮立即禁用并变字，超过 200ms 后虚化背景并显示动作文字，实际完成或失败后恢复；复制和本地编辑不显示遮罩。

维护时同步接口文档与隔离测试，新业务规则留在 feature。

设置页还展示 MCP 地址、OAuth 客户端连接及即时撤销。Server Action 验证当前会话，再调用 auth 的连接撤销；预览绑定发起连接，刷新令牌不改变归属，撤销后旧预览失效。列表查询顺序执行，兼容本地 PGlite socket。
