# 消耗记录

沿用activities模块，集中每日消耗、运动明细、原始来源和确认审计；网页、HTTP、MCP与Excel复用同一规则。

- model.ts：输入schema、明确模式、energyBaseline包含关系绑定及energyDays最终读数。只记总数与分开记录互斥，运动明细始终可记录；存在总数／活动合计时，included不加、additional额外增加，不按大小猜测。
- records.ts：归属、凭据、版本、幂等、整批预览、包含关系校验、正式事务及来源审计。旧无关系明细沿用原结果；未知不补0。
- presentation.ts：服务端读数；公式／默认值不参与正常功能，旧资料及审计保留。
- energy-editor.tsx／energy-view.tsx：日记录与运动一次事务保存、关系逐项／全部选择、保存日期、草稿保护、补录及历史趋势。AI日编辑只更新日草稿，运动在独立审核项确认。
- ai-api.ts／ai-openapi.ts：共用查询和公开协议，不新增权限；AI仅新增修改，正式保存须网页登录确认。
- history.ts：构造明确账号、固定范围的私有一次性补缺动作，不是长期默认。真实数值不进入客户端或公共migration。
- sources.ts：独立消耗来源建议池，成功保存才记忆，软移除保留历史与草稿。
- energy.test.ts／inclusion.test.ts／migration.test.ts：原口径、未知／0、包含关系、两种顺序、旧事实、归属、幂等、撤销和回滚。

页面先显示最近有效日读数与趋势，再列最近10个日历日及更早记录；空日不入库，不自动产生静息或活动。来源可留空。日常默认值、静息公式／资料的新动作与恢复均停用，旧申请只能取消。完整规则见[消耗文档](../../../docs/energy.md)。
