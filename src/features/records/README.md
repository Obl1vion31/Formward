# 统一记录审核

负责身体、摄入与食材库的混合提交、草稿核对和统一确认。`model.ts` 定义混合输入与审核视图；`operations.ts` 关联既有身体／饮食操作并在单个事务内确认；`record-review.tsx` 提供桌面和手机共用的紧凑审核页。

原始请求不可变，人工修改与取消仅影响草稿。三类内容可以独立选择；只保存摄入时由服务端保留食材快照，不强制入库。归属、授权、版本、照片核对和审计继续复用原 feature。旧链接只读展示，首次审核写操作幂等建立统一批次。测试使用虚构数据和隔离数据库。

审核信息的提交／到期时间首屏统一使用UTC，客户端完成初始渲染后采用设备时区，避免云端与手机时区不同导致水合错误；机器时间保留在time.dateTime。
