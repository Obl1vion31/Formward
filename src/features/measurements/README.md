# 身体指标

录入与首次等待复用MeasurementEntry及MeasurementEntryHeader，已知日期、时段、数值／来源字段和保存槽首帧显示，等待读取时禁用未知值；手机面板随内容增高。删除单项放入所属时段“更多设置”，保留原归属、版本和永久删除确认，避免真实数据接管时删除按钮挤压数值输入。

身体只接收体重与体脂率实测。晨间明确空腹，晚间非空腹；缺测保持 null，不生成、插补或恢复估计。旧估计仅作私有审计归档，不进入网页、API、图表、统计或导出。

## 记录与来源

records.ts 提供账号锁定、校验、事务导入、时间归属、请求防重和审计。days.ts 在同日同一时段采用最后保存实测；旧候选保留历史。entry-state.ts 只区分待选择、实测和缺测。

editing.ts 提供当天部分写入、带版本的历史编辑及网页单项删除。省略字段保留，显式 null 清空；至少一个主要指标有值。删除最后一个指标归档记录，不复活旧候选。手工、AI、导入和维护复用同一校验，失败回滚并保留草稿。maintenance.ts 仅维护实测，不允许恢复已退役估计。

来源可填写真实设备／应用或明确留空。网页新录入只有目标槽之前连续三次同源实测时沿用；AI须获得用户提供或明确留空确认。来源建议只在成功保存后更新，可移除建议而保留历史快照。

time.ts、timezone.ts 保留原始当地钟点、记录日、时段、准确时间及偏移；未知准确时间不虚构，时区支持固定偏移和已有 IANA 名称。已有记录仅修改来源或时区仍保留测量事实与原始输入。

## 展示与录入

桌面三卡与手机完整趋势沿用现有暖雾布局；手机默认使用当天实测摘要和记录动作。首页晨重卡与身体页共用七日真实小图和双向图形转场。缺测断线，不跨缺日连接，不插值生成健康值。7D／30D／90D按共同日期先移动实测点，再显示更早日期。缩短按反向顺序，快速切换从当前画面接续。

summary.ts 按所选日统计有效晨间实测：相邻两日都有实测才计算日差；七日窗口包含所选日和前六日，均值排除缺测，变化注明实际首末日期。体重固定开启，账号体脂偏好同步且隐藏时保留旧值；骨骼肌量／率仍未开放。

最近记录和历史日期行在电脑同排显示日期、晨晚读数与操作，窄屏分两行。有记录的行在「编辑」旁提供 ⓘ。鼠标悬停或触屏点按后，在图标旁的小浮层按晨晚显示来源、时区及已有测量细节。长名称在浮层内换行。今天空白可录入，过去空白可补录。图表、日期查找和日期链接仍可打开只读记录面板。编辑打开 MeasurementEntry，关闭后恢复记录行、历史展开状态、滚动与焦点。历史每批显示 50 个日历日。

身体表单的数字框使用轻底与细底线。体重与体脂率并排时，来源放在下一行。只显示体重时，来源根据整组宽度同排或换行。来源可手动输入、选用历史建议或清空。新增使用「保存录入」，已有记录使用「保存修改」，保存中禁用提交，失败提示靠近按钮并保留输入。

手机录入标题与日期居中，随内容增高，晨晚紧凑快切。仅有一个已记录时段时编辑默认进入该段，电脑并排填写。时区在更多设置里，短屏和键盘下字段滚动、保存可达。有效提交时立即启动约200ms的中心按压反馈，和真实请求同时进行，失败保留草稿。身体移动端开合使用均匀半透明遮罩，桌面右侧抽屉的遮罩随面板位置加深。

body-trend-plot.tsx 为晨间、晨晚和体脂提供同一绘图区、日期轴与底部读数；开关只改变实际系列及纵轴范围，外框和日期位置保持。日期轴统一 MM.DD、最多4个含首尾的等距刻度；完整日期 YYYY.MM.DD，跨年范围带年份。桌面读数槽常驻，手机沿用顶部读数。首页关联仅配对相同晨重、区间和模型，切换晚间或指标使旧配对失效。

仅剩晚间数据图表开关，直接展示；不保留估计开关、规则、依据、标记或空占位。静态标题、图例和操作槽从首帧显示，未知数值局部等待，加载位置及往返动效遵从[设计规范](../../../docs/design-reference.md)。

## AI 与归档

ai-operations.ts 只接收 save_day、batch 和 save_record，保留归属、版本、幂等、15分钟预览及网页登录确认。retirement.ts 拦截旧 estimate_cell；包含该操作的旧混合任务整体返回410 feature_removed，原请求和草稿保留，不执行其余项。旧实测预览移除已退役的计算说明和替换快照。

0035 migration 仅将明确 record_kind=estimated 的有效行归档，保留 measurement_events 外键、原始导入和审计。数据库禁止估计作为有效正式记录；保留的历史 JSON 不引用可执行估算类型。算法、补全／初始化／重建脚本已删除。

测试使用虚构数据，覆盖真实录入与编辑、来源、时区、缺测、统计、删除、账号隔离、旧任务退役、归档迁移及审计不变。图形和交互以实际网页验收为准。

queryAiMeasurementPage提供MCP可选summary／details，只读取所选日期及七日统计必要的前六天；sevenDay明确锚定page.to，不冒充整段均值或当前最新。旧queryAiMeasurements保留完整结构与最新七日summary，新增scope说明；choices只兼容校验，不要求模型选择候选。缺测、来源、实测与updatedAt版本保持。

AI查询的字段解释由ai-field-definitions.json维护，随MCP与HTTP成功结果的fieldDefinitions返回。新七日摘要的window为锚点及前6个日历日，start/end仍为各指标有效样本日期；change为窗口内首尾有效晨间空腹实测差，previousChange只比较相邻日，均值按有效天数计算。体脂差用百分点，旧当前摘要的scope保持。新增说明不改变既有计算或记录。

手机默认明确日期、实测录入／编辑、晨晚实测摘要与最近记录；无记录不以最近体重冒充今天，候选仍标待选择。身体设置贴近当天摘要；完整图表由view=trend进入，桌面完整分析及真实实测规则保持。手机录入头部以标题、日期与关闭为一行，加载、重试与编辑使用同一结构。

录入数据慢读超过8秒或失败时，保留相同字段外壳，在原保存操作槽提供重新读取；不在表单之后追加整行重试。等待期间禁止保存，重试只读取，原面板定位与键盘处理保持。

普通页面的记录列表只显示今天，缺测如实显示；其他日期从查看全部原位展开，图表选日不替换列表。原实测、晨晚、来源和维护规则保持。
