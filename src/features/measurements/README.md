# Measurements

本目录负责身体指标的校验、时间归属、导入、手动录入与编辑、账号隔离、显式缺测估计及回看。体重与体脂率已实现；网页删除／恢复、归属纠正和导入尚待接入，方案见 [身体指标记录](../../../docs/measurements.md)。

`assignment.ts` 按当地钟点将 06:00 前归前一天晚间、06:00–17:59 归当天白天、18:00 后归当天晚间；`time.ts` 解析 IANA 时区及夏令时偏移。精确测量时间与唯一记录日期 record_date 分别保存，实际发生日期从来源时间读取。日期／时段来源使用 `day_period`；用户授权占位时间使用 `assumed`，两者 UTC 时刻均为空，不改变实测数值的真实性。晚间统一非空腹，白天空腹须明确确认。

`records.ts` 提供校验、事务导入、日期时段实测写入、事件和账号查询。`recordKind` 区分实测与估计，`entryChannel` 独立区分 API、人为和开发后台；设备与连接应用不冒充数据同步系统。日期时段实测允许仅体重或仅体脂，至少一个主要指标有值。全部写入锁定归属账号，新增或恢复实测只替代对应指标的估计并保存审计，不自动估计剩余空项；导入去重仍按真实来源时间，日期时段实测重复跳过、不复活删除记录；一致的已有值可增补原来为空的指标，准确时间可确认原占位时间，保留原始输入并审计。

`editing.ts` 提供网页与 AI API 共用的当天部分写入、带版本的历史编辑和逐项显式估算。晨间写入必须为空腹；旧非空腹或条件未知记录只读，不能通过表单改值或改为空腹，晚间仍可独立录入。请求标识与内容摘要绑定，重复和并发请求幂等；修改校验记录归属、日期时段及 updatedAt，遗漏字段保留、显式 null 才清空，已知来源与准确时间保持。`measurement_days` 保留已保存日期及既有停止提醒状态；内部日期／提醒兼容函数不通过网页 Server Action 暴露，不伪造测量。`entry-state.ts` 是浏览器可用的四格状态与缺项判断，估计视为已填，多候选视为待选择。

`measurement-entry.tsx` 在 Inspector 中提供晨间／晚间四格表单，`source-input.tsx` 提供来源组合输入。四项可独立保存，包括仅体脂；晨间固定空腹，旧非空腹／未知条件只读，晚间固定非空腹。每个空项旁独立估算，草稿不参与计算；先保存实测，再估算剩余项。表单末尾仅“保存录入”，下划线距文字 4px，错误与操作结果在按钮之前。页面没有自动弹窗、新增日期或跳过入口；日历空行只在展示层推导，已有日期与提醒状态保留。历史修改携带 updatedAt 防止覆盖并发写入，遗漏字段保留、显式 null 清空，每条实测至少一个主要指标非空。冻结历史允许实测补录，禁止新增或重算估计。晨间、晚间各自填写数据来源，只回显已保存来源，未知来源保持空白；点击后提供按最近使用排序的历史建议，支持自由输入及本账号历史建议的鼠标、触控和方向键／Enter／Escape。来源随实测成功事务保存，草稿与失败不更新历史；来源必填不约束估算。已有实测允许只改来源，保留原录入入口、准确测量时间与原始输入，并保存修改审计。设备与连接应用合成 `device_label` 名称快照，修改某条记录不影响其他记录。

`estimation.ts` 提供两个明确分开的公开入口。正常模式 `morning-baseline-v3` 仅用目标日前 28 天真实数据：典型晨晚差至少 3 个配对日取中位数；晨间按实际日历日期最小二乘拟合，取最近最多 7 日、至少 3 日，距最新晨间不超过 7 天。有当天实测先加／减差值，双缺测先拟合晨间；只有晚间但配对不足时，可降级为同门槛晨间趋势。体重与体脂独立，估计、未来、条件不明及未解决候选不入正常模型。

历史初始化 `historical-initialization-v1` 仅供已明确授权的一次性任务：使用指定范围执行前的真实快照，全范围至少 3 个配对日取中位数；当天实测优先，否则用相邻晨间线性插值，两端距目标及总间隔不超过 28 天。边界在目标前后 28 天内选最近 3 个真实晨间做回归，最近实测距目标不超过 7 天才外推；同距离按日期升序。再由晨间加差值补晚间，依据不足或越界留空，不回灌估计。

`initialization.ts` 提供账号快照预览、独立事务批次、幂等执行、数据库持久报告及冻结范围检查。每个账号只能初始化一次；重复请求返回原报告，换操作标识也不能重做。批次保存真实来源快照与摘要、逐指标状态／计算依据／缺项原因及被替换旧估计。元数据区分模式、版本、实际是否用了后续日期、生成时间与批次。旧版本只读兼容，不计算预测区间。

`estimate-records.ts` 在账号锁定事务中存储估计与审计。普通写入、编辑、导入和恢复都不自动生成估计；补录仅移除实测覆盖的对应时段／指标，其他指标、另一时段和其他日期保持。部分替代保留剩余估计和依据；全部替代软删除旧快照。逐项估算只保存点击的指标，合并时不重算已有估计。冻结范围的空缺也禁止新增估计，仍可补录实测。批次刷新仅供明确的维护补全任务。

`completion.ts` 绑定账号快照、修正来源并补空缺，普通补全保留已有估计且跳过冻结日期；`trainingRange` 只约束来源维护范围。`rebuild.ts` 提供正常规则的显式重建，禁止与冻结范围重叠。恢复旧估计同样禁止覆盖冻结历史，实测恢复只替代对应指标。

`calendar.ts` 提供日历运算、账号／最早记录／已保存日期的起始边界和按批日期生成；`days.ts` 统一配对与候选选择，晨晚差只取真实同日、条件明确的配对，最近记录只构造最新 10 个日历日。`trend.ts` 使用日历区间、稀疏刻度、正常纵轴与晨晚连线；最小跨度 3 kg／3 个百分点，实测实线、估计虚线、未补全缺口淡色点线，未解决候选处断开。`summary.ts` 只统计实测空腹，计算最新值、7 日首末差、均值及覆盖天数。

`measurements-view.tsx` 与 CSS Module 使用最大 1120px 的居中正文，同时呈现当前体重、当前体脂及各自的 7 日变化、均值。当前值等宽、同级大字号；手机为两列摘要。体重图在上、体脂图在下，独立纵轴，共用 7D／30D／90D／全部／自定义、晚间、估计和集中规则入口；默认 30D，晨晚及估计都显示。最近记录展示最新 10 个日历日，日期／晨间／晚间／差值／操作五列，晨晚各两行同级读数，● 实测／◇ 估计逐项标记，点击进入正确记录和指标。差值仅计算真实配对，分别用 kg 与百分点。所有日期统一 88px 行高与列边界，桌面查看与状态按钮同排，手机上下排列，直接进入四格表单。双图常驻，页面自然增长。 每行常驻“查看”；今天无实测显示“录入”，过去无实测显示“补录”，已有任意实测显示“编辑”，只有估计仍按日期显示录入或补录。桌面按钮同排，手机上下排列，每个按钮点击高度至少 44px，行高统一且不横向溢出。

“估算规则”在估计开关旁，默认收起，在工具栏下方展开历史初始化、日常估计和实测优先原则，桌面两列、手机一列。关闭估计显示仍可查看规则；展开不重新挂载图表。`estimate-explanation.ts` 的 `estimateUserExplanation` 从保存的依据生成用户说明，分别统计真实晨间日和晨晚配对日，体脂差使用百分点，舍入使用约等号；旧版本与缺失依据只展示已知信息。`estimateCalculation` 继续为私有报告提供完整算式、插值比例、回归方法与真实样本列表，审计结构和计算规则保持。

有具体日期的查看与编辑 Inspector 顶部常驻晨间、晚间概览，每时段分别显示体重、体脂和逐指标实测／估计标识。查看时下方为晨间／晚间详情折叠区；图表或数值入口展开所点时段、记录与指标。实测与估计共存可分别查看，多候选必须明确选择代表，查看候选不改变代表。编辑时概览下方直接显示四格表单。空日期查看打开空概览，完整历史先显示日期索引，进入日期后复用此结构；返回恢复展开、滚动与焦点。记录信息集中显示来源、时区、设备与测量时间，未知均显示“无”，不把保存时间或占位钟点当准确测量时间。 Inspector 使用一个原生 dialog，320ms 滑入、240ms 退出，渐变遮罩同步变化；动画结束后恢复滚动与焦点。内部切换保持面板打开，Tab／Shift+Tab 与 Strict Mode 保护保留，减少动态效果下直接开关。

Inspector 锁定页面滚动时，将滚动条实际占用的宽度加入原有右侧内边距，保持背景页头、摘要、图表和表格的位置及宽度。关闭后恢复原有 overflow 与内边距；浮动滚动条或无滚动条时不增加留白，连续开关与 Strict Mode 重放不累积补偿。

图表组件在晚间／估计开关、日期切换时保留实例和已测量的容器宽度，只有容器实际缩放时由 `ResizeObserver` 更新尺寸，避免切换时先按默认宽度绘制再校正。悬停／聚焦提示按记录标识从当前可见点生成，指标变化同步更新，记录隐藏后不显示旧内容。

维护脚本见 [脚本目录](../../../scripts/README.md)。网页与后续 AI API 共用本目录规则，schema／migration 由 db／drizzle 管理，文件解析由 imports 负责。测试使用虚构数据，覆盖统计解析基准、正常／无效／重复／跨账号、回滚、实测替代估计、来源独立、占位时间、图表和抽屉；浏览器入口见 [测试目录](../../../tests/README.md)。

`sources.ts` 管理账号历史来源、实测事务中的最近使用时间和授权缺失来源补齐。`migration.test.ts` 验证旧结构升级与旧文件重导，`sources.test.ts` 验证来源规则、回滚、幂等与账号隔离。数据库完整字段、索引和关系见 [数据库字典](../../../docs/database.md)。

`ai-operations.ts` 保存单日／单项的 15 分钟预览、账号快照和状态，由登录网页确认；`ai-api.ts` 组合本账号查询及安全 HTTP 响应，`ai-openapi.ts`／`ai-instructions.ts` 定义协议与说明，`ai-confirmation.tsx` 展示前后值、重复／冲突和估算依据。预览与网页共享 editing 的准备函数，确认通过嵌套事务调用同一写入，审计保存令牌和确认上下文。具体范围见 [AI 接入](../../../docs/ai-api.md)。
