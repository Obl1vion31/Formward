# 身体指标

身体只接收体重与体脂率实测。晨间明确空腹，晚间非空腹；缺测保持 null，不生成、插补或恢复估计。旧估计仅作私有审计归档，不进入网页、API、图表、统计或导出。

## 记录与来源

records.ts 提供账号锁定、校验、事务导入、时间归属、请求防重和审计。days.ts 在同日同一时段采用最后保存实测；旧候选保留历史。entry-state.ts 只区分待选择、实测和缺测。

editing.ts 提供当天部分写入、带版本的历史编辑及网页单项删除。省略字段保留，显式 null 清空；至少一个主要指标有值。删除最后一个指标归档记录，不复活旧候选。手工、AI、导入和维护复用同一校验，失败回滚并保留草稿。maintenance.ts 仅维护实测，不允许恢复已退役估计。

来源可填写真实设备／应用或明确留空。网页新录入只有目标槽之前连续三次同源实测时沿用；AI须获得用户提供或明确留空确认。来源建议只在成功保存后更新，可移除建议而保留历史快照。

time.ts、timezone.ts 保留原始当地钟点、记录日、时段、准确时间及偏移；未知准确时间不虚构，时区支持固定偏移和已有 IANA 名称。已有记录仅修改来源或时区仍保留测量事实与原始输入。

## 展示与录入

手机主卡与桌面三卡沿用现有毛玻璃布局。首页晨重卡与身体页共用七日真实小图和双向图形转场。缺测断线，不跨缺日连接，不插值生成健康值。

summary.ts 按所选日统计有效晨间实测：相邻两日都有实测才计算日差；七日窗口包含所选日和前六日，均值排除缺测，变化注明实际首末日期。体重固定开启，账号体脂偏好同步且隐藏时保留旧值；骨骼肌量／率仍未开放。

日期、单项及候选查看均只读；独立编辑／录入入口打开 MeasurementEntry。手机切换晨晚、桌面并排，来源／时区按需展开，保存失败和外部更新不覆盖草稿。历史在最近记录下展开，每批50个日历日；关闭恢复日期、滚动和焦点。

body-trend-plot.tsx 为晨间、晨晚和体脂提供同一绘图区、日期轴与底部读数；开关只改变实际系列及纵轴范围，外框和日期位置保持。日期轴统一 MM.DD、最多4个含首尾的等距刻度；完整日期 YYYY.MM.DD，跨年范围带年份。桌面读数槽常驻，手机沿用顶部读数。首页关联仅配对相同晨重、区间和模型，切换晚间或指标使旧配对失效。

仅剩晚间数据图表开关，直接展示；不保留估计开关、规则、依据、标记或空占位。静态标题、图例和操作槽从首帧显示，未知数值局部等待，加载位置及往返动效遵从[设计规范](../../../docs/design-reference.md)。

## AI 与归档

ai-operations.ts 只接收 save_day、batch 和 save_record，保留归属、版本、幂等、15分钟预览及网页登录确认。retirement.ts 拦截旧 estimate_cell；包含该操作的旧混合任务整体返回410 feature_removed，原请求和草稿保留，不执行其余项。旧实测预览移除已退役的计算说明和替换快照。

0035 migration 仅将明确 record_kind=estimated 的有效行归档，保留 measurement_events 外键、原始导入和审计。数据库禁止估计作为有效正式记录；保留的历史 JSON 不引用可执行估算类型。算法、补全／初始化／重建脚本已删除。

测试使用虚构数据，覆盖真实录入与编辑、来源、时区、缺测、统计、删除、账号隔离、旧任务退役、归档迁移及审计不变。图形和交互以实际网页验收为准。
