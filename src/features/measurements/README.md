# Measurements

本目录负责身体指标的校验、时间归属、导入与日期时段实测写入、账号隔离、历史缺测估计及回看。体重、体脂率和 BMI 已实现；网页新增、修改、删除／恢复和正式 AI API 尚待接入，方案见 [身体指标记录](../../../docs/measurements.md)。

`assignment.ts` 按当地钟点将 06:00 前归前一天晚间、06:00–17:59 归当天白天、18:00 后归当天晚间；`time.ts` 解析 IANA 时区及夏令时偏移。精确测量时间、实际当地日期与分析归属分别保存。日期／时段来源使用 `day_period`；用户授权占位时间使用 `assumed`，两者 UTC 时刻均为空，不改变实测数值的真实性。晚间统一非空腹，白天空腹须明确确认。

`records.ts` 提供校验、事务导入、日期时段实测写入、事件和账号查询。`recordKind` 区分实测与估计，`entryChannel` 独立区分 API、人为和开发后台；设备与连接应用不冒充数据同步系统。全部写入锁定归属账号，新增或恢复实测会按指标替代估计，并刷新当天缺项、保存审计；导入去重仍按真实来源时间，日期时段实测重复跳过、不复活删除记录；相同体重可补录原来为空的体脂／BMI，准确时间可确认原占位时间，保留原始输入并审计。

`estimation.ts` 提供两个明确分开的公开入口。正常模式 `morning-baseline-v3` 仅用目标日前 28 天真实数据：典型晨晚差至少 3 个配对日取中位数；晨间按实际日历日期最小二乘拟合，取最近最多 7 日、至少 3 日，距最新晨间不超过 7 天。有当天实测先加／减差值，双缺测先拟合晨间；只有晚间但配对不足时，可降级为同门槛晨间趋势。体重与体脂独立，估计、未来、条件不明及未解决候选不入正常模型。

历史初始化 `historical-initialization-v1` 仅供已明确授权的一次性任务：使用指定范围执行前的真实快照，全范围至少 3 个配对日取中位数；当天实测优先，否则用相邻晨间线性插值，两端距目标及总间隔不超过 28 天。边界在目标前后 28 天内选最近 3 个真实晨间做回归，最近实测距目标不超过 7 天才外推；同距离按日期升序。再由晨间加差值补晚间，依据不足或越界留空，不回灌估计。

`initialization.ts` 提供账号快照预览、独立事务批次、幂等执行、数据库持久报告及冻结范围检查。每个账号只能初始化一次；重复请求返回原报告，换操作标识也不能重做。批次保存真实来源快照与摘要、逐指标状态／计算依据／缺项原因及被替换旧估计。元数据区分模式、版本、实际是否用了后续日期、生成时间与批次。旧版本只读兼容，不计算预测区间。

`estimate-records.ts` 在账号锁定事务中存储估计与审计。普通实测批次只刷新受影响日期；初始化冻结范围仅移除实测覆盖的对应时段／指标，其他指标、另一时段和其他日期逐字段保持。部分指标替代时保留剩余估计和依据；全部替代时软删除旧快照。冻结范围中的空缺也不再自动补齐。

`completion.ts` 绑定账号快照、修正来源并补空缺，普通补全保留已有估计且跳过冻结日期；`trainingRange` 只约束来源维护范围。`rebuild.ts` 提供正常规则的显式重建，禁止与冻结范围重叠。恢复旧估计同样禁止覆盖冻结历史，实测恢复只替代对应指标。

`days.ts` 统一配对和候选选择，按指标实测优先，估计不会成为实测候选；晨晚差仅取真实同日、条件明确的配对。`trend.ts` 提供日历区间、稀疏刻度、正常纵轴及晨晚连线；最小跨度为 3 kg／3 个百分点。实测连续段为实线，经过估计点为虚线，未补全缺口使用极淡同色点线；未解决候选处断开。`summary.ts` 始终只统计实测空腹记录，计算最新状态、截至该日的 7 日首末差、实际日均值与覆盖天数，独立于图表区间及估计开关。

`measurements-view.tsx` 与 CSS Module 提供指标切换、无框摘要、7D／30D／90D／全部／自定义、最近 10 个记录日及统一记录 Inspector。默认 30D，晨晚及估计都显示；金色晨间主线、较淡蓝色晚间线、估计菱形及虚线明确区分。最近记录与图表等宽，固定四列，手机日期与星期分行；估计标为“◇ 估计”。图表实测／估计点和表格有效数值直接打开对应记录与当前指标。两类记录共用日期／时段／状态、大号主读数、同条记录其他指标和记录信息；查看另一指标不改变页面趋势指标。实测显示已知来源、实际时间与精度、时区、设备及连接应用；估计在同一结构中增加依据、简洁算式、真实样本日数和辅助趋势提示，更多参考默认折叠。未知可选信息不占空行，估计不冒充设备实测，不展示技术版本、标识、生成时间、批次或完整历史范围。关闭估计影响图、最近记录及日期入口，完整历史继续保留全部记录；非真实配对的晨晚差留空。

“估算规则”在估计开关旁，默认收起，在工具栏下方展开历史初始化、日常估计和实测优先原则，桌面两列、手机一列。关闭估计显示仍可查看规则；展开不重新挂载图表。`estimate-explanation.ts` 的 `estimateUserExplanation` 从保存的依据生成用户说明，分别统计真实晨间日和晨晚配对日，体脂差使用百分点，舍入使用约等号；旧版本与缺失依据只展示已知信息。`estimateCalculation` 继续为私有报告提供完整算式、插值比例、回归方法与真实样本列表，审计结构和计算规则保持。

Inspector 使用一个原生 dialog；日期入口先查看已确定的晨间记录，否则查看晚间，未确定时展示候选列表。晨晚切换遵守当前指标的实测优先规则；查看候选不设置代表，单独选择代表才更新摘要、图和表，当前不持久化。完整历史使用日期索引与简洁记录入口，进入同一详情后可返回原展开、滚动和焦点位置。忽略开发 Strict Mode 重放时过期的 close 事件，保留 Tab／Shift+Tab 循环、Escape／遮罩关闭、焦点返回与滚动恢复。`maintenance.ts` 支持快照预览、条件修正、实测候选清理、软删除／恢复；有有效同段记录时不能恢复估计覆盖它。

图表组件在晚间／估计开关、指标及日期切换时保留实例和已测量的容器宽度，只有容器实际缩放时由 `ResizeObserver` 更新尺寸，避免切换时先按默认宽度绘制再校正。悬停／聚焦提示按记录标识从当前可见点生成，指标变化同步更新，记录隐藏后不显示旧内容。

维护脚本见 [脚本目录](../../../scripts/README.md)。网页与后续 AI API 共用本目录规则，schema／migration 由 db／drizzle 管理，文件解析由 imports 负责。测试使用虚构数据，覆盖统计解析基准、正常／无效／重复／跨账号、回滚、实测替代估计、来源独立、占位时间、图表和抽屉；浏览器入口见 [测试目录](../../../tests/README.md)。
