# 首次使用、个人资料与教程

birth-date-input.tsx提供直接选择年／月／日的生日控件，手机不再通过日历翻年。部分选择留在表单草稿并阻止不完整提交，三项清空才保存为空；改变年月后无效日期清空。沿用同一ProfileForm、云端资料与版本校验。

record-guidance.tsx在本人工作区按真实DOM引导饮食、消耗、身体和训练的入口→填写→保存说明；record-guidance-model.ts集中模块、账号隔离标记和提示定位。完成标记按账号、设备和版本保存，不存健康数据；存储不可用时仅本次工作区记忆。固定内容和业务数据加载不被引导阻塞，原生面板内定位，等待及更高优先级面板出现时暂停；离开清理。跳过或完成只关闭教程，永不提交、结束训练或清除草稿。小助手常用功能可重播，既有视频教程保留。

个人资料退出按有效身高／生日比较，数值格式变化不制造草稿，读取最新资料失败保留输入。教程脚本单次8秒超时可重试，加载中也能看文字、返回与开始使用；清理仅作用于当前播放器实例。身体与补录影片按新时段切换／显式查看入口更新，AI影片随助手常用功能入口更新。AI保存回看和历史补录的电脑／手机影片随精简饮食详情实录；补录增加餐次、食物的分层查看，其他六段影片沿用。

个人资料按本人账号云端保存身高、生日和引导进度；年龄按生日计算，体重和体脂继续归身体记录。无资料行的旧账号正常进入，新邀请及维护创建账号在同一事务中初始化待填写状态。资料保存与步骤切换校验会话、账号行锁和版本；未知保持空值。

model.ts提供表单校验与年龄；records.ts负责本人资料和引导事务；server.ts只在四个主页面检查未完成引导，不拦AI确认和OAuth。profile-form.tsx复用已认可布局；tutorial-view.tsx挂载经过核对的播放器，教程媒体与无用户数据的浏览器运行代码在public/tutorials。

管理员演练由网站后台验证owner身份，使用同样的页面组件，但不调用真实保存或修改完成状态。新菜单入口在DashboardHeader；Next.js页面和Server Actions位于app。

填写不再重复“以后再补”“未知留空”等辅助行；选填和跳过已说明用途，实际年龄放在生日标签旁。演练不保存只在页头标一次。教程短预览的按钮反映实际播放状态，受限时可主动播放；手机素材390×640、连续真实滚动及坐标命中已核查。
