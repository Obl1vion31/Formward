# 训练

训练会话独立于全天消耗。自由训练与模板均可开始；动作和组次自动保存，暂停／继续在服务端计时，结束只保留已勾选的组，月历按完成时长显示。不估算热量，不自动写入 activities 或 energy_days。

model.ts 定义输入、会话、模板和排期快照；records.ts 集中归属、账号锁、幂等、版本和审计；view.tsx 与 editor.tsx 提供界面。网页通过同一套 feature 写入，当前没有新增 AI 权限或公开接口。模板排期保存快照，后续模板变化不改写计划或已完成事实。空训练可确认放弃，保留今日计划。

每账号最多一场进行中训练。请求 ID 绑定内容；并发修改返回冲突，不能覆盖其他页面的版本。结束和放弃均保存审计。未知重量／次数用空值，完成组必须有正整数次数。服务端保存进度失败时保留当前输入，关闭及离开保护使用项目共用机制。
