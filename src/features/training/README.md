# 训练

训练会话、模板与日历计划独立于全天消耗；训练首页为紧凑具体训练入口、默认收起的模板区和月历；切换复用持久标题行。没有计划时只显示开始训练，有计划时区分按计划／自由训练，已有进行中训练则继续。月历共用六周网格，按已完成训练的时长显示深浅。

catalog.ts 自行整理150项中文动作：100项力量／徒手／核心、20项有氧、30项拉伸与活动度。稳定标识、英文／别名、部位、器械、动作模式、记录类型与参考链接用于检索；不依赖远程动作服务或图片。exercise-picker.tsx 为模板和训练共用的搜索、筛选与多选入口；template-form.tsx 支持排序、组数和可选目标，自定义动作可选择记录方式。

model.ts 定义输入与快照：reps记录次数及可选kg，duration记录秒，cardio记录秒／米。未知为null，已知重量和距离可为0；完成次数／时长必须为正值，有氧至少有正时长或正距离。模板目标与实际组次分开，旧无recordingType的快照按次数模式解释，不改写历史。会话总计时与动作时长分别保存。

use-template-drag.ts从独立手柄处理鼠标／触点捕获、名称浮层、日期命中、边缘滚动及取消；正文保留原生滚动，点选排期继续可用。模板名称可原位展开动作目标。

records.ts 集中账号锁、归属、幂等、版本和审计。每账号最多一场进行中训练；保存失败保留输入，结束只保留已勾选组，放弃保留计划。网页专用delete_completed经明确确认永久删除完成会话，同事务保存审计；最后一场完成删除后恢复关联计划并递增版本，AI来源拒绝删除。模板更新不改写已有排期快照，改期校验版本、归属、目标重复和进行中训练。

ai-model.ts／ai-plans.ts／ai-api.ts 为GPT提供动作查询、本人模板／计划查询及模板／排期投影，复用records的统一审核存储，不新增表。新模板可通过同批templateRef排多天；AI提交只有预览，原授权有效且用户在网页确认后才调用同一training事务写入，审计origin=ai。plan-review.tsx提供预览及修改目标／日期。OAuth独立training:read／training:write，旧连接不自动扩权；预览24小时有效，取消不删除既有事实。

layout.tsx／loading.tsx与正式页共用稳定外壳；加载全过程及面板退出按[设计与视觉验收](../../../docs/design-reference.md)检查。界面不估算热量，不自动写入activities或energy_days。维护规则与MCP例子见[训练记录](../../../docs/training.md)。

训练操作槽在加载首帧保留“开始训练”按钮；当前会话未核验时禁用，就绪后按真实状态显示开始、按计划或继续。训练模板、日历标题和固定图例始终显示，真实月份、星期和日期网格首帧显示；仅计划、完成记录及统计未知，不逐日绘制灰块，也不先猜休息或无训练。

MCP训练查询可选summary／details与日期分段；会话和排期在SQL中按本人／日期过滤，摘要只给必要编号、版本、日期和状态，模板目标及实际组次在details展开。模板与排期写入仍沿用原工具，不新增AI执行或完成训练的能力。

AI字段解释由ai-field-definitions.json维护，区分模板目标、日历计划与实际会话，明确秒／米／kg及会话经过时间。查询中的requiresWebConfirmation说明后续修改需要确认，不表示已有计划或模板未保存；待审after仍是目标投影，不是完成事实或消耗。
