# 当前账号 Excel 导出

`workbook.ts`读取经过认证的账号饮食、身体和消耗快照，复用服务端每日汇总与总览规则，在只读repeatable read事务内顺序读取一致快照，再在内存生成原生`.xlsx`。只导出有效记录，不读取账号凭据、OAuth、令牌或其他账号数据。首表为每日汇总、说明置于末尾。未知值为空白、明确0为数字；业务日期、来源、单位和实测／估计分开列出，文本不转成公式。

网页入口在`app/dashboard/export`，下载经同一会话认证且禁止缓存。from／to只筛选按日事实；食材库与公式资料是参考信息，完整导出并在说明工作表标注。每日汇总中的次晨配对允许读取区间外已存在的次日晨重，保持总览口径。原图不嵌入，仅导出数量／内部标识，不构成照片完整备份。文件不写public、Blob或磁盘。

`workbook.test.ts`以虚构数据验证xlsx回读、日期区间、数字／未知、日状态与盈余、模式采用、估计、文本公式防护及账号隔离。导出不产生健康记录、估算、审计修改或其他写入。
