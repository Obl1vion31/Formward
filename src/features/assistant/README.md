# 小助手

## 站内聊天方向约定

THESIS：真实业务任务贯穿提醒和聊天，回答正文优先，模型选择和用量保持次级。

OWN-WORLD：沿用Formward暖白／石墨／金色、品牌及漂浮导航；标题18px、正文输入16px、操作14px、辅助13px，44px命中。

STORY：指定owner选择千问／小米MiMo／智谱，查询真实记录、补充实际食量、查看预览并在原网页确认；其他账号保持确定性提醒。

FIRST VIEWPORT：电脑860px同窗双栏，左220px事项、右聊天；手机近全屏底部面板内聊天／待办切换。手机标题、切换与拖动整合约52px；输入工具栏选择模型，发送左侧仅显示百分比，提示只含重置时间。

聊天照片等待addPhotos结束后再清空选图控件，上传器在任何网络等待前读取完整原图字节；读取、申请凭据、上传和核对各自反馈。该修正独立于prompt、工具规则及会话上下文，当前仅为本地兼容候选，真实Safari复测与发布状态见验收文档。

FORM：已验收原型的普通扩展，code-led。seed: none (unavailable)

FINISH：独立复核对三项视觉修复及矮屏回归均评分resolved，disposition为ship，范围限于所列助手修复。现行D15与实际验收文档记录普通扩展证据；不重建全站视觉系统，无新增shipping raster。最终兼容包及正式账号验证分别记录。

站内聊天由chat-config按有效登录、owner和指定账号ID共同控制。chat-store管理30天独立授权、当前会话、请求幂等和每日共享预算；chat-provider适配三家流式协议；chat-tools复用21项正式MCP能力及records的按需工具会话协调器；chat-runtime组织按需工具、显式补充、私有照片、版本与预览。chat-client持有本账号输入与当前历史，chat-view和chat.module.css呈现已验收原型的普通扩展。业务及配置见[站内助手](../../../docs/assistant-chat.md)，视觉及验收见D15及[实际记录](../../../docs/assistant-chat-verification.md)。

提示词通过records/ai-prompt.mjs与隔离评测共用；chat-config.promptVariant显式选择original或compact，当前千问使用original、小米使用compact；智谱保留原配置，不在本轮收费测试范围。36题两版对照及两题接口修复整组回放中，千问长版质量77.24/80、精简版74.19/80；小米长版75.85/80、精简版75.37/80。选择依据是本题库的质量、费用与耗时，不声称更慢必然更聪明；原失败和未验收的网页保存流程单独保留。私有结果见`.codex/model-evaluation`，不能公开健康图片或报告。站内专用补充输入、已保存附件及技术元数据边界单独追加。工具请求编号由服务器按用户消息、授权和业务参数生成，模型无需填写；相同内容重试稳定复用，修正仍关联原待审草稿。外部MCP定义及正式保存保护不变，不增加审核模型。

首次默认千问，模型偏好跨刷新及新对话保留；切换不调用模型或清空输入。当前会话按5条加载、最多50条可访问，不自动删除更早历史。三家共用每日¥2，发送按钮左侧只显示百分比，提示仅含重置时间；费用、预占与未知仅由服务器继续核算。消息使用实际授权追溯来源，正式健康记录仍经原审核网页确认；自动提醒及忽略保持不调用模型。原型的模拟数据和私有评测不进入正式运行包。重试回执逐项保存并验证原授权引用，失效回执不借其他模型的新授权复活；新授权生成独立预览标识。

站内工具保留经过入口和会话验证的原Request，由正式MCP生成所属入口的审核链接及处理区域；内部JSON-RPC仅作传输，不另建丢失验证头的业务请求。国服开启区域验证的回归覆盖预览成功、同请求链接幂等及无验证来源不生成草稿，不放宽公网来源限制。跨模型历史正文仅传真实消息原文，附件编号及导航引用单独归入内部定位上下文，不冒充用户或助手已说的话；输出说明约束技术元数据及用户时区，不改写已存历史。

助手平时收起，手机从五项导航右侧独立按钮打开可拖动底部面板，电脑从右下按钮打开非模态浮窗。打开、反向与关闭复用可中断表面动画；关闭时面板与遮罩同步退出，完成后释放滚动并恢复焦点。

正文先显示三个快捷记录入口，再列真实事项及按需补记。底部常用功能按钮控制内部向上展开的教程、AI接入、导出和重播操作引导，不增加第二个模态层。重播在同一工具抽屉选择饮食、身体、消耗或训练；Escape先返回模块选择，再收起工具。快捷记录、重播与功能导航先等待助手退出，再进入真实业务页面，保留原草稿保护。

主动事项包括仍可处理的AI审核、今日尚未开始的训练计划、昨日尚未确认记全或缺失的饮食。统一审核批次与子操作去重，取消、过期及已撤销授权不计数；训练已开始、完成或跳过后不提醒。消耗和身体仅为可选补记，不形成打卡要求，不追讨前一天以前的饮食。

角标来自私有上下文，打开不等于处理完成。本账号本设备每天最多一条站内轻提示，点击才展开助手；不自动打开完整面板，无自动出现开关。页面可见时每60秒及恢复前台、实际保存后合并刷新，后台停止，同一时刻仅一个请求，迟到响应不能恢复旧事项。

昨日饮食可以忽略这一天。assistant_reminder_dismissals按账号和日期唯一保存，跨设备下一次读取生效，不改餐次、记全状态、训练或AI任务。Server Action采用当前会话证明，事务在账号锁内再次验证；失败保留事项，重试幂等。所有读取有界且校验账号，客户端不持久保存健康摘要；仅保留当日轻提示标记及跨标签失效信号。

聊天消息区使用零占位的居中悬浮向下按钮，距离最新超过80px显示，36px外观／44px命中，返回底部隐藏且不唤起键盘。小于360px以原生下拉切换聊天／待办，其他手机在同一头部切换；模式切换不卸载聊天，保留草稿、附件与阅读位置。输入区域使用稳定底色，移除独立用量行及金额明细。

手机聊天／待办使用16px标签与贴近文字的2px选中线，正常52px头部；小于360px改为同位置选择菜单。空对话只显示“拍照描述食物或查询你的记录。”。输入框单行正常约92px，照片、模型、用量百分比及发送沿底部工具行对齐；用量仅提示重置时间，不显示金额。最新箭头在输入框上方居中悬浮，不占布局行。

照片选入即在输入框内显示72px附件，准备使用暗色遮罩、传输显示真实字节百分比圆环，100%标为核对中，登记成功才可发送。每张支持移除／取消、重试，国内网络停滞可人工选择同源备用；选图即读取每张原图，网络排队不再等待临时File；原图字节复用，失败保留文字、引用及其他照片。单文件取消可解除准备等待，独立于模型生成状态；账号退出清理对象URL与上传任务。视觉回放不冒充真实存储或iPhone Safari通过。
