# 小助手

本目录提供跨页面的小助手：本人今天／昨天的待核对与补录建议、快捷记录、教程、AI 接入和 Excel 导出。

读取通过各业务 feature 的有界查询，规则复用既有饮食记全、身体采用和消耗计算。网页私有接口不接受账号参数；不增加公开 AI 权限或健康写入能力。

电脑保留右下非模态悬浮窗口；手机在右上入口下方展开模态助手，长内容内部滚动，不提供底部把手。共享状态随账号重置，仍只持久保存自动出现偏好和当日标记，不保存健康内容。

手机和电脑的助手均显式采用anchored动画，关闭末态保持到卸载。hide返回退出Promise；快捷记录和常用功能经LoadingLink.beforeNavigate等待退出后导航，避免两个弹层同时出现。每天自动限制、失败重试与先继续浏览保持。
