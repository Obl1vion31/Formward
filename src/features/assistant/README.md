# 小助手

本目录提供跨页面的小助手：本人今天／昨天的待核对与补录建议、快捷记录、教程、AI 接入和 Excel 导出。

读取通过各业务 feature 的有界查询，规则复用既有饮食记全、身体采用和消耗计算。网页私有接口不接受账号参数；不增加公开 AI 权限或健康写入能力。

电脑为非模态悬浮窗口，手机为底部模态面板；共享状态随账号重置。仅在本地保存自动出现偏好及当日展示标记，不持久化健康内容。未来消息能力从内容区与操作区扩展，当前不提供聊天输入。

手机复用Inspector半屏／展开和拖动，退出沿来源连续收束后再卸载；当日展示标记、每日自动限制、重新登录与先继续浏览均保留。电脑继续非模态窗口，进出复用surface-motion。
