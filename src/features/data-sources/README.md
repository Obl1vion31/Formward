# 设备与数据来源

负责账号数据连接、按指标采用来源、来源事实、同步和冲突保护。Garmin Personal 按服务器模式开放：personal 允许已登录账号填写本人密钥，pilot 仅指定账号，disabled 关闭；未配置保持原 pilot 行为。业务读数仍由 activities 提供，不将每日汇总与运动再次累计。

连接凭据使用独立服务器主密钥加密；返回浏览器的模型不包含密文、密钥或原始上游响应。同步先在事务外读取，再锁账号复核连接与规则版本后提交。来源事实与正式采用值分离，人工改动保护整天，备注改动不冻结。页面只读取连接元数据，勾选项在同一事务内映射采用来源；保存后读取失败不冒充设置保存失败。历史范围复用现有客户端读取；相似运动独立载入，同来源按activityId更新，不额外累计到日总量。保护日只追加真正首次出现的来源明细，不复活删除项或改写人工维护事实。测试只使用虚构响应。

旧v1凭据默认国际站且不重写；新v2凭据将站点加入认证附加数据，篡改站点会在请求前解密失败。换站点时暂停并归档旧连接，保留原凭据及来源事实，新连接使用独立编号和递增版本，防止两站来源编号冲突。

密钥入口位于卡片状态之后，未连接显示“输入个人密钥／连接并同步”，已有连接显示“更换个人密钥／更换并同步”。填写区按需展开，局部显示真实忙碌状态，成功清空输入；未保存失败保留输入。后台任务逐个账号获取本人的连接，最多三路读取，共用50秒截止信号；跳过暂停、停用和访问版本失效的连接，一人失败不影响其他账号。超过本轮预算的连接等待后续调度或前台补充同步；响应仅含执行计数。

首次未知连接只保留标题、关闭和超过200ms的一处局部等待，不显示假复选框、假未连接或零用量。消耗来源状态首次读取同样局部等待；保留真实缓存视图期间不自动同步，恢复实际页面后沿用原同步规则。
