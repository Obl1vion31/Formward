# 全站管理后台

仅owner及近期管理验证可访问。queries.ts在服务器聚合模型账本、业务调用计数和有效记录数量，不读取健康值、照片或聊天正文；policy.ts在账号锁内更新独立AI策略并写账号审计。console.tsx沿用Formward品牌，电脑以趋势和表格为主，手机提供概况与用户详情。统计北京时间归日，费用以请求费率快照计算，已结算、预占和未知分别显示。所有新增目录同时维护README，测试使用虚构数据。

加载外壳按可信请求路径保留已知日期、模型、用途、搜索、排序和用户编号，未知用户名仅显示所选用户；实际数据接管采用同一布局。详情返回同时保留筛选、页码和列表位置，验证到期隐藏数据但保留额度草稿。

后台共用theme.css的主站颜色、系统字体、BrandLogo及外观切换，不另设调色板。用户详情先显示Free／内测版／Plus会员档位，个人金额、次数与暂停在默认收起的个人AI限制中调整。切换档位保留既有个人覆盖；恢复档位额度后清除覆盖。继承默认的输入显示服务器计算的档位默认值，无单独金额／次数上限保持空值并明确说明。档位和个人策略共用单调版本，近期验证、幂等与审计规则保持。
