# 全站管理后台

仅owner及近期管理验证可访问。queries.ts在服务器聚合模型账本、业务调用计数和有效记录数量，不读取健康值、照片或聊天正文；policy.ts在账号锁内更新独立AI策略并写账号审计。console.tsx沿用Formward品牌并组织三个主栏目；navigation.ts统一新旧链接与有界后台返回路径，navigation-view.tsx提供共享导航。usage.tsx集中日期／用户筛选、费用趋势、模型明细和记录数量；规则设置由tiers.tsx管理档位。安全事件与账号操作记录单独进入。统计北京时间归日，费用以请求费率快照计算，已结算、预占和未知分别显示。所有新增目录同时维护README，测试使用虚构数据。

后台布局持续挂载顶栏和栏目导航。首次读取显示已知标题、筛选和操作槽，超过350毫秒才在标题旁提示。切栏目或进详情时留住当前正文直到目标就绪，账号搜索的等待位于列表标题。当日明细只显示一处提示，同条件刷新保留绘图和已返回记录。账号、邀请、规则、安全事件与操作记录读取各自所需数据，用量统计只在用量页及原有用户详情中读取。返回保留筛选、页码和列表位置，验证到期隐藏数据并保留草稿。后台链接采用按次验证的导航。

后台共用theme.css的主站颜色、系统字体、BrandLogo及外观切换，不另设调色板。person-summary.tsx只呈现用户概况和三个跳转，不含图表或表单。账号设置页分配会员档位及管理访问；policy-form.tsx在独立个人额度页调整金额、次数与暂停。切换档位保留既有个人覆盖；恢复档位额度后清除覆盖。继承默认的输入显示服务器计算的档位默认值，无单独金额／次数上限保持空值并明确说明。档位和个人策略共用单调版本，近期验证、幂等与审计规则保持。

档位入口由tiers.tsx提供，memberships.ts在独立配置锁、操作者及目标账号锁中执行新增、改名、额度／功能／默认档位调整和删除转移。管理员专用档位不授予角色、不分配给普通用户。个人覆盖保留，档位修改递增相关账号权益版本，运行中的已预占费用转未知占用；恢复不重放任务。创建账号与邀请激活读取当前默认档位。

cost-chart.tsx使用站内即时提示、键盘方向键与点击固定日期，不修改外层日期区间。queries.ts每日期预取前三个模型／用户摘要；当日明细通过受保护动作每页50项读取，可按实际模型或用户继续筛选。单人默认模型视角，全站可切换用户／模型。具体模型与供应商共同筛选，不把模型名称当作供应商。

档位草稿保留打开时的版本，刷新到其他修改后展示最新配置，管理员明确核对才继续；目标已归档时禁用提交并保留输入，不把旧草稿当作新增档位。档位加载外壳在服务器直接渲染，避免为固定文字再引入客户端等待。

后台按三个主栏目及安全入口的排列顺序移动就绪正文。账号与邀请按子栏顺序切换。用户概况沿原入口前进与返回，账号设置及个人额度再向前一级。实际回读和按次验证沿用导航流程。
