# 总览

图表返回时，缓存总览只承接显示，不向转场报告真实读取已经完成；只有非刷新快照的OverviewView可以交出返回外壳。慢读取期间保留缓存、来源卡片及焦点恢复目标，真实页面接管后再恢复焦点，不能由缓存提前消费。

前进图形到达后预备隐藏且inert的本人缓存总览，返回点击不再现场构建整页。隐藏分支保留尺寸计算，以专属预备标记和inert阻止图形注册、焦点恢复与提示；外层高度0并裁切，不增加当前页滚动高度，读数和双层趋势通过memo隔离未变化内容，转场上下文只更新外壳接管；数据读取与图形移动仍独立。

daily-reminders.ts仅构造最小记录目录，复用采用中的身体实测、dailyTotals和energyDays，供features/assistant判断今天／昨天的事项；原总览提醒条已退出。助手通过独立私有上下文读取有限的今日／昨日及有效事项，不将总览的部分摘要当作权威提醒，也不随图表选日读取完整历史。助手和图表选日互不改写。range-coverage.ts从已有OverviewDay结果统计区间收支覆盖，未知不当0；range-coverage-view.tsx在双图后展示摘要并原位加载每批50日的缺口。

记录页面共同框架提供日期与查看、主要读数、区间、标题与实际选项及图例；总览使用净收支和次晨实测变化的双层关联图。手机绘图区按宽度与矮屏等级稳定分配，不受上方卡片或临时状态高度影响，不缩放字形；能量读数显示整数，身体和kg差显示两位，数据与坐标范围不因悬停改写。

总览双层关联图共用日期、选中线和命中区。上层按日显示已有净收支，缺口在零线下方，盈余在上方，明确持平在零线用短标记。当天有能量记录但收支未计算时，下方独立的「未计」行显示灰横，日期完全无能量记录时留空。下层将相邻两天实测晨重变化用金色细杆从零线连接到读数。能量、体重的纵轴各自独立，坐标按整个区间决定。收支采用已有的完整性和全天消耗判断，手机7D、桌面30D，默认选择最近能算收支的日期。

手机能量区上方显示选中日期和收支，图后两行展示七天结果和计入天数，依据可原位展开。电脑七天摘要位于区间栏之前，完整的区间覆盖和缺口清单位于图后。

状况摘要分别采用今天及以前最近的实际记录日期；摄入汇总该日有效餐次，消耗采用最近有效日记录或已完成运动，晨重采用最近实测。各类日期可不同，未知、部分和明确0保持区别。两端都在完整关系图之前展示摄入／晨重／消耗卡片，手机横滑、电脑自适应并排；图后不再重复摘要卡。三卡共用summary-cards.ts准备的七日图形和链接，进入专页对齐日期范围，不打开日期详情或编辑器。总览图形继续围绕所选日期，卡片不随悬停改写；跨零点不清空已有摘要。

业务聚合、收支和相邻日配对在model.ts。presentation.ts生成实测日期和摘要，overview-trend.tsx提供区间与完整当日记录。relationship-plot.tsx绘制两层SVG并管理选日时的明细卡片，chart-geometry.ts提供次晨刻度、刻度密度和卡片换侧定位。day-readings.ts使用已有事实准备简短文案，day-readout.tsx显示日期、收支、蓝色摄入、红色消耗和次晨变化。单缺一天明确标日期，两天均无晨重直接说明，实测相同显示「无变化」，需要确认时显示「晨重待核对」。

手机点柱或灰横打开单日明细，电脑悬停预览、点击锁定。再点同日、点图外或按Escape收起，明确选择的日期可继续用于「查看记录」。键盘方向键按日移动，Enter展开或收起。卡片贴近所选日期、靠边换侧，覆盖在自己的绘图区内。「查看记录」打开选中日的原有详情，关闭后回到所选日期和原滚动位置。手机图组常规276px、矮视口236px。

网页保存和AI确认刷新总览，登录身份校验留在app。净收支柱和次晨变化细杆由use-chart-motion.ts同时从各自的零线伸出，首次约600ms，主动换区间约220ms。灰横、持平标记、坐标轴和命中区首帧位于最终位置。纵轴始终标出零点，其他刻度按实际像素间距取舍。选日、共享转场、缓存返回、静默更新、设备接管和减少动态效果按现有图表规则处理。相关验收见tests/energy.browser.mts和tests/overview-first-screen.browser.mjs。

七天读数由model.ts为每个选中日准备，独立读取前6日支持数据，体重比较开始晨至结束次晨。presentation.ts补齐可查日历日以支持空日的七天统计，不写数据库占位。有效日先按原精度相加，最终按整数展示；缺失不当零。手机次晨变化显示在双图过渡处，图后七天按两行左对齐；电脑保留六项单日读数和紧凑七日横条，依据直接显示。普通状态切换不移动筛选或图形，必要提示贴日期行。

日期详情复用meals/saved-meal-list.tsx，展示与饮食页一致的餐次、食物及附件层级；仅当天合计保留供能环图。超过三餐按需展开，跳转饮食仅在列表末尾保留一次，带正确日期；待确认改为合计附近的短状态入口。身体／消耗摘要与主图表保持。

首页标题、当地日期及三项记录入口由持久WorkspaceFrame提供。数据组件只准备真实卡片与趋势；跨午夜才刷新快照，初次设备／当地日期校正不再次导航。总览骨架复用卡片的双端布局与共轴双图。OverviewTrend在本人持久上下文中保存已应用区间、自定义范围和估计选项，返回按新快照展示，不恢复旧健康数值。

workspace-cache-state.ts与workspace-cache.tsx保留当前账号浏览器内存中已成功读取的视图，每类页面仅最近一组条件、合计最多五组；键包含路径、日期、区间及筛选，不缓存录入／编辑。相同条件返回时真实内容只读保留并后台更新，超过200ms局部提示；首次只显示真实固定外壳，查询失败可重试。账号切换、跨日及记录变更使旧内容失效，不新增健康数据本地持久化；服务器固定查询键防止迟到响应误登记。缓存重新挂载期间不打开编辑器或触发设备同步。

relationship-frame.ts共享总览实际图形及首次等待框几何：电脑448px、手机276px、矮屏236px，宽度／设备模式接管不另设一套预加载高度。未知图形留空和局部等待，不绘制假曲线；页面首帧、正常及慢查询按设计文档逐帧检查。

设备识别不再隐藏总览／身体的已知正文；总览首帧由响应式外壳显示对应内容，识别后仅保留可见图形分支。图表外框由CSS预留，SVG只接管真实坐标，未知刻度宽度不推动记录标题。

关联图在首次宽度未知时SVG仍隐藏，但父框及SVG高度均由relationshipFrameStyle提供（桌面448px，手机276／236px），不依赖fallback viewBox的固有纵横比，避免WebKit冷加载先撑高再收回；首次测量完成前仅图形区显示原模块占位，标题、读数、图例和操作继续可见。
