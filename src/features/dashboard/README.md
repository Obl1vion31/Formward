# 总览

总览以一张图展示 D 日摄入、最终消耗、盈余（摄入−消耗）及 D+1 晨重−D 晨重。浅蓝／浅红／金色三柱固定并排，暖白细线用右侧 kg 刻度，两轴零点对齐。相邻日缺测或候选未决留空；开关可显示已有估计，以虚线区分，不生成未来体重或作确定因果结论。标题与日期范围紧邻，图例和读数紧凑排列，保留 7D／30D／90D／全部／自定义、键盘选择和日期详情。图下身体、摄入、消耗三张卡进入对应页面；身体卡显示最近有效空腹晨重。

`model.ts`聚合饮食、身体与消耗快照，只计算展示数据；`overview-trend.tsx`绘制综合图及日期详情，`overview-view.tsx`提供三张入口卡，样式在`overview.module.css`。身体详情仍保留真实晨晚差和独立图表。

网页保存和AI确认刷新总览；身份查询留在app。`model.test.ts`覆盖三柱数值、相邻晨重、估计开关、缺日、候选与正负刻度，浏览器见`tests/energy.browser.mts`。图形动效共用`use-chart-motion.ts`，坐标与命中区域保持稳定。
