# 总览

总览采用双层日期关联图：上层为蓝色摄入线和红色消耗线，线间柔杏金（#D8B38A，28%）表示盈余、雾蓝灰（#92B2C2，28%）表示缺口，交点处分区；下层暖白线显示严格相邻次晨变化，两层共用日期、选择线和命中区域。能量折线按完整区间取整并留余量，kg轴独立包含零；未知断线，填色在有效段末尾轻淡出，不跨缺日。顶部展示摄入−消耗＝盈余／缺口，以及两日晨重与差值；部分摄入和估算不阻止相减。保留7D／30D／90D／全部／自定义、估计开关、固定图宽；鼠标、触屏或方向键选日，Enter或“查看记录”打开详情。下方为紧凑的身体、摄入、消耗入口摘要。

`model.ts`负责业务聚合、盈余与严格相邻日配对；`presentation.ts`在服务端生成两种估计显示口径及摘要。`overview-trend.tsx`负责区间、单日计算式与详情，`relationship-plot.tsx`绘制同一SVG中的双层图，`chart-geometry.ts`仅提供折线刻度、交点、分区、缺测段和淡出几何；不在客户端重算健康规则。样式在`overview.module.css`。kg轴使用components/chart-scale.ts，能量折线使用本目录局部刻度，其他页面柱图仍从零开始。

网页保存和AI确认刷新总览，身份校验留在app。`model.test.ts`验证业务，`chart-geometry.test.ts`验证交点和缺测边界；浏览器入口为tests/energy.browser.mts，覆盖四种宽度、拖动、键盘、触屏、详情及减少动态效果。复用use-chart-motion.ts：图形450ms入场／200ms区间变化，读数、坐标和命中区域不动，选日不重播。
