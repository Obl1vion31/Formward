# 总览

总览以一张图展示每日摄入 kcal、相对区间首个有效晨重的变化 kg，以及同日晚重减晨重的带符号差值 kg。蓝色摄入柱使用左轴，金色晨重线和红色晨晚差柱共用右轴；同一天红蓝柱水平居中、共用零点，蓝柱较宽、红柱在前，负差值向下。默认 30D、显示已有估计；不生成估计，估计线虚线、差值柱纹理，缺记录留空、多候选不擅选。7D／30D／90D／全部／自定义均固定宽度，悬停／聚焦／方向键更新读数，点击日期打开详情。图下身体和摄入整卡分别进入详情，身体显示最近一次真实晨间或晚间体重及日期，摄入显示今天已记录热量与“预算未设置”。Logo 返回总览，详情页有返回入口，页头不再重复列三个模块。

model.ts 聚合事实、计算展示用晨晚差／相对晨重、按测量日期晨晚取最新实测；overview-trend.tsx 提供统一图与当日详情；overview-view.tsx 提供入口卡片。身体详情的晨晚差仍只用真实配对，总览可显示已有估计，不改变该规则。

网页保存和 AI 确认刷新 /dashboard；身份查询留在 app。单元测试验证带符号差、区间基准、候选／估计／缺日、零值和最新实测，浏览器验收位于 tests/meals.browser.mts。
