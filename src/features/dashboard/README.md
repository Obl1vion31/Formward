# 总览

图表返回时，缓存总览只承接显示，不向转场报告真实读取已经完成；只有非刷新快照的OverviewView可以交出返回外壳。慢读取期间保留缓存、来源卡片及焦点恢复目标，真实页面接管后再恢复焦点，不能由缓存提前消费。

前进图形到达后预备隐藏且inert的本人缓存总览，返回点击不再现场构建整页。隐藏分支保留尺寸计算，以专属预备标记和inert阻止图形注册、焦点恢复与提示；外层高度0并裁切，不增加当前页滚动高度，读数和双层趋势通过memo隔离未变化内容，转场上下文只更新外壳接管；数据读取与图形移动仍独立。

daily-reminders.ts仅构造最小记录目录，复用采用中的身体实测、dailyTotals和energyDays，供features/assistant判断今天／昨天的事项；原总览提醒条已退出。助手通过独立私有上下文读取有限的今日／昨日及有效事项，不将总览的部分摘要当作权威提醒，也不随图表选日读取完整历史。助手和图表选日互不改写。

记录页面共同框架提供日期与查看、主要读数、区间、标题与实际选项及图例；总览使用净收支和次晨实测变化的双层关联图。手机绘图区按宽度与矮屏等级稳定分配，不受上方卡片或临时状态高度影响，不缩放字形；能量读数显示整数，身体和kg差显示两位，数据与坐标范围不因悬停改写。

总览双层关联图共用日期、选中线和命中区。上图显示净收支柱，缺口向下、盈余向上、确认持平用零线短标记。无法计算的日期留空，仍可选日读明细。下图用金色细杆显示相邻两天实测晨重变化，零点两侧按图高选择可读的 kg 刻度，两轴独立。默认手机7D、电脑30D，选最近可计算收支的日期。

30D在首日、每隔五天及末日绘制七条淡日期线，上下绘图区对齐。窄视口按实际宽度减少日期文字。区间下方按当日、近7天排成两行，左右对齐日期、热量收支和实测体重变化。计入天数在周日期旁的信息按钮中，鼠标悬停或点击即可读。缺口、盈余图例与查看记录在图上方同排。

状况摘要分别采用今天及以前最近的实际记录日期；摄入汇总该日有效餐次，消耗采用最近有效日记录或已完成运动，晨重采用最近实测。各类日期可不同，未知、部分和明确0保持区别。两端都在完整关系图之前展示摄入／晨重／消耗卡片，手机横滑、电脑自适应并排；图后不再重复摘要卡。三卡共用summary-cards.ts准备的七日图形和链接，进入专页对齐日期范围，不打开日期详情或编辑器。总览图形继续围绕所选日期，卡片不随悬停改写；跨零点不清空已有摘要。

业务聚合、收支和相邻日配对在model.ts。presentation.ts生成实测日期和摘要，overview-trend.tsx提供区间与完整当日记录。relationship-plot.tsx绘制两层SVG并管理选日时的明细卡片，chart-geometry.ts提供次晨刻度、刻度密度和卡片换侧定位。day-readings.ts使用已有事实准备简短文案，day-readout.tsx显示日期、收支、蓝色摄入、红色消耗和次晨变化。单缺一天明确标日期，两天均无晨重直接说明，实测相同显示「无变化」，需要确认时显示「晨重待核对」。

手机点柱或对应日期位置打开单日明细，电脑悬停预览、点击锁定。再点同日、点图外或按Escape收起，明确选择的日期可继续用于「查看记录」。独立绘制的日期刻度也能点选。同一区间各日期命中区域及选中带等宽，键盘方向键按日移动时用金色实线标出焦点，Enter展开或收起。卡片贴近所选日期、靠边换侧，覆盖在自己的绘图区内。「查看记录」打开选中日的原有详情，关闭后回到所选日期和原滚动位置。

网页保存和AI确认刷新总览，登录身份校验留在app。首次显示时，净收支柱和次晨变化细杆在约600ms内同时从各自的零线伸出。7D、30D、90D扩大区间时，共同日期先用约180ms向右收拢，较早日期的柱与细杆随后用约220ms按相同缓动同时从各自零线伸出。缩短区间时用约300ms先淡出早期日期再展开共同日期。两层的标记、零线和共同刻度同步移动，快速换档从当前画面续接。「全部」和有效的自定义区间切换沿用约220ms的零线伸展。纵轴始终标出零点，其他刻度按实际像素间距取舍。选日、共享转场、缓存返回、静默更新、设备接管和减少动态效果按现有图表规则处理。相关验收见tests/energy.browser.mts和tests/overview-first-screen.browser.mjs。

七天读数由model.ts为每个选中日准备，独立读取前6日支持数据，体重比较开始晨至结束次晨。presentation.ts补齐可查日历日以支持空日的七天统计。有效日先按原精度相加，最终按整数展示，缺失仍为未知。选日同时更新两行，信息浮层不占图表位置。

日期详情复用meals/saved-meal-list.tsx，展示与饮食页一致的餐次、食物及附件层级；仅当天合计保留供能环图。超过三餐按需展开，跳转饮食仅在列表末尾保留一次，带正确日期；待确认改为合计附近的短状态入口。身体／消耗摘要与主图表保持。

首页标题、当地日期及三项记录入口由持久WorkspaceFrame提供。数据组件只准备真实卡片与趋势；跨午夜才刷新快照，初次设备／当地日期校正不再次导航。总览骨架复用卡片的双端布局与共轴双图。OverviewTrend在本人持久上下文中保存已应用区间、自定义范围和估计选项，返回按新快照展示，不恢复旧健康数值。

workspace-cache-state.ts与workspace-cache.tsx保留当前账号浏览器内存中已成功读取的视图，每类页面仅最近一组条件、合计最多五组；键包含路径、日期、区间及筛选，不缓存录入／编辑。相同条件返回时真实内容只读保留并后台更新，超过200ms局部提示；首次只显示真实固定外壳，查询失败可重试。账号切换、跨日及记录变更使旧内容失效，不新增健康数据本地持久化；服务器固定查询键防止迟到响应误登记。缓存重新挂载期间不打开编辑器或触发设备同步。

relationship-frame.ts为总览实际图形和首次等待框提供同一几何。电脑418px、手机268px、矮屏228px，两层间距分别为26px和24px。宽度／设备模式接管使用对应视口预留高度。首帧和真实读数共用overview-trend-layout.tsx，未知图形留空和局部等待，不绘制假曲线；页面首帧、正常及慢查询按设计文档逐帧检查。

总览首帧由响应式默认区间和共用双行读数呈现。设备识别后，实际绘图区接管对应的坐标和密度。图表外框由CSS预留，未知刻度宽度不推动上方读数。

关联图在首次宽度未知时SVG仍隐藏，父框及SVG高度均由relationshipFrameStyle提供，避免WebKit冷加载先撑高再收回。首次测量完成前仅在图形区显示占位，标题、读数、图例和操作继续可见。
