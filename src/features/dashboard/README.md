# 总览

daily-reminders.ts仅构造最小记录目录，复用采用中的身体实测、dailyTotals和energyDays，供features/assistant判断今天／昨天的事项；原总览提醒条已退出。总览服务端快照派生助手种子，不因小助手读取完整历史；其他页面手动打开时按需读取私有接口。助手和图表选日互不改写。range-coverage.ts从已有OverviewDay结果统计区间收支覆盖，未知不当0；range-coverage-view.tsx在双图后展示摘要并原位加载每批50日的缺口。

四页共同框架提供日期与查看、主要读数、区间、标题与实际选项及图例；总览保留原双层关联图。手机绘图区按宽度与矮屏等级稳定分配，不受上方卡片或临时状态高度影响，不缩放字形；能量读数显示整数，身体和kg差显示两位，数据与坐标范围不因悬停改写。

总览保留双层日期关联图：上层蓝色摄入线、红色消耗线，柔杏金盈余与雾蓝灰缺口填色；下层金色次晨变化，共用日期、选中线与命中区，缺测断开。默认选最近同时有摄入和消耗数值的一天，再回退至最近有记录日；手机7D、桌面30D，不足时扩大至容纳目标日的最短既有区间。能量线图按全区间留5%且至少100 kcal余量，整齐刻度与范围分开生成，kg轴独立包含零，选日不改变坐标。手机先显示三类同色完整快捷记录及摄入／晨重／消耗B卡片带；summary-cards.ts从实际结果准备各卡七日图形，进入摄入／晨重专页对齐日期范围。紧凑主图保留日期、收支、共轴双图和次晨结果，前后晨重及状态原因在当日详情查看；统计与显示选项、七日结果、覆盖与缺口不在手机首页显示；桌面保留两组读数和紧凑入口。7D／30D／90D／全部／自定义、键盘／触屏及详情保持，当天确认为已记完且摄入、消耗都有数值时计算盈余；营养部分未知或估算不额外阻止相减。未记全／未确认日保留摄入展示，不产生盈余。

状况摘要分别采用今天及以前最近的实际记录日期；摄入汇总该日有效餐次，消耗采用最近有效日记录或已完成运动，晨重采用最近实测。各类日期可不同，未知、部分和明确0保持区别。两端都在完整关系图之前展示摄入／晨重／消耗卡片，手机横滑、电脑自适应并排；图后不再重复摘要卡。三卡共用summary-cards.ts准备的七日图形和链接，进入专页对齐日期范围，不打开日期详情或编辑器。总览图形继续围绕所选日期，卡片不随悬停改写；跨零点不清空已有摘要。

`model.ts`负责业务聚合、盈余与严格相邻日配对；`presentation.ts`在服务端生成实际记录日期清单、两种估计显示口径及摘要。`overview-trend.tsx`负责区间、单日计算式与详情，`relationship-plot.tsx`绘制同一SVG中的双层图，`chart-geometry.ts`仅提供折线刻度、交点、分区、缺测段和淡出几何；不在客户端重算健康规则。样式在`overview.module.css`。kg与能量折线均使用本目录局部刻度，其他页面柱图仍从零开始。

网页保存和AI确认刷新总览，身份校验留在app。`model.test.ts`验证业务，`chart-geometry.test.ts`验证交点和缺测边界；浏览器入口为tests/energy.browser.mts，覆盖四种宽度、拖动、键盘、触屏、详情及减少动态效果。复用use-chart-motion.ts：首次加载直接呈现，主动区间变更保留短反馈，读数、坐标和命中区域不动，选日不重播。

界面修改及验收必读[设计文档](../../../docs/design-reference.md)。总览直接在图上选日，无独立日期导航；桌面点击保持日期，鼠标移动／离开不取消；未点击的悬停离开完整面板恢复默认日，Escape或换区间解除选择；移动到查看入口不丢日期。自定义范围应用后收起。手机图组常规268px／矮视口228px，减少刻度密度而不缩放文字或改变数据范围。首屏几何与截图检查见tests/overview-first-screen.browser.mjs。

总览共用四页100ms选日与4%底纹、1px辅助线及6px空心高亮圈，真实曲线和坐标不插值；次晨标题与读数合并在过渡区右侧，缺测只断线，不再绘制短横。两图尺寸及手机首屏要求保持。

顶部七天读数由model.ts为每个选中日准备，独立读取前6日支持数据，体重比较开始晨至结束次晨。presentation.ts补齐可查日历日以支持空日的七天统计，不写数据库占位。有效日先按原精度相加，最终按整数展示；缺失不当零。手机次晨变化显示在双图过渡处，七日统计仅电脑保留；电脑保留原六项与七日排法，依据直接显示。普通状态切换不移动筛选或图形，必要提示贴日期行。

日期详情复用meals/saved-meal-list.tsx，展示与饮食页一致的餐次、食物及附件层级；仅当天合计保留供能环图。超过三餐按需展开，跳转饮食仅在列表末尾保留一次，带正确日期；待确认改为合计附近的短状态入口。身体／消耗摘要与主图表保持。

首页标题、当地日期及三项记录入口由持久WorkspaceFrame提供。数据组件只准备真实卡片与趋势；跨午夜才刷新快照，初次设备／当地日期校正不再次导航。总览骨架复用卡片的双端布局与共轴双图。OverviewTrend在本人持久上下文中保存已应用区间、自定义范围和估计选项，返回按新快照展示，不恢复旧健康数值。
