# 总览

聚合饮食和身体事实，不拥有原始记录。model.ts 汇总当天有效餐次、最新真实空腹摘要及逐日历史；overview-view.tsx 保留今天四项摄入、餐次数、身体数值与实测日期、7日变化。overview-trend.tsx 将空腹体重、体脂和每日摄入三张图按真实日期对齐，共用范围和选中日期，分别读出当天摄入、当天空腹及次晨空腹。点击打开当日只读详情，可跳转对应日期的身体／饮食记录。

支持 7D／30D／90D／全部／自定义，桌面默认 30D、手机默认 7D，图表固定适配宽度。默认只显示实测；开关仅展示已存在估计，使用空心点与虚线，不生成估计、不把缺日补零、不移动次晨曲线。多候选不自动选代表，晚间记录不进入空腹趋势。日期随设备时区及跨日更新。全天消耗和活动尚未接入，energyBalance／activities 保持 null。

网页保存和 AI 确认刷新 /dashboard；身份和数据查询在 app 入口执行，计算复用 meals 和 measurements。model.test.ts 验证日期、软删除、零值／未知、独立指标和估计筛选；浏览器联动验收位于 tests/meals.browser.mts。
