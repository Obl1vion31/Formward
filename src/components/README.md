# Components

Inspector只处理面板自身的取消事件；子级文件选择器的cancel继续留在原编辑任务，不关闭面板或额外触发放弃草稿确认。面板中的手机食材选择与详情通过 InspectorStepContext 登记当前标题和返回动作。页面内返回、面板取消和遮罩先返回登记的上一层，退出本餐草稿时触发现有未保存输入保护。快捷录入的 EntrySurface 将相同能力传入实际表单。

等待外壳与真实内容共用布局。总览、饮食、消耗及身体共用整块图表骨架，底色与所属图框一致，光带由左向右扫过。数据与绘图尺寸就绪后，轴与实际图形同时呈现；失败或减少动态效果时使用静态底色。chart-legend.tsx、trend-axes.tsx和daily-records.tsx复用实际图例、关联趋势刻度与记录操作槽。workspace-loading.tsx保留首帧已知信息；未知数值与列表按真实读取就绪，训练月历先显示实际日期。相同条件的真实快照交给workspace-cache静默更新。普通页面导航在可执行的点击后率先展示目标外壳和选中态，路由提交后在同一容器交接；单次正文过渡与卡片关联转场各走原有入口。

local-loading.tsx在一次读取超过350ms后显示一处局部提示，位置由所属页面或面板确定。关联详情从正文露出开始计时，已有读数时提示留在仍待返回的明细区。LoadingLink跟踪实际导航，账号菜单关闭后的提示留在账号按钮。登录和提交使用所属控件的操作反馈。

总览和记录趋势整块未知时，workspace-loading.tsx 在同一位置首帧显示一个加载提示。带真实快照的局部读取保留延迟策略。task-guide.tsx在账号工作区维持主动打开的编号页面讲解，读取外壳与真实内容替换后保留当前步骤。page-tour.tsx只在当前可见页面实例查找目标，等待横滑吸附稳定后量框；滚动、尺寸与页面接管后重测。关闭、跳过和导航先结束导览，清除拦截与观察器；录入与保存不参与。

workspace-error.tsx使用当前Next.js的retry重新请求并渲染失败页面；reset只清除错误，不能用于服务端读取重试。快捷录入把同一个retry交给EntrySurface，失败时不再追加一次router.refresh；普通慢读取仍可单独刷新。缓存校验期间仅静态使用指引保持可点击和键盘操作，旧业务控件继续只读，旧内容不能作为最新高亮目标；缓存失败通过同一个retry重读并保留编号。

Inspector标题两端均直接排列在面板底色上，不增加独立圆角、内高光、模糊或负边距。电脑保留原侧栏尺寸和滚动，隐藏把手且不占位；手机通过ResizeObserver读取实际头高设置--inspector-sticky-offset，饮食与消耗的粘性区域复用该偏移，长表单滚动不盖住把手。手机把手区与面板底色连续，键盘焦点仅围绕小把手；关闭按钮保持44px。record-intent.ts集中校验网页view／edit／create打开意图，record-ui统一列表编辑实底与查看次级样式，业务组件决定各任务可用内容。

record-intent-client.ts将同地址再次点击交给当前已挂载业务，沿用LoadingLink的草稿确认及来源退出顺序；EntrySurface仅为重复create重开稳定外壳，三类业务重新打开对应内容。不拦截趋势、其他日期／来源／查询的正常导航，不存储健康快照或增加接口。

metric-card-rail.tsx在手机提供横滑及拖后点击抑制，电脑提供自适应网格；真实卡片与MetricCardRailPending共用外壳。trend-glyph.tsx复用2:1数据平面，metric-trend-model.ts只管绘图尺度和内部趋势链接校验。三类卡片两端共用已知日期、区间和真实趋势；7D与不超过7天的对应自定义区间图区最大宽640px、居中，30D／90D铺满，布局不依赖是否有转场来源；更长桌面区间保留完整图幅。nutrition-chart.tsx将设备分支放在绘图外壳，尺寸测量只随实际挂载节点运行，切换设备宽度后重新绑定。关联趋势页通过主导航、Logo或浏览器返回总览。

chart-transition.tsx管理三类趋势入口的真实目标地址、已知读数和返回意图。WorkspaceFrame用同一条约200ms的时间轴协调前后正文，workspace-motion.ts集中管理位移、透明度和取消。只在当前转场保留短暂的旧正文画面，退出后释放。顶栏和导航随可见页面更新。每次前进重置返回就绪标记；快速浏览器返回时，子级已完成的接管不能被父级重复开始覆盖，避免真实内容长期藏在只读快照后。

Inspector在手机提供底部面板：只读stableScroll详情默认半屏，录入默认近全屏，把手可拖动及点击切换。所有关闭路径仍经过同一个草稿/忙碌保护；正文自行滚动，桌面侧栏和compact确认框保持各自用途。工作区的读取反馈由 WorkspaceLoading 和 LocalLoading 在实际内容区域呈现。登录和独立动作在对应表单内显示反馈。

手机录入面板与助手通过 input-viewport.ts 读取系统键盘后的可视视口和焦点。Inspector 按实际可用高度布置面板，输入被标题或保存区遮住时只滚动面板正文。按内容增高的短面板关闭标题拖动。来源与其他锚定浮层使用 anchored-popover.ts 计算触发控件、可视视口及所在面板的交集，空间不足时让选项在浮层内滚动。面板完成视口布局后，同步通知所属浮层读取新坐标。双重验证和管理后台的独立页面按可视高度滚动到被键盘遮住的字段，嵌入弹框的表单继续由 Inspector 处理。

appearance-state区分用户选择system/light/dark与实际data-theme，早期初始化保留本机既有偏好；AppearanceSync在持久框架内保持系统监听，设置面板关闭后仍响应。AppearanceToggle在顶栏直接切换，FollowSystemAppearance提供账号菜单单个系统外观开关；首次使用与演练使用OnboardingAppearance，复用日／月切换、圆形揭示和轻量外观菜单的跟随系统选项。GlassMenu默认账号菜单，可为复用入口指定可访问名称。appearance-motion使用原生View Transition揭示真实主题，快速反向取消旧层及旧回调，失败／减少动态效果立即交接，不复制表单或重挂载页面。

form-draft.ts比较有效数字文本而不舍入，draft-guard.ts集中“继续编辑／放弃修改”。LoadingLink保留Next原有链接能力，站内导航先处理真实草稿；Inspector、内部返回和退出登录遵从相同判定。record-history.tsx使用显式日期查看表单，Enter与同日重复查看可用。主表单和独立搜索共用边框、底色和16px输入。紧凑录入的单层边界绘制在44px输入的中间36px，体重、体脂率和来源共用焦点、错误及禁用反馈。RecordRowAction 为记录列表及窄屏食材库提供44px触控区，编辑只在文字周围绘制32px浅底，查看以文字呈现。带单位的个人资料沿用一个外框。

`brand-logo.tsx` 和同名 CSS 模块统一 F＋手臂图标、formward 字标和金色圆点。图形用 `/icons/formward-mark.svg` 的透明遮罩跟随文字颜色；工作区的 `compactOnMobile` 在窄屏／触屏仅显示图标。可访问名称由外层图片语义或链接提供，内部图形与文字不重复朗读。


AnimatedRegion 提供食材行、核对明细与最近记录的原位开合。退场时可见内容随高度淡出，控件立即退出命中和焦点范围。DailyRecords 只在本人保存回执后强调可见的对应日期读数。
## 四页共用框架、确认和读数

record-trend-panel.tsx统一正文、日期与查看、主要读数、区间、标题与实际选项、图例和绘图区。InlineChartControls直接呈现单个勾选与占比切换，ChartOptions只放真正需展开的业务选项，自定义日期须应用才生效。数值、单位及完整标签共同决定列数，labelVariants／noteVariants按当前区间全部状态预留高度；reserveNote保留身体估计说明行，稳定id避免标签变化重新挂载。必要状态按当前区间的可能文字预留紧凑高度，无提示区间不占行。确认由confirmation.tsx与confirmation-state.ts集中排队、取消/Escape、焦点和滚动锁；没有挂载时不降级到浏览器确认。number-format.ts按业务显示蛋白质／碳水／脂肪最多一位小数并去掉末尾0、热量／消耗整数和身体两位；decimal-input.tsx的宏量输入最多接受一位小数，手填热量／消耗仍只收整数。格式化、聚焦和失焦不写回未修改原值，未知与0保持区别；热量计算与落库不提前取整，公开请求和查询精度保持。健康计算仍在各feature共用模型。

record-updates.tsx沿用现有变化检测并发出formward-record-context-stale供助手失效重查，提供跨页面更新提示，record-change-client.ts负责只读检查、保存前核对和本窗口保存确认；draft-guard.ts登记草稿供明确采用最新时保护输入。use-chart-drag.ts仅处理水平手势，竖向滚动交还页面。number-change.ts仅为身体、消耗与运动保留十倍／十分之一输入量级提示，不用于饮食或食材。

app-information.tsx提供首页与账号菜单共用的“更多信息”：手机按内容自然增高的底部面板、电脑compact居中窗，均以ImageGen定稿的七行三组为基准，初始显示完整入口；版本、更新说明、备案和联系一次展开一项。Inspector的fitContent用于指定的短面板和身体录入。移动端按内容增高，关闭共用草稿保护。app-information-content.ts集中真实产品版本、网站／ICP、公开邮箱、协议和帮助地址及简短更新说明；公安备案获批后再补号。app-update-state.ts合并手动检查与原自动提醒的在途请求，沿用/api/app-version的公开构建号；检查失败可重试，刷新共用草稿／忙碌保护。复制只包含公开版本或邮箱，失败可手动选择；协议及帮助打开新标签。

本目录保存多个页面共同使用的界面组件，例如按钮、输入、导航、日期范围和图表外壳。业务专用组件留在对应页面或 feature 附近，避免形成无边界组件仓库。

workspace-motion.ts只管理四模块普通导航的正文轻横移与淡变，方向来自workspace-pages顺序；WorkspaceFrame持久挂载同一容器，真实内容接管不重播。图形交接、日期详情、录入、同页刷新及初次打开不叠加，顶栏／导航与面板不在动画容器内。200ms、手机16px／电脑12px；快速反向从当前姿态续接，取消前撤销所有权，过期完成回调不影响新动画，减少动态效果即时完成。record-change-client的可选id校验防止同版本不同编号被误认；已知核对错误使用RecordVersionError供业务保留具体原因。

local-loading.tsx提供读取等待的共用反馈。已知内容和操作槽立即展示，真实请求仍在进行且缺少同条件内容时，350ms后在所属区域出现一条文字。读数和等待文本共用对应内容的位置。文字显隐沿固定行顶对齐，空行和单行提示的外框保持同高。长时间没有响应的入口可在原处重试。

`loading-link.tsx`包装Next.js Link并保留草稿保护、预取、新标签和下载语义。普通导航不登记全局等待；直接录入不预取，保存与真实任务继续使用原反馈。

`scroll-lock.ts` 为 Inspector、确认层、图片预览和手机助手共用滚动锁。首次锁定保存 html／body 原 overflow 和 body paddingRight，按 body 实际释放的宽度补偿。锁定期间保持工作区原滚动位置。最后一个持有者退出时恢复原 overflow 和 paddingRight。

维护时只接入真实异步状态，操作内容和错误处理留在对应 feature。颜色与减少动态效果规则在 app/globals.css，浏览器验收在 tests/page-loading.browser.mjs。


`use-local-today.ts` 根据设备时区显示今天，每分钟及页面重新可见时更新，服务端日期只用于一致的初始水合。

`use-mobile-mode.ts` 用 useSyncExternalStore 共用窄屏／粗指针触屏判断，覆盖触屏横屏；服务端快照为 null，避免水合时先显示桌面 30 日图或请求手机不需要的视频。设备模式变化后，已手动选择的图表区间保持。

`use-backdrop-dismiss.ts` 为饮食与身体 Inspector 共用遮罩手势判断。只有主指针按下、抬起均在真实遮罩且移动不超过 6px 才关闭；从内容拖出或拖选文字不关闭。关闭按钮、Escape、忙碌保护、焦点恢复和滚动锁由各弹窗继续管理。

`use-chart-motion.ts`供总览、身体、摄入及消耗SVG共用。首次真实柱形在约400ms内从零线伸出。折线约600ms在实测位置显点后描线。总览两层以约600ms同时从各自的零线伸出，离屏时等待进入视口。共享交接、悬停和缓存回看直接呈现，卸载及减少动态效果时取消动画。

关联趋势由 chart-transition.tsx 决定路由和实际读数的接管，workspace-frame.tsx 用前一正文与当前正文完成转场。真实图形与坐标及读数在同一个视图中绘制。返回按本次总览的位置恢复滚动和焦点。

use-chart-drag供四页共用横拖选择与纵向滚动判断；手指按下不立即选日，确认横拖或完成点击后才选中，拖动后抑制额外合成点击。

`chart-scale.ts`为各页面柱图提供独立的等距整倍数刻度，包含零并覆盖整个区间；kg步长至少0.1，空图使用固定中性范围，不随选中日期改变。总览能量折线的局部刻度在dashboard/chart-geometry.ts，不改变这里柱图包含零点的默认值。

`record-dates.ts`只推导最近7个日历日、今天／昨天标签、默认有效日期和容纳日期的最短区间，不创建记录或计算健康数值。`record-date-context.tsx`在饮食／消耗编辑器显示目标日期与补录状态；跨零点提示保持原草稿日期。

`source-input.tsx`与同名CSS模块提供身体、消耗及AI审核共用的来源输入、全部历史展开、搜索、键盘／触控选择与软移除交互；数据和移除接口由各feature提供，maxLength分别为300／200。候选使用真实按钮，触屏不取消pointerdown默认行为；输入框失焦且relatedTarget为空时不抢先收起，改由点击／聚焦外部、Tab离开、Escape及窗口失焦关闭。鼠标选择保留输入焦点，中文输入法确认不触发历史选中。

use-chart-date-selection.ts统一四页的鼠标临时预览、自定义期间暂停、完整面板离开恢复，以及键盘和触屏选择；鼠标点击后保持日期并忽略后续悬停，Escape／换区间解除；未点击的悬停离开后恢复默认，同日同输入方式去重，仅维护界面状态。chart-ranges.tsx复用区间按钮，日期输入保留在各模块的自定义表单。

 daily-records.tsx与record-ui.module.css统一日期行、查看入口及次要状态位置；record-history.tsx提供页面内日期查找与每批50行加载；daily-records.tsx在最近行下方提供展开／收起历史。单日查看或编辑才开Inspector，关闭保留列表加载状态及页面位置。主列表只显示今天，图表选日不改变列表；其他日期由RecordHistory在原位展开，每批50日，不计算健康数值。

 inspector.tsx与同名CSS统一侧栏、滚动锁、焦点、Escape／遮罩、输入保护和减少动态效果。身体页传入专用标题和内容，保留候选与晨晚流程；饮食旧EditorDialog导出仅为兼容现有调用，不再自建弹窗。

 draft-guard.ts 只登记当前弹窗未提交输入与上传状态，饮食／消耗及统一审核编辑器共用。关闭、Escape、真实遮罩及表单放弃按钮走同一确认，未改动直接关闭；刷新／离开页面使用浏览器原生保护，不将健康草稿写入本地存储。

Disclosure关闭时不挂载内容，只在展开后请求原图或显示较长的详情，避免总览和审核首屏加载全部附件。

use-chart-viewport.ts按实际坐标字体测量刻度宽度，统一总览、饮食及消耗的图宽与左边距；数据或区间换刻度时先完成测量，悬停不改变坐标。长整数不缩字、不裁切。


appearance-state.ts保存本设备主题的读取、早期初始化和跨窗口通知；appearance-switch.tsx提供顶栏日／月切换及账号菜单的跟随系统开关。颜色集中在app/theme.css，图表也使用同一语义变量，图片不反色。

app-updates.tsx仅检查构建版本，与record-updates.tsx的健康记录变化分开。可见时90秒、恢复前台检查；不缓存的版本接口不带身份或旧部署标记。草稿确认复用confirmation及draft-guard；approvePageRefresh只允许用户明确批准的这次刷新跳过重复离开弹窗，不存健康草稿。

DailyRecords、DailyRecordRow 和 RecordHistory 提供三页最近记录与历史展开。历史按钮与身体行内操作共用 32px 浅底和透明的 44px 触控区。展开后收起操作、系统日期控件与查询同排。未选日期时查询禁用，收起保留选中日期与已加载批次。业务页面不得用全局按钮规则覆盖这些控件。RecordTrendPanel支持六项读数按6／3／2退让、数值基线对齐；电脑图表标题、单位与图例同排，手机图例另行。控件边界使用主题control-border，深浅两套均须核对对比。

RecordTrendPanel的metricVariants传入当前区间已算好的各日读数字符串，按数字实际字体缓存最长宽度；测量订阅由实际内容键决定，不随外壳状态或数组身份重建。单次先读取尺寸再更新布局属性，相同属性不重复写入。MetricCardRail同样批量读取各卡宽度后才更新换行状态，避免逐卡读写强制整页重排。列数不随鼠标选日反复变化，换区间或窗口再测量。不生成或修改健康读数。

总览通过RecordTrendPanel的可选statusInDate将短提示放入既有日期行，其他页面默认行为保持。SelectedDateHeading的可选status只提供同排内容，不扩展业务计算。

chart-selection-marker.tsx及同名CSS集中管理ChartSelectionColumn底纹／辅助线／柱图短标记、ChartSelectionPoint空心高亮圈。永久SVG图层100ms（cubic-bezier(.2,0,0,1)）短过渡，中断时取消旧动画并续接当前视觉位置；列层位于数据之前、裁在绘图区，底纹与线使用同一变换。触屏、首次定位、区间／尺寸更换和减少动态效果直接就位，折线首次600ms／柱图首次400ms及主动区间切换动画仍由use-chart-motion独立负责；use-chart-date-selection.ts区分鼠标临时预览、点击保持、键盘焦点内选择与触屏持久选择。完整趋势面板负责离开及焦点边界，查看入口先捕获目标日期。


sliding-selection.ts 测量触屏胶囊当前尺寸，处理拖动、取消和吸附。路由、表单与选中语义由调用方提交。glass-controls.module.css 共用按钮内层材质与胶囊底片。独立按钮的命中区透明，默认和按下共用同一块可见面。三页记录使用 RecordRowAction 表达编辑与查看。账号和模型菜单使用 GlassMenuFace，从触发位置连续改变同一轮廓，内容单独裁入。实测支持背景像素位移的 Chromium 组合启用边缘折射，其余浏览器使用同轮廓的高遮蔽背景。小助手加号、模型只保留文字或图标及可见键盘焦点，发送和停止共用圆形底面。桌面主导航沿用固定槽位，用纵向底片指示当前页。共用规则见 [跨端控件材质与反馈](../../docs/design-reference.md#跨端控件材质与反馈)，真机和模拟结果见 [当前视觉验收](../../design-qa.md)。

record-detail-actions.tsx在已展开的餐次／运动中统一编辑及更多删除；删除保留业务原有确认，Escape先关闭更多并返回焦点，外部点击或焦点离开关闭菜单。Disclosure继续只在展开后挂载完整内容。

Inspector 的手机表头使用等宽操作槽。常规标题及 titleParts 居中，日期保持为完整文字块，长标题在中间列换行。子层的 backTo 提供完整返回名称，shortBackTo 在可用空间足够时显示。自定义表头通过 data-inspector-title-row 复用同一对齐，单个标题可直接用 h2，带附加内容的标题组使用 data-inspector-title。stableScroll 在手机两侧对称预留滚动空间；粘顶测量同时提供滚动与聚焦避让。桌面标题仍随侧栏排布。

workspace-loading.tsx复用正式卡片、语义色图例与图形槽位，首次未知图形只保留同尺寸框及局部等待；已有真实缩略图先到目标，数据接管不二次入场。WorkspaceFrame在目标正文暂时缺席时接续同页等待外壳，保留真实位置。图形往返仍由既有场景控制。导航不注册全局加载提示，保留8秒重试及保存／认证反馈。surface-motion显式区分sheet／drawer／anchored／center；底部面板直接从底部升起。Inspector的遮罩沿用面板开合时长，退场末态保持透明直到弹框关闭，具体背景由桌面／手机的业务样式决定。滚动和焦点只向打开弹框的同一页面恢复。

workspace-frame.tsx提供固定首页动作及桌面标题，手机返回并入DashboardHeader，不额外占行。EntrySurface先开录入面板，原表单portal接管并保留草稿上下文。Inspector自定义标题关闭按钮复用InspectorCloseButton；onSavedCloseReady仅在服务器确认保存成功后用于退出，普通关闭继续检查忙碌和草稿。饮食／消耗在同一Inspector中切换查看与编辑，不叠加两个dialog。

草稿登记、关闭回调和InspectorBusyContext在首绘前同步；portal转交忙碌Context，自定义标题使用同一关闭按钮，避免保存尚未完全结束时看似能关闭却没有反应。助手外壳固定在视口许可的高度，数据就绪只更新内部内容。

电脑饮食／消耗／身体的RecordTrendPanel读数复用现有主页／身体暖雾卡片材质、圆角、高光及阴影：常规横排，主卡内显示对应的真实供能环图、静息／活动比例或晨重小折线，语义色点与数值一致。等待外壳共用同一结构，宽度不足按整个区间的实际文字宽度稳定换行，不缩字；未知与0不伪造比例。手机普通页同样保留完整图表；紧凑记录优先只用于录入／编辑。

主导航第三项为训练，原消耗仍由同一导航分组进入，WorkspaceFrame为训练提供持续页面外壳和标题，不将其识别为身体页。训练与消耗的内容及图表语义保持独立。

训练与消耗加载态按目标路由呈现；消耗等待外壳与正式页共用RecordWorkspace、切换栏、日期、读数和EnergyPlotFrame首帧容器，设备识别期间沿用同一槽位。Inspector支持beforeClose异步保护，onSavedCloseReady在完整退出结束后才完成；退出距离按无变换静止位置与视口边界计算，快速反向保留当前位置。

训练、消耗拥有独立主导航项与准确页名，不再叠加重复切换栏；固定标题不依赖业务快照，保留关联返回、可访问页名与44px操作。

Inspector可通过motionDuration指定所属功能的开合时长；未指定时继续沿用既有面板时长。AI接入权限／管理面板使用160ms，减少动态效果时即时交接。

RecordWorkspace双端保留原有读数及完整图表，不增加替代趋势的手机摘要。DailyRecords日期和短状态同排，手机44px操作与紧凑摘要相邻，身体保留晨晚两行。Inspector将把手、标题、展开／半屏与关闭合并为紧凑手机头部，标题空白区拖动，粘性偏移通过ResizeObserver读取真实头高；EntrySurface饮食等待直接复用禁用的MealEditor，不用通用骨架替代字段。

饮食保存条通过ResizeObserver提供--entry-footer-height，Inspector的scroll-padding与实测头高共同避让粘性区域；文字放大后的焦点及显式滚动不落在标题或保存条后。共用录入输入使用1rem及相对行高／最小高度，正常16px／44px，200%自然增高。

DateField的可选displayLabel只改变可见日期说明，原生value、校验、焦点和选择行为不变；未传时继续显示原日期。消耗录入可显示“日期 · 今天”而不增加独立标题行。DateField为饮食／消耗提供单一可见边界，原生日期控件透明覆盖，焦点和禁用不重复描边；文字16px、44px命中。短饮食／消耗录入通过完整flex容器链将保存区贴底，长表单按实测底部操作高度滚动避让，不用空白或固定内容高度撑高。

图表轴通过use-chart-viewport同时观察容器与实际SVG刻度文字，字体放大时重新测量边距；饮食和身体按可用文字宽度减少日期刻度，不缩字或裁切。外框仍由共享CSS首帧确定。

图表刻度与卡片按实际字体和容器测量，字体已经就绪时不重复排入fonts.ready微任务；首次字体仍在加载时等待其完成，ResizeObserver继续处理尺寸、刻度与文字放大。返回总览恢复真实卡片带位置及焦点，缓存外壳留下恢复目标直至真实总览接管。

手机普通页主摘要与桌面完整读数共用真实数据，MobileRecordReadings按CSS断点从首帧确定布局；加载与真实值共用行盒。关联趋势只在真实目标图框里显示，首次未知区域保留布局，已知读数和趋势一起进入。Inspector同条件刷新保留挂载，不重置编辑；触屏滚动锁保存并恢复背景位置，键盘高度变化不叠加原生平移。

面向用户的热量单位统一显示千卡，组件仍接收既有kcal标识；不改变业务数值或接口单位。摘要卡加载时保留真实单位，数字占位使用相同字号与基线，防止读数接管时单位跳动。

录入数据慢读超过8秒或失败时，保留相同字段外壳，在原保存操作槽提供重新读取；不在表单之后追加整行重试。等待期间禁止保存，重试只读取，原面板定位与键盘处理保持。

录入底部操作的布局链覆盖手机与桌面，以及EntrySurface的portal挂载层；主要操作不因读取状态或权限接管变换槽位。MealEditor首帧通过命名容器确定布局，测量后处理实际长文字；未知识图权限保留禁用入口，避免两项／三项切换。

桌面图框统一320px（文字放大可增高）。7D最大640px居中，30D／90D铺满。同条件的等待图框可用本次总览真实趋势。首次绘制仅作用于数据图形，坐标、读数与命中区稳定。`use-nested-chart-range.ts`按日期移动共同图形，扩展区间时新柱从零线伸出，新实测点先显现并由较早日期描往较晚日期。临时图层可中断并按当前画面续接。

详情正文露出时，图形、适用的坐标轴、日期与读数留在最终布局。慢查询独立执行，350ms后在未知的读数或最近记录槽显示等待文字，同一内容原位接管。

返回总览时反向衔接正文。缓存视图可先显示，真实总览接管后恢复卡片滚动与焦点。等待期间的真实指针／键盘操作取消自动聚焦。新的导航、失败或减少动态效果立即释放临时正文。

总览状态卡以真实数值与单位的max-content行盒测量宽度，不用DOM Range跨文字和子元素的包围框；Activity隐藏时宽度0不登记为窄卡；恢复后在同一layout阶段按真实宽度完成换行。预备缓存与实际总览采用相同的换行判断，返回首个可见帧不能增高一行。返回焦点从意图开始保留到真实卡片接管，动画取消或慢读取不能丢失；用户主动转移焦点时仍停止自动恢复。

`use-nested-chart-range`让身体、摄入和消耗在 7D／30D／90D 间按真实日期衔接。临时图层只负责可见标记过渡，坐标轴、命中区、读数和键盘选择使用实际区间。快速切换从当前标记位置衔接，减少动态效果即时换区间。

有序切换复用 workspace-motion 的方向判定与时间轴。顺序变化才启动正文横移。已绘制的照片成对交换，前一张与目标张均可接续正在显示的姿态。减少动态直接交接。
