# Formward 1.0 手机首发

Formward 帮助受邀用户记录饮食、身体、消耗和训练，查看真实记录及趋势，用助手整理内容，再由本人核对保存。首版面向华为应用市场中国大陆，免费下载，版本 1.0.0，包名 top.formward.app。

使用现有账号、上海数据库和 formward.top。新应用不复制一套用户资料，不更换既有 Garmin 连接，不申请华为运动健康权限；已保存记录继续按账号隔离。网页登录、OAuth、HTTP 与 MCP 业务协议保持兼容。

首次打开先阅读本地隐私说明，选择同意后才连接网站。手机沿用已确认的网页界面和导航。系统层补齐选图、文件选择、拍照入口、导出到本人选定位置、返回、键盘和后台恢复。系统选择器只交付用户本次选定的文件，不获取整本相册。

助手文本明确标识 AI 生成，复制回答保留标识；识图的文字与记录结果需要本人核对。模型产生预览不等于正式保存。取消选择、收起、后台恢复和正常重试不得暗中产生重复记录或重新收费的模型请求。营养未知和实测缺失保持未知，不补零。

首发保留邀请制。审核使用独立的普通账号与虚构记录，不提供管理员权限或运营者的私人数据。测试库、模拟器测试包和模型回放明确标注隔离环境；测试通过不等于真实识别准确度、真机验证或商店审核通过。

完成条件是签名 Release 包、备案和必要资料齐备，提交审核后在商店可下载安装，并通过首次完整使用。构建、提交和上架分别记录；未完成的本人验证、签署及真机测试不能写为已通过。实时状态见 ../../docs/harmonyos-release.md，视觉与操作标准见 ../../docs/design-reference.md。
