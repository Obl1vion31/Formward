## 已保存的介绍文案

一句话简介：记录饮食身体，查看每日趋势。

Formward帮助你记录饮食、身体指标、每日消耗与训练，查看自己的记录和阶段趋势。可以手动录入、修改和查看数据，也可以在账号可用额度内使用小助手整理文字或照片，核对AI生成的预览后再确认保存。AI估算和建议可能有误，请自行核对，应用不提供医疗诊断。支持将本人记录导出为Excel，并可选择连接本人的Garmin Personal数据来源；首版暂不接入华为运动健康。当前采用邀请制，需已有或受邀账号登录。不同账号的数据独立保存，使用现有Formward账号即可访问自己的记录。
