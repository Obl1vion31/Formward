首发华为应用市场中国大陆，免费下载，版本 **1.0.0**，包名 `top.formward.app`，沿用已有 APP ID `6917621421857049870`。ArkUI 与 ArkWeb 混合应用保留邀请制、上海数据库、记录、趋势、小助手和 Garmin。华为运动健康留待后续版本。

## 源码、构建与手机边界

`apps/harmonyos` 为客户端源码，`D:/Projects/FormwardHarmony` 是 DevEco 构建工作区。`scripts/harmonyos/sync-build.ps1` 同步源码白名单，使用已安装的官方 DevEco 26 工具链；保留本机签名、IDE 设置和依赖，不回传私有配置。未签名 Release 产物为 `build/outputs/default/FormwardHarmony-default-unsigned.app`。源码、产物、摘要及证据私有归档，签名私钥不进 Git。

本地隐私选择通过后才创建远程业务页；协议页不运行 JavaScript。有效会话从 `/dashboard` 恢复，未登录沿用现有登录。可信业务源为 `https://formward.top`，外部 HTTPS 链接交给系统。桥只交接外观及返回状态，不传密码、连接凭据、健康记录或文件正文。系统返回与网页草稿保护共用原逻辑，重复返回不叠加交接。

照片使用 ArkWeb 系统选择器。导出沿用 ArkWeb 认证下载，再交给系统保存位置选择器；只接收可信源的 xlsx、csv、tsv，最大20 MiB，最多两个在途任务，完成、取消或失败后清理本次临时文件。首版仅声明 INTERNET，不提前申请相册、相机、通讯录、定位或健康权限。系统选择器中的拍照能力仍需在兼容真机验证。

## 上架材料与本人节点

华为控制台现为“准备提交”，软件包列表为空。DevEco上传产品需要单独登录华为账号；当前未完成该登录。官方工具链支持云端管理发布证书与Profile，仍须在本人登录后核对实际可用方式。取得最终签名公钥与指纹后再办理腾讯云 APP 备案，不使用调试证书替代。

网站备案已核实为正常，APP 备案列表为空；网站备案不等于 APP 备案。备案实名核验、验证码、本人签署与新绑定协议由本人完成，证件号不进入仓库或聊天。控制台默认全球分发及境外授权不能直接提交，应按已确定范围改为中国大陆。

送审还需实际应用截图、介绍、隐私标签、普通审核账号、AI声明及实际要求的版权材料。审核账号只含虚构记录，无管理员权限或运营者私人数据。新版本保留邀请制，审核说明需写明真实登录路径和可体验范围。

AI声明为“涉及／文本”。识图输出文字及结构化记录，不因此申报图片生成。回答与复制已有显式标识；Excel可能包含经本人确认的AI辅助记录，不能笼统声明没有任何AI相关导出。按当前平台要求准备标识截图、说明及服务资质，不伪造备案号、证明或权利人签字。版权证书具体要求需结合当前分类、控制台和审核意见核对，不把一般推荐条款当成统一必选。

材料齐全并完成最终签名包、真机验证后，再按授权上传并提交。分别记录提交时间／版本／状态和正式上架结果；最终完成需要商店下载安装及首轮完整使用通过。
