# Formward 实现盘点与清理验收

首轮以主线 8b7f32c 和正式运行包 dual-entry-59e5fc73-overview-chart-layout-20261120 为基线。两者之间只有部署与验收记录。盘点以仓库的 25 个页面和 32 个 HTTP 处理入口为索引，跟踪 16 个业务目录中的共用职责，并核对最近的双入口发布。页面、API、Server Actions 和工具入口有交集，数量分别统计。

第一批 850 项单元与集成测试通过。最终包 851 项通过，三个候选均通过 lint、typecheck 和生产构建。应用运行包摘要和公网发布记录保存在原项目的 `.codex/backups/regional-releases` 下，当前版本见[部署记录](deployment.md)。

末批首次切换命中备份服务的启动频率限制，自动恢复上一正式版。核对网页、聊天 worker 和备份上次成功状态后，清理该单元的失败计数，用同一验收包重新执行正式备份和切换。原生校验、异地回读和正式库摘要均通过。

首轮按入口和模块定位。列入本轮的四项已清理。键盘定位、发送时机和活动趋势的路由接管分别有实际职责，暂未发现等价替代实现。旧客户端、历史审核 URL 和历史数据继续由现有兼容路径处理。实体 iPhone 的原生键盘与相册体验未在本轮实测。
