# Formward 实现盘点与清理验收

首轮以主线 8b7f32c 和正式运行包 dual-entry-59e5fc73-overview-chart-layout-20261120 为基线。两者之间只有部署与验收记录。盘点以仓库的 25 个页面和 32 个 HTTP 处理入口为索引，跟踪 16 个业务目录中的共用职责，并核对最近的双入口发布。页面、API、Server Actions 和工具入口有交集，数量分别统计。

## 批次与验收

1. 前端先清除两处确认项，对比正式包和候选包的实际页面。运行 lint、typecheck、单元与集成测试、生产构建，检查两个浏览器引擎和原始转场记录。
2. 正式部署复用脚本单独验收，从旧包核对、准备、激活前检查、同一包上线到验证均保留独立证据。先用隔离场景核对停写、失败和回退，再执行正式发布。
3. 活动键盘与发送、活动趋势交接、历史审核和协议保留在待核查条目中。每条须有等价证据才从清单进入实施。目前完成的是入口与职责首轮覆盖，无法据此估计尚未发现的重复项数量。

原始截图、动态记录、运行包摘要与正式验证报告保存在项目私有验收目录。正式版本及兼容回退见[部署记录](deployment.md)。
