# Excel 数据导入

## 来源位置

原始工作簿保存在本地 `data/imports/`。文件保持原样，不放入 `public/`，也不提交到版本控制。

工作簿包含饮食明细、运动明细、每日汇总、使用说明和趋势看板。趋势看板是展示结果，不作为事实导入。

## 流程

```text
选择文件
→ 只读解析
→ 映射饮食、运动、测量和日期状态
→ 校验与重复识别
→ 展示预览和问题
→ 用户确认
→ 事务写入
→ 输出结果报告
```

## 关键规则

- Excel 日期转换为业务日期，明确指定的跨午夜归属保持不变。
- 正常饮食进入汇总；无法计算的记录保留描述，未知营养字段为空。
- 尚未确认完成的运动保持计划状态，不计入运动消耗。
- 显式热量保留，不强制用三大营养素覆盖酒精等额外供能。
- 公式缓存值仅用于核对，汇总由 Formward 重新计算。
- 已知异常体脂值 `1461.8%` 必须进入错误报告。
- 文件摘要、工作表和来源行共同参与重复识别。
- 原始文件不因导入成功而被修改或删除。
