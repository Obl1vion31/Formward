# 页面方案

本文件记录页面方向以及已确定的内容与交互。产品范围由 `product.md` 决定，阶段顺序见 `milestones.md`。尚未讨论的页面不提前固定字段和构图。

## 首页与登录入口

首页是访问 Formward 时的登录入口，不提供公开注册。当前表单是视觉预览；账号能力接入后才会提交凭据。

### 画面与交互方向

- 页面采用深石墨色中央舞台，人物躯干后方有透明度 11% 的微弱暖金环境光，叠加透明度 3.5% 的宽幅暖光；侧下方保留极淡 petrol 环境色。环境层静止，主界面仅使用暖象牙白、哑金和深石墨色，petrol 不用于文字或按钮。
- 第一屏保留左上角文字 Logo、居中人物和人物右侧腰部附近的`SCROLL` 提示。文字 9px、哑金，整体透明度 55%，旁边是 14×20px 的细线鼠标轮廓；滚轮每 1.6s 上下移动 3px。位置随人物显示高度计算，与首帧人物约隔 32px，限制在视口内；提示不跟随人物视差。现有人物显示高度、Frame 1 构图和逐帧校准保持不变。
- 提示仅在图片解码完成、INTRO、宽度超过 700px 且支持 hover 的细指针设备显示。停在 INTRO 时持续显示，鼠标移动及未触发播放的滚轮或键盘操作不会隐藏；离开 INTRO 后 120ms 淡出，倒放完整回到 INTRO 后恢复。解码前操作不影响以后回到首屏时的提示显示，触屏与窄屏不显示。加载与失败信息独立保留，提示不承担鼠标点击操作。
- 人物外层使用 1600px 透视，变换中心位于舞台 50% / 32%。INTRO 鼠标反向位移上限为水平 6px、垂直 4px，朝鼠标方向的倾转上限为 rotateY 0.6°、rotateX 0.3°；背景、Logo、提示和表单保持固定。跟随时间常数 90ms，停止 180ms 后用 600ms smoothstep 回中。鼠标离开舞台时回中，归稳后停止 rAF；窗口失焦、页面隐藏或关闭联动能力时立即归零。
- 正放、倒放和 FINAL_TRANSITION 停止接收鼠标目标，100ms 内回中。LOGIN_READY 尚未聚焦输入框时为首屏半幅，首次聚焦 Email 或 Password 后在 180ms 内回中并锁定整个登录阶段；自动聚焦同样触发。切换字段、失焦、点击空白或移向 ENTER 均不解除，只有倒放完整回到 INTRO 或进入 FINAL 才解除。FINAL 只在输入框无焦点且有新鼠标移动时恢复半幅；倾转只作用于 PNG 图层。
- 表单在液态尾部上方居中，肩背和腰线保持露出。桌面宽度最多 340px，手机最多 320px；中心分别位于舞台高度的 64%、67%，视口高度不超过 640px 时为 66%，不超过 480px 时为 70%。只显示 Email、Password、两条输入下划线和 `ENTER`，没有标题、说明、品牌重复信息或箭头。
- 衬底采用边缘渐隐的暖烟色玻璃，底色为 `rgba(28, 26, 22, .82)`，背景模糊 10px，没有外框或厚重阴影。标签为 12px 象牙色，输入值为 16px，输入下划线透明度为 42%。ENTER 为 15px、600 字重的哑金文字，下方保留 42px 短细线；整行点击高度至少 44px，背景透明。禁用态透明度为 80%，填写完整后启用，hover 时变为象牙色。
- 舞台以 100svh 固定在视口内，滚动区域约 155vh。滚动只选择方向，不拖动帧进度；一次明确下滚触发约 425ms 的 1 → 12 自动播放，上滚触发约 425ms 的 12 → 1 自动倒放。手势结束后继续播放，同方向惯性不重启时间线。反方向累计超过阈值时，立即从当前连续时间游标反向，无需先到端点；剩余时长为 425ms 乘以到目标的进度距离。
- 滚轮在 250ms 内同方向累计约 44px 后触发；移动端单指上滑约 40px 正放，下滑约 40px 倒放。手指尚未松开也可改变方向。方向监听在 Enter 开始最终过渡后移除。
- 人物帧绝对定位在同一个容器中。1–12 的 11 个段长依次为 38 / 36 / 34 / 32 / 30 / 30 / 32 / 38 / 45 / 52 / 58ms，启动快、中段最快、最后三段逐渐收住。`animationProgress` 为线性时间游标，不再使用整段缓动；倒放原路返回。每段前部停留，末尾 16ms 按 smoothstep 互补权重混合相邻帧，最多同时出现两帧。人物容器使用 `isolation: isolate`，帧使用 `mix-blend-mode: plus-lighter`，先在透明组内合成，再叠到舞台背景；Login 与背景位于该组之外。正放、倒放、reduced motion 和最终过渡使用同一合成方式，避免交叠中点变暗。
- Login 的 opacity 与 translateY（16px → 0）直接映射同一 `animationProgress`。前 60% 时间保持隐藏，接近背面时在最后 170ms 浮出，Frame 12 完整进入；倒放同步隐藏，中途反向也保持连续。表单本身不缩放或模糊。
- Frame 12 完整显示后进入 LOGIN_READY，表单才可操作。Email、Password 非空且点击 `ENTER` 后，确保人物外层完全归零，再独立以 700ms 交叉过渡到 13，并带轻微 scale（0.98 → 1）和 blur（3px → 0）。若提交时 180ms 回中尚未完成，立即归零后开始，不增加等待时间。FINAL_TRANSITION 和 FINAL 都拒绝方向输入，最终帧保持到刷新。
- `src/app/frame-config.ts` 集中定义 `PRE_LOGIN_FRAMES`、`FINAL_FRAME` 和每帧桌面、移动端对齐值；图片尺寸由静态导入读取。1–12 以 Frame 1 为基准，等比缩放与平移优先稳定头顶和躯干，尾部保留自然变化；原图、帧顺序与 Frame 13 对齐值不变。测量、拟合和残差见 `frame-calibration.md`。12 帧使用显式时间节点，其他帧数使用等间隔兼容映射。
- 全部 13 张 PNG 设置 Next.js `preload`；实际图片全部解码前保持 Frame 1，加载期间记录最近方向，就绪后自动执行。图片加载失败时显示刷新提示。
- 素材包含 Alpha；不同图片的构图、分辨率和自身光晕差异仍影响画面一致性。

### 可用性边界

- 表单在桌面和窄屏下保持可读，输入与按钮有清晰的键盘焦点。
- 键盘聚焦时显示“进入登录”入口，点击或 Enter / Space 可触发同一正放时间线，完成后聚焦 Email 并锁定人物回中。页面方向键、PageUp / PageDown、Home / End 和 Space 支持双向触发；输入框、按钮及可编辑内容中的键盘操作不会切换动画。手机键盘改变视口不会自动倒放。
- 触屏、宽度不超过 700px 和 reduced motion 均关闭鼠标视差。reduced motion 下鼠标提示静止，离开首屏时隐藏无动画；正放、倒放以 180ms 首尾 crossfade 简化，Login 全程仅淡入淡出，Enter 为 240ms，不播放连续转身或位移、缩放、模糊效果。
- Email 与 Password 仅保留在页面组件状态；倒放后输入不会丢失。点击 Enter 只播放 12 → 13，不发送请求、不保存凭据。
