# 页面方案

本文件记录页面方向以及已确定的内容与交互。产品范围由 `product.md` 决定，阶段顺序见 `milestones.md`。尚未讨论的页面不提前固定字段和构图。

## 首页与登录入口

首页是访问 Formward 时的登录入口，不提供公开注册。表单通过 Better Auth 验证账号，账号由内部管理员创建。

### 画面与交互方向

- 页面采用深石墨色中央舞台，人物躯干后方有透明度 11% 的微弱暖金环境光，叠加透明度 3.5% 的宽幅暖光；侧下方保留极淡 petrol 环境色。环境层静止，主界面使用暖象牙白、哑金、暖灰和深石墨色，petrol 不用于文字或按钮。
- 首页采用“数字雕塑 + 编辑式界面”。素材就绪后，人物下层的独立轨道图层显示同级单行的 Discipline / NUTRITION、Drive / BUILD YOURSELF、Effortless / AI LOGGING。主词采用本地 Newsreader 正体 400、自动光学尺寸、0.035em 字距、1.2 行高和 `clamp(20px, 1.68vw, 26px)` 字号，颜色为暖灰白 `#d0c8ba`。副标签保留本地 IBM Plex Mono 400、9px、大写样式、0.13em 字距和哑金 `#aa9574`；Logo 和产品 UI 沿用 Avenir Next / Segoe UI / PingFang SC / sans-serif。字体与许可证本地分发，Manrope 不加载。
- 桌面轨道使用倾斜椭圆与透视投影，初始相位分别为 210°、330°、450°，沿人物同一 500ms 进度增加 150°。参考舞台为 1440×900，中心为 (792,450)，两根空间轴为 (288,-135,160)、(316.8,252,-240)，透视距离为 2400。终点节点约为舞台 76.4% / 33.9%、63.1% / 78.3%、24.3% / 32.3%；文字向外排布，保持 Discipline 右上、Drive 右下、Effortless 左侧。
- 节点、引线与 240° 开口弧段共用投影坐标；轨道为棕金 `#77664d`，近段透明度 16%、远段 7.5%，引线 30%，线宽 0.8px，节点 5px。统一标注结构为上方节点与水平引线、下方两级文字：文字顶部距节点水平线 12px，引线与最近文字边缘间隔 12px，常规引线长 24px，响应式避让时伸缩。左侧标注向右对齐、右侧向左对齐，跨中轴时连续插值文字偏移与引线方向。文字始终朝向读者，以 0.95–1.05 的缩放和轻微明暗表现远近；完整标注在视口内避让。图层不接收指针事件，不随人物鼠标移动，不参与人物的 `plus-lighter` 合成。视口与字体变化后缓存尺寸，不逐帧读取布局；转身最后 200ms 平滑将文字向外排布，为居中表单留出至少 24px 间距。
- 登录终点的标题相对亮度降至约 70%–76%，微标签至少保留 84%，轨迹降至原来的 75%。LOGIN_READY 与 AUTHENTICATING 保留终点，认证失败不退出；成功后随 700ms（reduced motion 为 240ms）最终人物动画淡出。加载、失败和 FINAL 隐藏；辅助技术只读取一份文案，装饰场景隐藏于辅助技术。
- 宽度不超过 700px 时，三组文字在底部安全区上方 16px 横排，左右各留 20px；Newsreader 主词均为单行 14px、副标签为 8.5px。隐藏空间弧线，用棕金细轴与等距节点连接主词，整个转身和登录阶段位置不变，只适度减弱；键盘入口获焦时底部间距为安全区加 110px，位于词组上方。reduced motion 在桌面交叠两套静态轨道构图 180ms，不产生空间旋转；手机保留静态网格。英文图层标记 `lang="en"`。
- 第一屏保留左上角文字 Logo、居中人物，`SCROLL TO ENTER` 收在左下角，左边距固定为 7%，底部间距为 `clamp(24px, 5.8svh, 52px)`。提示使用 IBM Plex Mono、8.5px、暖金与 75% 透明度，旁边是 1×26px 细轨道和 7px 动标；动标每 1.6s 轻移 12px。提示不跟随人物视差，现有人物显示高度、Frame 1 构图和逐帧校准保持不变。
- 提示仅在图片解码完成、INTRO、宽度超过 700px 且支持 hover 的细指针设备显示。停在 INTRO 时持续显示，鼠标移动及未触发播放的滚轮或键盘操作不会隐藏；离开 INTRO 后 120ms 淡出，倒放完整回到 INTRO 后恢复。解码前操作不影响以后回到首屏时的提示显示，触屏与窄屏不显示。加载与失败信息独立保留，提示不承担鼠标点击操作。
- 人物外层使用 1600px 透视，变换中心位于舞台 50% / 32%。INTRO 鼠标反向位移上限为水平 6px、垂直 4px，朝鼠标方向的倾转上限为 rotateY 0.6°、rotateX 0.3°；背景、Logo、提示和表单保持固定。跟随时间常数 90ms，停止 180ms 后用 600ms smoothstep 回中。鼠标离开舞台时回中，归稳后停止 rAF；窗口失焦、页面隐藏或关闭联动能力时立即归零。
- 正放、倒放和 FINAL_TRANSITION 停止接收鼠标目标，100ms 内回中。LOGIN_READY 尚未聚焦输入框时为首屏半幅，首次聚焦 Email 或 Password 后在 180ms 内回中并锁定整个登录阶段；自动聚焦同样触发。切换字段、失焦、点击空白或移向 ENTER 均不解除，只有倒放完整回到 INTRO 或进入 FINAL 才解除。FINAL 只在输入框无焦点且有新鼠标移动时恢复半幅；倾转只作用于 PNG 图层。
- 表单在液态尾部上方居中，肩背和腰线保持露出。桌面宽度最多 340px，手机最多 320px；中心分别位于舞台高度的 64%、67%，视口高度不超过 640px 时为 66%，不超过 480px 时为 70%。静止时只显示 Email、Password、输入内容和 `ENTER`，没有标题、说明、品牌重复信息或箭头。
- 衬底采用边缘渐隐的暖烟色玻璃，底色为 `rgba(28, 26, 22, .82)`，背景模糊 10px，没有外框或厚重阴影。标签为 12px 象牙色，输入值为 16px；底线保留 1px 透明边框占位，可操作字段 hover / focus 时在 180ms 内显现为哑金，失焦且未悬停时退去，禁用字段不响应悬停。键盘保留清晰焦点框，触屏点击标签或字段即可聚焦，reduced motion 即时改变底线。ENTER 为 15px、600 字重的哑金文字，下方保留 42px 短细线；整行点击高度至少 44px，背景透明。禁用态透明度为 80%，填写完整后启用，hover 时变为象牙色。
- 舞台以 100svh 固定在视口内，滚动区域约 155vh。滚动只选择方向；一次下滚触发完整 500ms 视频（2 倍速），上滚沿同一进度自动倒放。手势结束后继续播放，同方向惯性不重启；反方向超过阈值时从当前连续进度反向，剩余时长按到目标的进度距离计算。
- 滚轮在 250ms 内同方向累计约 44px 后触发；移动端单指上滑约 40px 正放，下滑约 40px 倒放。手指尚未松开也可改变方向。方向监听在 Enter 开始认证后暂停；认证失败时恢复，成功后的最终过渡与导航期间继续关闭。
- 人物由静态首尾、视频 Canvas 与独立最终图组成，均绝对定位。视频有额外留白，按头顶和尾滴匹配静态端点并平滑调整大小及位置。视频黑底使用 WebGL 转为透明；两端各 40ms 按 smoothstep 交叠，人物组仍使用隔离的 `plus-lighter` 合成，背景与 Login 不参与。
- Login 的 opacity 与 translateY（16px → 0）映射同一 `animationProgress`；前 60%（300ms）隐藏，最后 200ms 浮出。倒放同步隐藏，中途反向连续，静态第 12 张完整显示后才允许提交。
- Frame 12 完整显示后进入 LOGIN_READY，表单才可操作。Email、Password 非空且点击 `ENTER` 后，先进入 AUTHENTICATING 验证账号；成功后确保人物外层完全归零，再独立以 700ms 交叉过渡到 13，并带轻微 scale（0.98 → 1）和 blur（3px → 0）。若提交时 180ms 回中尚未完成，立即归零后开始，不增加等待时间。AUTHENTICATING、FINAL_TRANSITION 和 FINAL 都拒绝方向输入。最终透明度动画的 animationend 触发后导航到 `/dashboard`，不提前跳转；认证失败回到 LOGIN_READY 并显示中文提示。
- `src/app/frame-config.ts` 保存原始 1、12、13 的静态导入与原有桌面、移动端校准；`turn-video.ts` 保存 60 帧视频配置、寻帧和透明合成。`PRE_LOGIN_FRAMES` 只包含静态两端，第 13 张继续保持独立。
- 三张静态 PNG 通过 Next.js `preload` 提前加载并解码；视频使用 `preload="auto"`。全部素材就绪前保持原始首帧，加载期间记录最近方向，就绪后自动执行。图片或视频失败时显示刷新提示。
- 静态素材包含 Alpha，视频的黑底通过透明合成去除；首尾原图的光晕与视频细节存在差异，因此在两端保留短交叠。

### 可用性边界

- 表单在桌面和窄屏下保持可读，输入与按钮有清晰的键盘焦点。
- 键盘聚焦时显示“进入登录”入口，点击或 Enter / Space 可触发同一正放时间线，完成后聚焦 Email 并锁定人物回中。页面方向键、PageUp / PageDown、Home / End 和 Space 支持双向触发；输入框、按钮及可编辑内容中的键盘操作不会切换动画。手机键盘改变视口不会自动倒放。
- 触屏、宽度不超过 700px 和 reduced motion 均关闭鼠标视差。reduced motion 下鼠标提示静止，离开首屏时隐藏无动画；正放、倒放以 180ms 首尾 crossfade 简化，Login 全程仅淡入淡出，Enter 为 240ms，不播放连续转身或位移、缩放、模糊效果。
- Email 与 Password 仅在页面组件状态中保留；倒放后输入不会丢失。点击 Enter 将凭据提交至认证接口，密码不保存到浏览器持久存储。认证中与最终过渡中禁用输入和提交。错误密码、限流、网络故障可重试，只有成功验证才播放最终动画。

### 登录后的主页

- `/dashboard` 每个请求验证当前会话，未登录、过期或撤销后返回登录入口。页面只采用经过认证的 user_id，不采用 URL 中的账号标识。
- 当前页面沿用深石墨、暖白与哑金，显示邮箱和退出按钮。有身体记录时展示最新空腹摘要、空腹主趋势、最近晨晚记录和历史抽屉；无记录账号显示简短空状态。饮食、运动与热量报表尚未实现。
- 退出登录撤销自己的会话，完整导航回登录页并清空当前客户端页面缓存。

目标是以报表为登录后的第一页，提供当日、昨日或最近状态汇总。主区域逐步增加热量盈余曲线，各自保留 kg、% 和 kcal 刻度。每日分析区分 D 日晨晚差对照 D 日盈余，以及 D+1 日空腹变化对照 D 日盈余；提示明确实际测量时间和分析归属，不作确定因果解释。

训练计划、热量消耗等内容按后续能力接入，当前页面不放未实现模块的占位。未授权补全的缺测保持空值，极淡同色点线跨越已有端点；图下焦点提示保持固定单行，长内容省略，移开焦点不会推动详情按钮。估计值统一使用简短标识，详情以数值、真实依据与样本日数为主。历史初始化与日常估计的规则集中在图表开关旁说明，工程与审计元数据不进入用户阅读界面。热量盈余须先确定全天总消耗口径，不能用摄入减记录的运动或仅减基础代谢替代。

### 身体指标记录

页面顺序是身体记录标题与指标切换、当前空腹及 7 日摘要、全宽空腹主趋势和最近记录。实测与估计共用右侧记录 Inspector，手机占满屏幕；点击后直接进入对应详情。沿用石墨、暖白、哑金和蓝灰，摘要为四组无边框文字，主数值突出，日期、表头和单位保持可读。默认主要内容以约 1–1.5 屏为目标，技术验证与用户视觉认可分别记录。

体重和体脂率均为高值在上，最小可视跨度分别为 3 kg、3 个百分点。晨间空腹形成金色主线，晚间形成较淡蓝色折线，默认都显示，可关闭晚间。实测为圆点；授权补全为菱形，经过估计端点的线段为虚线，图例注明估计。未补全缺口使用极淡同色点线，未解决真实候选处断开。异常晨晚读数保留，日历轴维持真实间距。

日期视角统一为 7D／30D／90D／全部／自定义，默认截至最新记录归属日的 30D，滚动区间包含截止日。起止日期常驻显示：桌面为完整日期，手机将年份与月日范围分两行，跨年同时显示两端年份，与日期按钮同排，开关及估算规则在下一行。日历按钮打开自定义日期表单；起始晚于结束或非法日期不能应用。切换预设回到截至最新记录的相应区间。全部使用所有记录的最早／最晚归属日。图表适配屏幕宽度，长区间仅显示少量日期刻度，完整日期和数值可通过悬停、点击或键盘聚焦读取，单日区间居中显示。手机焦点提示与图例共用固定高度，显示当前点提示时覆盖图例，不改变页面布局。

晚间／估计开关和指标／日期切换保留图表尺寸，避免短暂横向压缩或移动；窗口缩放时重新适配实际可用宽度。悬停与聚焦提示只显示当前可见记录及当前指标的内容。

摘要跟随体重／体脂指标切换，依次显示当前值、7 日内变化、7 日均值与另一指标当前值。当前仅取该指标最新有效实测空腹代表记录并标明日期，独立于图表历史区间；另一指标使用自己的最新有效空腹日期。7 日窗口包含截止日及前 6 天，变化为实际首末差，不足两个记录日显示 —；均值只计真实有值日期、每天最多一条，显示如 2/7 天的覆盖情况。体重变化单位为 kg，体脂变化为百分点；本阶段不画移动均线。

图表和最近记录共用趋势指标、区间与代表选择；Inspector 默认进入所点指标，可独立查看同条记录的其他指标。最近记录按归属日倒序显示当前区间最新 10 个有记录日期，不生成全空行，缺项为 —。表格与图表内容区域等宽，固定日期、晨间、晚间、差值四列，桌面各占 25%；手机依次为 28%、25%、25%、22%，日期与星期分两行。日期左对齐，其他列右对齐，表头、数据与细行分隔线统一；估计在数值下方用小号“◇ 估计”，不重复长来源标签。行高至少 44px，不增加厚重边框、竖线或外框卡片。

晚间开关只改变图，不改变晨晚表或差值。估计开关默认开启，关闭后图、最近记录和日期入口只显示实测，完整历史仍保留全部。估计点明确标注并保留两位小数；按指标真实值优先，可同时展示真实体重与估计体脂。晨晚差只取同日真实、条件明确的配对，含估计则留空。

图表实测／估计点及表格有效数值直接打开所点记录与当前指标。Inspector 顶部统一显示归属日期、星期、时段、实测／估计状态，实测附空腹条件；主读数与单位使用相同字号和晨晚颜色。同条记录的其他已有指标作为次级读数，体重／体脂可切换为主读数，BMI 有值时保留。记录信息使用轻量两列标签和值，展示来源及已知时间、时区、设备和连接应用；未知可选字段不占空行，日期时段记录不伪造测量时间，跨午夜显示实际当地时间和归属日。估计只增加依据块：当天锚点或主要参考实测、个人典型差、简洁计算、真实样本日数和“用于辅助趋势，并非实际测量”，更多参考默认折叠；来源标“系统估计 · 历史补全／日常估计”。规则版本、UUID、批次、生成时间、完整历史范围及拟合系数保留在后台。

日期入口直接进入同一 Inspector，优先查看已确定的晨间记录，否则查看晚间，无已确定记录则展示候选；紧凑晨晚导航与当天记录列表支持切换，点击“待选择”直接进入对应时段候选。查看候选与选择代表分开，后者才改变趋势、摘要及表格。查看全部打开完整历史的日期索引，记录入口复用同一详情，返回恢复索引展开、滚动和焦点。导航使用一个原生 dialog，支持 Tab／Shift+Tab、Escape、关闭按钮和桌面遮罩，关闭后返回外部触发位置并恢复页面滚动。

“估算规则”在估计开关旁，默认收起，在工具栏下方展开。桌面两列、手机一列：历史初始化用于首次补齐已有缺口，可参考前后真实历史，结果固定，真实补录替代对应指标；日常估计参考此前真实历史，以当天实测为基准并优先使用个人晨晚差，必要时使用近期晨间趋势，依据不足留空。共用说明为真实测量优先、估计辅助趋势、不参与实测统计。关闭估计后仍可打开规则；展开不重新挂载趋势图。

Inspector 打开时锁定背景滚动并保留滚动条占位，关闭恢复原有滚动与内边距。页头、摘要、图表和最近记录保持原有横向位置及宽度，手机与浮动滚动条不增加额外留白。

晚间全部标“非空腹”，白天空腹仍需明确确认。凌晨 06:00 前归前一天晚间，原始时间、当地日期与时区保留在详情与原始记录中。当前重复组按用户确认保留较早一条，其余软删除；未来候选选择只用于当前查看，未持久保存。
