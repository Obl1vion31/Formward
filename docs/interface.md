# 页面方案

## 四页共同顺序与确认

总览、饮食、消耗、身体使用同一框架：区间按钮 → 日期/查看记录 → 读数 → 图表标题/选项 → 图例与图形 → 原有记录或入口。正文最大1120px，手机左右16px；桌面有相同四页导航，手机保留一行页头和底部导航。身体顶部按选中日显示晨间体重/体脂，无值就是—；最新值、近7日变化均值放统计与选项。业务指标数量和图形保留。

删除、放弃输入、覆盖和数量级变化统一小型应用内确认，默认取消；Escape只关闭最上层。刷新/关闭浏览器仍为浏览器保护。健康读数固定两位，轴/日期/计数不补；旧四位原数不因打开或格式化而写回。消耗顶部总数与保存固定，其后总消耗、运动明细、时间备注；自动累计与手填合计明确区分，清空恢复累计，新运动没有完成勾选。

## 记录与填写交互

身体晨晚各采用最后保存的一条，数值旁小叉经二次确认只删除该指标。运动只记总数或分开填纯运动／期间静息，结果区分本次总数与计入当天。只有已有采用中总数时才问是否包含，并写明对应数值。跨页更新每90秒检查，提示后保留输入，采用最新前确认放弃；保存前再次核对。AI修改称“应用修改”，回页再确认保存。饮食、消耗横拖选日，纵向正常滚动；自定义应用前保留原图、取消不变。普通登录在封面失败或等待4秒后可用。


本文件记录页面方向以及已确定的内容与交互。产品范围由 `product.md` 决定，阶段顺序见 `milestones.md`。尚未讨论的页面不提前固定字段和构图。

## 全站加载反馈

保存、修改、估算、AI 审核、令牌管理、登录／退出、必要首页素材与站内页面加载共用等待反馈。按钮立即显示对应进行状态并阻止重复提交，等待超过 200ms 后显示全屏半透明虚化背景、32px 哑金旋转环及暖白动作文字；快速结束不闪现全屏提示，不人为延长等待。文案对应真实动作，如“正在保存记录…”“正在应用修改…”“正在加载页面…”，不显示虚构百分比。

加载层使用原生模态 dialog，位于编辑 Inspector 上方，等待期间阻止背景操作、Escape 和 Tab；完成、失败或中断后清理对应状态，恢复可用焦点，错误在原位置显示且输入保留。多个等待来源共同管理，连续导航阶段不重复闪现，全部完成才收起。滚动锁与 Inspector 共用，保持正文宽度和位置；减少动态效果时使用静态环和文字。

受保护页面先验证身份，再显示数据加载后备；审核页同时保留归属检查的 404，导航等待由链接状态跟踪。登录成功先播放既有最终动画，再进入页面等待。后台预取、复制、本地展开与图表切换不触发模态层。身体记录与 AI 设置页的首次数据响应提供相同视觉的后备，客户端接管后只显示一份。

## 首页与登录入口

首页是访问 Formward 时的登录入口，不提供公开注册。表单通过 Better Auth 验证账号，账号由内部管理员创建。

### 画面与交互方向

- 桌面采用深石墨色中央舞台，人物躯干后方有透明度 11% 的微弱暖金环境光，叠加透明度 3.5% 的宽幅暖光；侧下方保留极淡 petrol 环境色。环境层静止，主界面使用暖象牙白、哑金、暖灰和深石墨色，petrol 不用于文字或按钮。
- 首页采用“数字雕塑 + 编辑式界面”。素材就绪后，人物下层的独立轨道图层显示同级单行的 Discipline / NUTRITION、Drive / BUILD YOURSELF、Effortless / AI LOGGING。主词采用本地 Newsreader 正体 400、自动光学尺寸、0.035em 字距、1.2 行高和 `clamp(20px, 1.68vw, 26px)` 字号，颜色为暖灰白 `#d0c8ba`。副标签保留本地 IBM Plex Mono 400、9px、大写样式、0.13em 字距和哑金 `#aa9574`；Logo 和产品 UI 沿用 Avenir Next / Segoe UI / PingFang SC / sans-serif。字体与许可证本地分发，Manrope 不加载。
- 桌面轨道使用倾斜椭圆与透视投影，初始相位分别为 210°、330°、450°，沿人物同一 500ms 进度增加 150°。参考舞台为 1440×900，中心为 (792,450)，两根空间轴为 (288,-135,160)、(316.8,252,-240)，透视距离为 2400。终点节点约为舞台 76.4% / 33.9%、63.1% / 78.3%、24.3% / 32.3%；文字向外排布，保持 Discipline 右上、Drive 右下、Effortless 左侧。
- 节点、引线与 240° 开口弧段共用投影坐标；轨道为棕金 `#77664d`，近段透明度 16%、远段 7.5%，引线 30%，线宽 0.8px，节点 5px。统一标注结构为上方节点与水平引线、下方两级文字：文字顶部距节点水平线 12px，引线与最近文字边缘间隔 12px，常规引线长 24px，响应式避让时伸缩。左侧标注向右对齐、右侧向左对齐，跨中轴时连续插值文字偏移与引线方向。文字始终朝向读者，以 0.95–1.05 的缩放和轻微明暗表现远近；完整标注在视口内避让。图层不接收指针事件，不随人物鼠标移动，不参与人物的 `plus-lighter` 合成。视口与字体变化后缓存尺寸，不逐帧读取布局；转身最后 200ms 平滑将文字向外排布，为居中表单留出至少 24px 间距。
- 登录终点的标题相对亮度降至约 70%–76%，微标签至少保留 84%，轨迹降至原来的 75%。LOGIN_READY 与 AUTHENTICATING 保留终点，认证失败不退出；成功后随 700ms（reduced motion 为 240ms）最终人物动画淡出。加载、失败和 FINAL 隐藏；辅助技术只读取一份文案，装饰场景隐藏于辅助技术。
- 宽度不超过 700px 时，三组文字在底部安全区上方 16px 横排，左右各留 20px；Newsreader 主词均为单行 14px、副标签为 8.5px。隐藏空间弧线，用棕金细轴与等距节点连接主词，整个转身和登录阶段位置不变，只适度减弱；键盘入口获焦时底部间距为安全区加 110px，位于词组上方。reduced motion 在桌面交叠两套静态轨道构图 180ms，不产生空间旋转；手机保留静态网格。英文图层标记 `lang="en"`。
- 第一屏保留左上角文字 Logo、居中人物，`SCROLL TO ENTER` 收在左下角，左边距固定为 7%，底部间距为 `clamp(24px, 5.8svh, 52px)`。提示使用 IBM Plex Mono、8.5px、暖金与 75% 透明度，旁边是 1×26px 细轨道和 7px 动标；动标每 1.6s 轻移 12px。提示不跟随人物视差，现有人物显示高度、Frame 1 构图和逐帧校准保持不变。
- 提示仅在图片解码完成、INTRO、宽度超过 700px 且支持 hover 的细指针设备显示。停在 INTRO 时持续显示，鼠标移动及未触发播放的滚轮或键盘操作不会隐藏；离开 INTRO 后 120ms 淡出，倒放完整回到 INTRO 后恢复。解码前操作不影响以后回到首屏时的提示显示，触屏与窄屏不显示。加载与失败信息独立保留，提示不承担鼠标点击操作。
- 人物外层使用 1600px 透视，变换中心位于舞台 50% / 32%。INTRO 鼠标反向位移上限为水平 6px、垂直 4px，朝鼠标方向的倾转上限为 rotateY 0.6°、rotateX 0.3°；背景、Logo、提示和表单保持固定。跟随时间常数 90ms，停止 180ms 后用 600ms smoothstep 回中。鼠标离开舞台时回中，归稳后停止 rAF；窗口失焦、页面隐藏或关闭联动能力时立即归零。
- 正放、倒放和 FINAL_TRANSITION 停止接收鼠标目标，100ms 内回中。LOGIN_READY 尚未聚焦输入框时为首屏半幅，首次聚焦 Email 或 Password 后在 180ms 内回中并锁定整个登录阶段；自动聚焦同样触发。切换字段、失焦、点击空白或移向 ENTER 均不解除，只有倒放完整回到 INTRO 或进入 FINAL 才解除。FINAL 只在输入框无焦点且有新鼠标移动时恢复半幅；倾转只作用于 PNG 图层。
- 表单在液态尾部上方居中，肩背和腰线保持露出。桌面宽度最多 340px，手机最多 320px；中心分别位于舞台高度的 64%、67%，视口高度不超过 640px 时为 66%，不超过 480px 时为 70%。静止时只显示 Email、Password、输入内容和 `ENTER`，没有标题、说明、品牌重复信息或箭头。
- 衬底采用边缘渐隐的暖烟色玻璃，底色为 `rgba(28, 26, 22, .82)`，背景模糊 10px，没有外框或厚重阴影。标签为 12px 象牙色，输入值为 16px；底线保留 1px 透明边框占位，可操作字段 hover / focus 时在 180ms 内显现为哑金，失焦且未悬停时退去，禁用字段不响应悬停。键盘保留清晰焦点框，触屏点击标签或字段即可聚焦，reduced motion 即时改变底线。ENTER 为 15px、600 字重的哑金文字，下方保留 42px 短细线；整行点击高度至少 44px，背景透明。禁用态透明度为 80%，填写完整后启用，hover 时变为象牙色。
- 桌面舞台以 100svh 固定在视口内，滚动区域约 155vh。滚动只选择方向；一次下滚触发完整 500ms 视频（2 倍速），上滚沿同一进度自动倒放。手势结束后继续播放，同方向惯性不重启；反方向超过阈值时从当前连续进度反向，剩余时长按到目标的进度距离计算。
- 桌面滚轮在 250ms 内同方向累计约 44px 后触发。手机点击首屏任意非交互区域立即显示登录尾帧；滑动不切换阶段，登录后点击背景不返回，顶部“返回”按钮回首帧并保留输入。方向监听在 Enter 开始认证后暂停；认证失败时恢复，成功后的最终过渡与导航期间继续关闭。
- 人物由静态首尾、视频 Canvas 与独立最终图组成，均绝对定位。视频有额外留白，按头顶和尾滴匹配静态端点并平滑调整大小及位置。桌面视频黑底与宽幅暗光晕使用 WebGL 的柔和亮度阈值去除，保留人物亮部和近轮廓；两端各 40ms 按 smoothstep 交叠，人物组仍使用隔离的 `plus-lighter` 合成，背景与 Login 不参与。
- 桌面 Login 的 opacity 与 translateY（16px → 0）映射同一 `animationProgress`；前 60%（300ms）隐藏，最后 200ms 浮出。倒放同步隐藏，中途反向连续，静态第 12 张完整显示后才允许提交。
- Frame 12 完整显示后进入 LOGIN_READY，表单才可操作。Email、Password 非空且点击 `ENTER` 后，先进入 AUTHENTICATING 验证账号；成功后确保人物外层完全归零，再独立以 700ms 交叉过渡到 13，并带轻微 scale（0.98 → 1）和 blur（3px → 0）。若提交时 180ms 回中尚未完成，立即归零后开始，不增加等待时间。AUTHENTICATING、FINAL_TRANSITION 和 FINAL 都拒绝方向输入。最终透明度动画的 animationend 触发后导航到 `/dashboard`，不提前跳转；认证失败回到 LOGIN_READY 并显示中文提示。
- `src/app/frame-config.ts` 保存原始 1、12、13 的静态导入与原有桌面、移动端校准；`turn-video.ts` 保存 60 帧视频配置、寻帧和透明合成。`PRE_LOGIN_FRAMES` 只包含静态两端，第 13 张继续保持独立。
- 三张静态 PNG 通过 Next.js `preload` 提前加载并解码；只有桌面加载视频，使用 `preload="auto"` 并主动静音内联播放唤醒解码，当前帧可绘制后暂停。静态图完成解码前保持原始首帧，加载期间记录最近方向，就绪后自动执行。视频失败、WebGL 不可用或预加载超过 4 秒时采用 180ms 静态首尾交叠，表单可正常登录；触摸／点击／按键可重试受限视频，恢复只在端点切回完整动画。图片失败仍显示刷新提示。
- 手机模式由 `(max-width: 700px), (hover: none) and (pointer: coarse)` 判断，包括触屏横屏。舞台与页面均为 100svh；首屏显示“轻触屏幕进入登录”，三张图解码后开放点击，手机不创建 video／Canvas、不等待视频唤醒。背景为纯石墨，原始 1／12／13 透明 PNG 使用 normal 合成，消除彩色舞台光影。登录中返回按钮至少 44px，认证中禁用，返回关闭键盘并保留表单。
- 静态素材包含 Alpha，视频的黑底与宽幅暗光晕通过透明合成去除；首尾原图的光晕与视频细节存在差异，因此在两端保留短交叠。

### 可用性边界

- 表单在桌面和窄屏下保持可读，输入与按钮有清晰的键盘焦点。
- 键盘聚焦时显示“进入登录”入口，点击或 Enter / Space 可触发同一正放时间线，完成后聚焦 Email 并锁定人物回中。桌面页面方向键、PageUp / PageDown、Home / End 和 Space 支持双向触发；手机键盘入口可直接显示登录，返回只用顶部按钮；输入框、按钮及可编辑内容中的键盘操作不会切换动画。手机键盘改变视口不会自动倒放。
- 触屏、宽度不超过 700px 和 reduced motion 均关闭鼠标视差。reduced motion 下鼠标提示静止，离开首屏时隐藏无动画；桌面正放、倒放以 180ms 首尾 crossfade 简化，手机直接跳到端点，Login 全程仅淡入淡出，Enter 为 240ms，不播放连续转身或位移、缩放、模糊效果。
- Email 与 Password 仅在页面组件状态中保留；倒放后输入不会丢失。点击 Enter 将凭据提交至认证接口，密码不保存到浏览器持久存储。认证中与最终过渡中禁用输入和提交。错误密码、限流、网络故障可重试，只有成功验证才播放最终动画。

### 登录后的主页

- `/dashboard` 每个请求验证当前会话，未登录、过期或撤销后返回登录入口，只采用服务端认证的 user_id。

总览保留双层日期关联图：上层蓝色摄入线、红色消耗线，柔杏金盈余与雾蓝灰缺口填色；下层暖白次晨变化，共用日期、选中线与命中区，缺测断开。默认选最近同时有摄入和消耗数值的一天，再回退至最近有记录日；手机7D、桌面30D，不足时扩大至容纳目标日的最短既有区间。能量线图按全区间留5%且至少100 kcal余量，整齐刻度与范围分开生成，kg轴独立包含零，选日不改变坐标。手机先展示单日盈余／缺口和摄入−消耗，次晨读数贴近下层图，两日晨重在详情；桌面保留两组读数和紧凑入口。7D／30D／90D／全部／自定义、估计开关、键盘／触屏及详情保持，当天确认为已记完且摄入、消耗都有数值时计算盈余；营养部分未知或估算不额外阻止相减。未记全／未确认日保留摄入展示，不产生盈余。

状况摘要分别采用今天及以前最近的记录日期：摄入汇总该日全部有效餐次，显示日期、餐数及kcal；消耗采用最近有效日记录或已完成运动所在日期，显示日期和读数。部分、未知和明确0保持区别；各类日期可以不同。手机在趋势图下显示身体／摄入／消耗三行紧凑摘要，桌面保留三张卡片；跨零点不会清空已有摘要。

退出登录撤销当前会话并回到登录页。总览只聚合现有记录，不把摄入和体重差解释为确定因果，不接入预算设置或训练计划。身体详情继续使用原来的真实配对、估计与来源规则。


#### 总览首屏与日期选择

设计和视觉验收统一使用[设计文档](design-reference.md)的适用条目。手机先展示选中日期／查看记录、同一紧凑行的摄入／消耗／盈余或缺口，再展示区间栏、热量收支和次晨变化两图及共用日期刻度；其他状况摘要在图后。长数字最多紧凑换行，未记全、未知和估计仍可辨认。区间栏上下间距一致，图例保留四个核心颜色，缺测及空心点解释在图后。

总览没有前后一天、独立日期输入或解除固定按钮。桌面悬停预览、移出恢复，点击日期列固定或切换，点击图外／Escape解除；图外按钮仍执行自身操作。手机点击或横向拖选，纵向滚动和键盘选日保持。范围内固定日期保留，移出新区间则解除并选择该区间有效日期。自定义范围按需展开，应用后收起，取消不改变已用区间。

手机图组按实际可视高度重绘：常规约268px、600px及以下矮视口约228px，缩小图间空白并按绘图区高度减少等距刻度标签；标签实际至少12px，不缩放整幅SVG。数据范围、kg零线、真实波动、断线、估计虚线及计算口径保持。默认首屏完整双图与日期刻度需通过实际底部导航边界检查；横屏、文字放大允许自然滚动。


### 身体指标记录

Inspector 统一以 320ms 从右向左滑入，渐变遮罩同步淡入；Escape、关闭按钮、遮罩和录入返回都以 240ms 向右退出并同步淡出。动画结束后卸载 dialog，恢复滚动、滚动条补偿和外部焦点。减少动态效果设置下直接开关，动态改变设置也及时完成切换。面板内部切换指标、记录、时段和编辑表单保持打开。打开期间保留原有页面内边距与滚动条占位，页头、摘要、双图和表格不横移；Strict Mode 重放保护与键盘循环保持。

四项可独立保存，包括仅体脂；晨间固定空腹，旧非空腹／未知条件只读，晚间固定非空腹。每个空项旁独立估算，草稿不参与计算；先保存实测，再估算剩余项。表单末尾仅“保存录入”，下划线距文字 4px，错误与操作结果在按钮之前。页面没有自动弹窗、新增日期或跳过入口；日历空行只在展示层推导，已有日期与提醒状态保留。历史修改携带 updatedAt 防止覆盖并发写入，遗漏字段保留、显式 null 清空，每条实测至少一个主要指标非空。冻结历史允许实测补录，禁止新增或重算估计。 晨间、晚间各自填写数据来源，只回显已保存来源，未知来源保持空白；点击后提供按最近使用排序的历史建议，支持自由输入及本账号历史建议的鼠标、触控和方向键／Enter／Escape。来源可填写实际设备／应用名称，也可直接留空；点击保存或应用修改即确认当前输入，空来源保存为 null，估算不要求来源。身体录入与 AI 审核共用来源输入，来源只保留标签与输入框；点击输入框直接展开本账号全部历史建议，保留现有文字，输入时再筛选。没有历史或没有匹配时显示明确提示。建议旁“×”仅软删除建议并保留当前草稿与历史名称快照；旧记录仅保留原来源时不会恢复建议，明确再次用于新实测或来源修改并保存后恢复。建议仅在实测成功事务中新增或更新，草稿、失败和留空不产生建议。已有实测允许只改来源，保留原录入入口、准确测量时间与原始输入，并保存修改审计。设备与连接应用合成 `device_label` 名称快照，修改某条记录不影响其他记录。

网页晨间固定“空腹”，服务端拒绝非空腹或条件未知的晨间写入；旧非空腹／未知白天记录只读，不能经表单改为空腹，晚间仍可编辑。晚间全部标“非空腹”。导入与维护入口继续保留历史条件的三态来源，不从钟点推断空腹。凌晨 06:00 前归前一天晚间，原始时间、当地日期与时区保留在详情与原始记录中。旧同槽多条统一采用最后保存行，原值留档，后续覆盖或删除时归档被取代记录。

网页已支持四项录入与历史编辑，晨晚独立选择 GMT 时区，新记录默认系统时区，已有记录回显原值并支持只改时区保存；准确测量时间与归属纠正、整条恢复及文件导入尚未接入；网页已支持逐指标删除，维护脚本已有条件修正与软删除／恢复。身体记录 AI API 已实现，邮箱右侧 AI 接入提供令牌、接入说明与最近提交；截图／语音解析及设备直连待实现，见 [身体指标记录](measurements.md)。

### AI 统一审核

统一审核页按身体状况、摄入记录、食材库记录和消耗记录排列，只显示本次内容。新增直接展示内容，修改突出增加、移除和更改的项目，旧内容按需展开；本餐先显示服务端合计kcal及P／C／F，已知部分、未知和0分开；多餐逐餐展示，修改展示变更及修改后合计。照片默认折叠，变更照片展开后显示前后对照。修改先更新草稿，取消可恢复；普通餐次只需底部一次“确认保存”。缺图只提示，可先保存文字；没有照片核对清单。重复餐和消耗包含关系未定时才提出对应问题。所选内容在一个数据库事务中保存，失败保留输入并整体回滚。手机压缩信息间距，底部吸附按钮保留安全区；依据、备注和审核技术信息折叠。保存成功显示勾，2秒后返回总览，保留立即返回入口；重新打开已完成链接不自动跳转。

三类记录独立取舍。同批新食材通过稳定项目标识供餐次引用，多餐只创建一个食材。取消入库时由服务端生成独立营养与规格快照；只入库时不产生摄入。修改在弹窗内完成，跨页审核版本冲突可在弹窗内加载最新状态并保留输入。过期或外部数据变化须刷新后重新核对，更新／刷新后的有效期为15分钟。

时区使用 GMT+8（东八区）、GMT+7（东七区）等标签，选择项只提供 GMT-12 至 GMT+14 的整数小时；旧半小时／一刻钟偏移按原值显示。原 IANA 值只显示相应偏移，未主动更改则保留存储。新录入自动采用当次系统时区并在审核页回显，可选择其他时区或点击“采用设备时区”，之后仍须应用修改、确认保存。已有记录省略时区时保留原值，显式 null 显示“未指定”。历史时区修改保持当地钟点与记录日期，未知钟点不补；记录详情与 API 查询采用同一标签。

## 饮食记录

## 录入与审核的当前口径

桌面总览用普通指针：未固定时悬停预览、移开恢复；点击固定，点击另一列切换，点击图外或Escape释放，越出新区间解除。详情身体／消耗并排、当日总营养常驻，前三餐默认折叠，剩余餐次再展开；原图只在展开后请求。

摄入摘要取今天及以前最近有记录日，网址日期和主动选择优先。今天及前6个日历日的待处理日期含空日补录，更早记录按50个有记录日期分页。新自由项填名称、单位、数量和本次总营养，默认1份，数量不再相乘；单击、Tab可输入，Enter结束当前格，不隐式保存。手机单位与数量并排、营养两列，暖色边框常驻。详情用小框选择标签／成分表或预估，旧项不批量转换，未修改项原样保存。包装只采用可靠换算。

消耗可记录总数也可保留运动明细，存在总数／活动合计时明确已包含或额外增加，支持全部选择；不按大小推断。更改总数／模式重新核对，只改来源备注不重问。公式与资料入口撤下。

普通AI餐次先展示日期、本餐kcal及P／C／F、食物，然后修改／取消，底部一次确认保存。缺图只提示，不要求照片勾选或标记已核对。餐次修改列清增减及修改后合计，旧内容按需展开。AI不得删除恢复整条或批量删除；网页手工操作保留。

## 共用记录与查看

四页图表共用悬停预览、点击固定、图外／Escape解除、范围内保留固定日和键盘操作；无前后日导航。查看记录统一位于日期／图表标题右侧。身体、饮食和消耗的主列表始终保留今天，前6天仅保留各模块待处理日期；已完成或更早日期在查看全部中查找。饮食状态是次要的小型切换按钮，不占整行。餐次、活动和图片进入Inspector查看，主列表不铺开详情。

手机身体页常驻当前体重和体脂、完整体重图，近7日统计展开，体脂图下滑查看。饮食仅保留一份日期与营养合计，无连线；消耗日期／查看在三项读数上方。总览右侧合并次晨标题与读数，缺测不再堆叠短横。设计和验收统一按design-reference.md。

餐次编辑器最大1280px，宽屏食材库220px，窄桌面复用食材库／本餐切换后铺满录入区。按实际文字和可用宽度决定八列表格或卡片；主字段16px／22px、44px高，名称单位左对齐、数值右对齐，表头与输入／只读值内容边缘一致。包装规格在食材库及按钮旁的详情中保留，未在名称下重复占行。气泡位于所属Inspector顶层，随按钮滚动和可视区变化重新定位，长内容内部滚动，Escape先关闭气泡。
