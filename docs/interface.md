# 页面方案

本文件记录页面方向以及已确定的内容与交互。产品范围由 `product.md` 决定，阶段顺序见 `milestones.md`。尚未讨论的页面不提前固定字段和构图。

## 首页与登录入口

首页是访问 Formward 时的登录入口，不提供公开注册。表单通过 Better Auth 验证账号，账号由内部管理员创建。

### 画面与交互方向

- 页面采用深石墨色中央舞台，人物躯干后方有透明度 11% 的微弱暖金环境光，叠加透明度 3.5% 的宽幅暖光；侧下方保留极淡 petrol 环境色。环境层静止，主界面使用暖象牙白、哑金、暖灰和深石墨色，petrol 不用于文字或按钮。
- 素材就绪后，人物下层的独立背景层显示 Discipline、Drive、Effortless，分别配以 Nutrition、Build yourself、AI logging。标题使用本地 Manrope、330 字重、`clamp(24px, 2.25vw, 34px)` 字号和暖 ivory `#c7bcaa`；辅助标签使用本地 IBM Plex Mono 400、9px、大写样式、0.13em 字距和暖金 `#aa9574`。字体变量由 `hero-font.ts` 提供，资源及许可证在 `public/fonts/`；表单和 Logo 使用原有字体。
- 三个轨迹节点分别位于舞台 25% / 32%、75% / 30%、75% / 71.11%。Discipline 从左侧 7% 起排，另外两组从左侧 79% 起排；各标题的行框中心与对应节点垂直对齐。静态 SVG 弧线经过三个节点，线宽 0.8px、透明度 14%，短引线透明度 30%，5px 圆形节点保持固定尺寸。节点和文字坐标来自同一配置，人物自然遮挡经过主体的轨迹；背景不接收指针事件、不随鼠标移动，不参与人物内部的 `plus-lighter` 合成。
- 背景层映射同一转身进度，前 40%（200ms）以 smoothstep 淡出，倒放时连续恢复；reduced motion 随全程 180ms 淡入淡出。透明度归零时同步设置 `visibility: hidden`，从辅助技术中隐藏。加载及失败、LOGIN_READY、认证及最终过渡阶段均隐藏。
- 宽度不超过 700px 时，三组文字在底部安全区上方 16px 横排，左右各留 20px。标题 14px、辅助标签 8.5px；隐藏大弧线，用细横轴与三个等距节点连接标题。键盘进入登录入口获焦时位于文字上方；英文背景层标记 `lang="en"`，装饰轨迹和节点对辅助技术隐藏。
- 第一屏保留左上角文字 Logo、居中人物，`SCROLL TO ENTER` 收在左下角，左边距与 Discipline 同为 7%，底部间距为 `clamp(24px, 5.8svh, 52px)`。提示使用 IBM Plex Mono、8.5px、暖金与 75% 透明度，旁边是 1×26px 细轨道和 7px 动标；动标每 1.6s 轻移 12px。提示不跟随人物视差，现有人物显示高度、Frame 1 构图和逐帧校准保持不变。
- 提示仅在图片解码完成、INTRO、宽度超过 700px 且支持 hover 的细指针设备显示。停在 INTRO 时持续显示，鼠标移动及未触发播放的滚轮或键盘操作不会隐藏；离开 INTRO 后 120ms 淡出，倒放完整回到 INTRO 后恢复。解码前操作不影响以后回到首屏时的提示显示，触屏与窄屏不显示。加载与失败信息独立保留，提示不承担鼠标点击操作。
- 人物外层使用 1600px 透视，变换中心位于舞台 50% / 32%。INTRO 鼠标反向位移上限为水平 6px、垂直 4px，朝鼠标方向的倾转上限为 rotateY 0.6°、rotateX 0.3°；背景、Logo、提示和表单保持固定。跟随时间常数 90ms，停止 180ms 后用 600ms smoothstep 回中。鼠标离开舞台时回中，归稳后停止 rAF；窗口失焦、页面隐藏或关闭联动能力时立即归零。
- 正放、倒放和 FINAL_TRANSITION 停止接收鼠标目标，100ms 内回中。LOGIN_READY 尚未聚焦输入框时为首屏半幅，首次聚焦 Email 或 Password 后在 180ms 内回中并锁定整个登录阶段；自动聚焦同样触发。切换字段、失焦、点击空白或移向 ENTER 均不解除，只有倒放完整回到 INTRO 或进入 FINAL 才解除。FINAL 只在输入框无焦点且有新鼠标移动时恢复半幅；倾转只作用于 PNG 图层。
- 表单在液态尾部上方居中，肩背和腰线保持露出。桌面宽度最多 340px，手机最多 320px；中心分别位于舞台高度的 64%、67%，视口高度不超过 640px 时为 66%，不超过 480px 时为 70%。只显示 Email、Password、两条输入下划线和 `ENTER`，没有标题、说明、品牌重复信息或箭头。
- 衬底采用边缘渐隐的暖烟色玻璃，底色为 `rgba(28, 26, 22, .82)`，背景模糊 10px，没有外框或厚重阴影。标签为 12px 象牙色，输入值为 16px，输入下划线透明度为 42%。ENTER 为 15px、600 字重的哑金文字，下方保留 42px 短细线；整行点击高度至少 44px，背景透明。禁用态透明度为 80%，填写完整后启用，hover 时变为象牙色。
- 舞台以 100svh 固定在视口内，滚动区域约 155vh。滚动只选择方向；一次下滚触发完整 500ms 视频（2 倍速），上滚沿同一进度自动倒放。手势结束后继续播放，同方向惯性不重启；反方向超过阈值时从当前连续进度反向，剩余时长按到目标的进度距离计算。
- 滚轮在 250ms 内同方向累计约 44px 后触发；移动端单指上滑约 40px 正放，下滑约 40px 倒放。手指尚未松开也可改变方向。方向监听在 Enter 开始认证后暂停；认证失败时恢复，成功后的最终过渡与导航期间继续关闭。
- 人物由静态首尾、视频 Canvas 与独立最终图组成，均绝对定位。视频有额外留白，按头顶和尾滴匹配静态端点并平滑调整大小及位置。视频黑底使用 WebGL 转为透明；两端各 40ms 按 smoothstep 交叠，人物组仍使用隔离的 `plus-lighter` 合成，背景与 Login 不参与。
- Login 的 opacity 与 translateY（16px → 0）映射同一 `animationProgress`；前 60%（300ms）隐藏，最后 200ms 浮出。倒放同步隐藏，中途反向连续，静态第 12 张完整显示后才允许提交。
- Frame 12 完整显示后进入 LOGIN_READY，表单才可操作。Email、Password 非空且点击 `ENTER` 后，先进入 AUTHENTICATING 验证账号；成功后确保人物外层完全归零，再独立以 700ms 交叉过渡到 13，并带轻微 scale（0.98 → 1）和 blur（3px → 0）。若提交时 180ms 回中尚未完成，立即归零后开始，不增加等待时间。AUTHENTICATING、FINAL_TRANSITION 和 FINAL 都拒绝方向输入。最终透明度动画的 animationend 触发后导航到 `/dashboard`，不提前跳转；认证失败回到 LOGIN_READY 并显示中文提示。
- `src/app/frame-config.ts` 保存原始 1、12、13 的静态导入与原有桌面、移动端校准；`turn-video.ts` 保存 60 帧视频配置、寻帧和透明合成。`PRE_LOGIN_FRAMES` 只包含静态两端，第 13 张继续保持独立。
- 三张静态 PNG 通过 Next.js `preload` 提前加载并解码；视频使用 `preload="auto"`。全部素材就绪前保持原始首帧，加载期间记录最近方向，就绪后自动执行。图片或视频失败时显示刷新提示。
- 静态素材包含 Alpha，视频的黑底通过透明合成去除；首尾原图的光晕与视频细节存在差异，因此在两端保留短交叠。

### 可用性边界

- 表单在桌面和窄屏下保持可读，输入与按钮有清晰的键盘焦点。
- 键盘聚焦时显示“进入登录”入口，点击或 Enter / Space 可触发同一正放时间线，完成后聚焦 Email 并锁定人物回中。页面方向键、PageUp / PageDown、Home / End 和 Space 支持双向触发；输入框、按钮及可编辑内容中的键盘操作不会切换动画。手机键盘改变视口不会自动倒放。
- 触屏、宽度不超过 700px 和 reduced motion 均关闭鼠标视差。reduced motion 下鼠标提示静止，离开首屏时隐藏无动画；正放、倒放以 180ms 首尾 crossfade 简化，Login 全程仅淡入淡出，Enter 为 240ms，不播放连续转身或位移、缩放、模糊效果。
- Email 与 Password 仅在页面组件状态中保留；倒放后输入不会丢失。点击 Enter 将凭据提交至认证接口，密码不保存到浏览器持久存储。认证中与最终过渡中禁用输入和提交。错误密码、限流、网络故障可重试，只有成功验证才播放最终动画。

### 登录后的主页

- `/dashboard` 每个请求验证当前会话，未登录、过期或撤销后返回登录入口。页面只采用经过认证的 user_id，不采用 URL 中的账号标识。
- 页面沿用深石墨、暖白与哑金，显示当前邮箱和退出按钮。饮食、运动与身体指标显示“即将开放”，不生成虚构健康记录或零值汇总。
- 退出登录撤销自己的会话，完整导航回登录页并清空当前客户端页面缓存。
- 身体、饮食、运动与总览的实际记录页面在进入相应里程碑前补充详细规格。
