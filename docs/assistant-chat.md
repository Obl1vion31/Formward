# 站内助手聊天

会员档位独立于管理权限。Free聊天锁定并标Plus，可手工记录、使用提醒和已开放设备接入，每日可识图4次；内测账号聊天与识图共用¥1，Plus及指定有效owner共用¥2。Pro预留且不可分配。现有及新建普通账号默认Free。千问、小米MiMo、智谱使用同一段可读对话和正式业务工具，不自动转交或重试。

## 提示词与工具

当前正式协议为MCP2.0.1，站内助手通过同一目录按需加载18项业务工具。千问使用original长版、小米compact精简版、智谱original；共用生成器records/ai-prompt.mjs提供正式业务规则，再附站内补充、引用和私有附件说明。模型默认准备最近10组完整问答、当前任务与引用；上下文数量和模型参数保持；共用提示词修订2026-11-15-preserve-verbatim-v1仅增加已验证的原文冲突处理要求：规则冲突时等待用户选择，合法来源说明保留原文。较宽泛的候选因出现退化未采用。

新增餐次使用preview_meals，正式餐次修改使用preview_meal_changes，食材维护使用preview_foods；get_preview统一查询预览状态，update_preview修改原草稿及补照片，preview_record_bundle只用于至少两类功能的组合任务。受控会话生成稳定请求编号，重试复用原结果；来源、授权、归属、版本和最终人工确认保持。完整工具与已知边界见[AI调用规则](ai-tool-contracts.md)，模型回答质量与链路验收分开记录。

首次默认千问。当前选择存于本人当前会话；新对话继承上一选择。切换只改变下一次发送，保存选择本身不调用模型。保存期间暂时禁用发送；生成中先停止，再切换。草稿、照片、单条引用和阅读位置保留，每条助手消息独立保存实际提供方。跨模型重试增加一次助手尝试，沿用原用户问题，旧结果和费用保留；每条回执保留原授权引用，撤销后不能通过中间模型回执借新授权复活旧预览。

当前会话首读最近5条，每次再读5条，最多可访问最近50条；用户和助手各算一条。数据库更早消息和归档会话不自动删除，本轮没有旧会话列表、搜索或长期记忆检索。模型上下文默认取最近10组完整问答，再附当前任务和引用；不将原始思考、供应商工具信封或缓存状态跨模型传递。

缺少本次实际食量等必要信息时，由当前模型调用内部request_followup明确返回任务及问题。questions最多4题，每题最多8个选项，可声明多选、自由填写和可跳过。问题与选项ID唯一，不预选健康事实；选择只改本地状态，全部核对后统一提交，必填不可跳过。旧纯文字问题继续可用。补充保留已知信息，引用绑定本人当前会话的真实已完成回答，服务器查该回答的运行所关联的原问题，准备完整问答上下文；可以取消引用或换话题。任务及引用关联的私有照片在归属校验后读取，不靠最近使用的模型或问号猜测状态。

## 业务和授权

chat-tools通过进程内MCP适配器发现现有18项业务工具，按需定义、错误补定义和同题草稿协调复用records/ai-tool-session.mjs。网页、外部AI和站内助手继续使用同一套查询、版本、营养、预览及人工确认规则；load_tools和request_followup只是站内控制工具，不新增公开业务工具或scope。历史修改先查询最新对象和版本，AI不得整条删除。外部AI仍在原网页审核；站内AI通过聊天内卡片调用同一人工审核服务，保存仍来自已登录用户的明确操作。

三个模型分别关联独立ai_tokens及assistant_connections，Free饮食任务使用单独purpose=meal_entry且仅限meals的令牌，首次发送创建已授权的站内连接，有效期30天。数据库只保存随机原文的摘要；站内执行使用已验证会话与本人连接引用，不向浏览器发放Bearer原文。撤销、到期、停用或账号访问失效阻止后续工具调用；恢复须在连接详情明确启用，创建新授权，不复活旧令牌或旧预览。原授权关联保留以追溯“千问／小米MiMo／智谱 · 站内助手”来源。

照片复用私有meal_images上传和读取，最多8张，单张20MiB，仅JPEG／PNG／WEBP。消息保存附件ID，不保存公开图片地址。模型调用由服务器读取本人附件并传输；补充或引用时只带相关原图。已有清理脚本仅处理未登记对象，聊天中已登记原图同样保留，不因尚未关联正式餐次而删除。

## 每日用量

内测三模型合计每日¥1，Plus及指定管理员合计每日¥2，按每次模型请求开始时的北京时间归属日期，零点重置。输入工具栏发送按钮左侧仅显示百分比，0、<1%及向下取整分别处理，超过100%如实显示。悬停、聚焦或点击仅显示重置时间；不提供用户金额、费用明细或额外交互。服务端仍按未取整费用判断预算，保留预占、未知费用与结算。

服务器在账号锁内按未命中输入上界、图片保守估计及8192输出预占，再按usage结算；同一请求只结算一次。明确HTTP拒绝释放预占，网络中断、停止或没有可靠usage时保留待结算，不将未知伪装为免费。刷新、打开助手、切换、结算、恢复前台及日界同步用量，读取失败保留原值并提供重试，不闪现0%。预算与私有模型评测分开。

平台余额、限流、凭据、网络、超时与站内额度分别说明。未确认原因显示通用故障。单家失败后由用户选择其他模型；站内共享预算不足则暂停三家新请求，提醒、历史和手工记录保持可用。停止和刷新均不自动收费重发。

## 私有接口与限制

| 入口 | 用途 |
| --- | --- |
| GET /api/account/entitlements | 最新权益版本及百分比／识图次数，只读、不调用模型 |
| GET /api/assistant-chat | 模型目录、当前选择、当前会话、5条分页、运行状态和用量；previewId读取本人已结束回答关联的原审核内容 |
| POST /api/assistant-chat | send／retry／continue，返回真实SSE消息、工具摘要及用量 |
| POST /api/assistant-chat/control | select_model／new／stop／enable／revoke／clear_followup；review_preview及remove_preview_source复用人工审核／来源服务 |

以上入口均验证有效会话及本人数据；聊天写入核对chat权益，饮食识别核对mealRecognition权益。指定管理员仍须匹配账号ID和owner；写入检查同源，拒绝客户端指定账号、API地址、Key、价格及未知字段。引用和照片校验本人归属。消息、运行和账本保留账号及复合归属外键，请求ID绑定内容防重复。

每账号最多一个生成任务，20次用户发送／重试每分钟；每回合最多8次模型请求，每次8192输出tokens、120秒。上下文与图片保守输入估计超过200000时明确要求缩小内容或新对话，不静默裁剪当前任务。心跳超过150秒未更新的运行回收为停止，未知费用保留；刷新先读运行状态。

## 饮食页内识别

私有GET／POST /api/assistant-meal管理本餐识别任务，沿用有效登录、最新档位、同源写入、附件归属、每账号单生成及共享日预算／免费计次。Free必须有本人本餐照片，不能通过此入口使用无图片通用聊天。create绑定draftKey及当前草稿；run调用同一生产适配器与流，模型选择只属于本餐任务，不改主聊天；apply仅返回待核对草稿；save经原审核服务更新草稿并确认；stop停止生成、cancel取消本次识别；enable_model／revoke_model管理本人当前任务模型的30天授权，恢复必须明确操作。生成结果本身不保存正式记录。

任务使用assistant_conversations.purpose=meal_entry、active=false及私有context，不替换主聊天的当前会话。context保留原手工草稿、当前绑定、附件引用、预览及实际提供方。模型仅能为当前餐次提出新增食物，目录限preview_meals、get_preview、search_foods与站内补充；日期、餐次及已有手填由应用固定合并，不信任模型覆盖。重复识别扩展同一预览；有预览后沿用其模型授权，不借切换复活旧授权。原始草稿与AI及人工修订可审计。

手机表单一次展开一个食物，三个主字段及四项营养正常字号同排；文字放大或长数值可换行。首屏直接提供自己填写、食材库与拍照录入，添加食物直接增加手填项。通过同一个原生照片选择框选择相机或相册后复用原图字节上传、真实百分比、核对、取消／重试及国内手动备用通道。识别有独立任务与当前草稿签名，迟到结果不能覆盖新草稿，取消或失败保留原手工填写。回填后最后一次保存走原归属、授权、期限、版本和幂等检查。AI确认内的嵌套编辑不再次提供拍照入口。

## 聊天交互

桌面左栏约200px，三行手动记录后为统一向下的按需补记／AI确认／常用功能；右侧专注聊天。手机64px头部保留聊天／待办，小于360px用同位置下拉。新聊天欢迎24px，说明16px；输入提示固定，不被追问替换。用量百分比与发送底部对齐，向下按钮零占位悬浮。

用户气泡随内容宽度，发送约180ms轻位移，本地待发与服务器用真实请求ID对齐，历史恢复不重播。引用只在完成回答下。查询链接及确认卡等到回答结束后出现，卡片复用RecordReview及web-review，确认保存与本次不保存同级；复杂内容展开原审核。卡片读取失败可打开原网页；网页和卡片不能并发绕过版本、到期、撤销、来源或幂等校验。减少动态效果即时呈现，工具摘要不包含原始内部推理。
