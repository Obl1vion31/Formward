# 站内助手聊天

站内聊天只向配置指定的有效owner账号开放；其他账号仍使用原有提醒、补录和快捷记录，聊天显示“暂未开放”。千问、小米MiMo、智谱使用同一段可读对话和正式业务工具，不自动转交或重试。

## 模型与会话

| 顺序 | 工具栏名称 | 实际型号 | 每百万tokens：输入／缓存命中／输出（元） |
| --- | --- | --- | --- |
| 1 | 千问 | qwen3.8-flash | 0.8／0.1／2.7 |
| 2 | 小米 MiMo | mimo-v2.6-flash | 1／0.02／2 |
| 3 | 智谱 | glm-5.3-flash | 0.8／0.23／2.8 |

价格核对依据为[千问官方型号页](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)、[小米官方型号页](https://mimo.mi.com/models/zh-CN/mimo-v2.6-flash)和[智谱官方定价](https://docs.bigmodel.cn/cn/guide/start/pricing)。采用按量原价估算，不推测优惠、平台钱包或订阅余额。每次请求保存原始usage和当时单价，思考tokens已包含在completion_tokens时不重复相加。

首次默认千问。当前选择存于本人当前会话；新对话继承上一选择。切换只改变下一次发送，保存选择本身不调用模型。保存期间暂时禁用发送；生成中先停止，再切换。草稿、照片、单条引用和阅读位置保留，每条助手消息独立保存实际提供方。跨模型重试增加一次助手尝试，沿用原用户问题，旧结果和费用保留。

当前会话首读最近5条，每次再读5条，最多可访问最近50条；用户和助手各算一条。数据库更早消息和归档会话不自动删除，本轮没有旧会话列表、搜索或长期记忆检索。模型上下文默认取最近10组完整问答，再附当前任务和引用；不将原始思考、供应商工具信封或缓存状态跨模型传递。

缺少本次实际食量等必要信息时，由当前模型调用内部request_followup明确返回任务及问题。补充保留已知信息，引用绑定本人当前会话的真实消息；可以取消引用或换话题。任务及引用关联的私有照片在归属校验后读取，不靠最近使用的模型或问号猜测状态。

## 业务和授权

chat-tools通过进程内MCP适配器发现并按需启用现有21项业务工具。网页、外部AI和站内助手继续使用同一套查询、版本、营养、预览及人工确认规则；load_tools和request_followup只是站内控制工具，不新增公开业务工具或scope。历史修改先查询最新对象和版本，AI不得整条删除。正式保存继续在原审核网页完成。

三个模型分别关联独立ai_tokens及assistant_connections，首次发送创建已授权的站内连接，有效期30天。数据库只保存随机原文的摘要；站内执行使用已验证会话与本人连接引用，不向浏览器发放Bearer原文。撤销、到期、停用或账号访问失效阻止后续工具调用；恢复须在连接详情明确启用，创建新授权，不复活旧令牌或旧预览。原授权关联保留以追溯“千问／小米MiMo／智谱 · 站内助手”来源。

照片复用私有meal_images上传和读取，最多8张，单张20MiB，仅JPEG／PNG／WEBP。消息保存附件ID，不保存公开图片地址。模型调用由服务器读取本人附件并传输；补充或引用时只带相关原图。已有清理脚本仅处理未登记对象，聊天中已登记原图同样保留，不因尚未关联正式餐次而删除。

## 每日用量

三模型合计每日¥2，按每次模型请求开始时的北京时间归属日期，零点重置。输入区下方常驻“今日已用N%”，0、<1%及向下取整分别处理，超过100%如实显示。点开明细查看三家已核算费用、剩余可用、处理中预占、待结算和重置时间；金额两位小数显示，额度判断使用更高精度值。

服务器在账号锁内按未命中输入上界、图片保守估计及8192输出预占，再按usage结算；同一请求只结算一次。明确HTTP拒绝释放预占，网络中断、停止或没有可靠usage时保留待结算，不将未知伪装为免费。刷新、打开助手、切换、结算、恢复前台及日界同步用量，读取失败保留原值并提供重试，不闪现0%。预算与私有模型评测分开。

平台余额、限流、凭据、网络、超时与站内额度分别说明。未确认原因显示通用故障。单家失败后由用户选择其他模型；站内共享预算不足则暂停三家新请求，提醒、历史和手工记录保持可用。停止和刷新均不自动收费重发。

## 私有接口与限制

| 入口 | 用途 |
| --- | --- |
| GET /api/assistant-chat | 模型目录、当前选择、当前会话、5条分页、运行状态和用量 |
| POST /api/assistant-chat | send／retry／continue，返回真实SSE消息、工具摘要及用量 |
| POST /api/assistant-chat/control | select_model／new／stop／enable／revoke／clear_followup |

三个入口均验证有效会话、owner和服务器指定账号；写入检查同源，拒绝客户端指定账号、API地址、Key、价格及未知字段。引用和照片校验本人归属。消息、运行和账本保留账号及复合归属外键，请求ID绑定内容防重复。

每账号最多一个生成任务，20次用户发送／重试每分钟；每回合最多8次模型请求，每次8192输出tokens、120秒。上下文与图片保守输入估计超过200000时明确要求缩小内容或新对话，不静默裁剪当前任务。心跳超过150秒未更新的运行回收为停止，未知费用保留；刷新先读运行状态。

## 配置、关闭与回退

- FORMWARD_CHAT_ENABLED=1：总试用开关；未设置或其他值使用原助手。
- FORMWARD_CHAT_PILOT_USER_ID：唯一指定账号ID，仍须owner且未停用。
- QWEN_API_KEY、MIMO_API_KEY、GLM_API_KEY：分别保存在服务器root私有运行配置，不进入客户端或运行归档。
- QWEN_BASE_URL：已测试的千问北京标准接口；服务器严格校验HTTPS和官方域名。小米、智谱使用固定官方地址。
- FORMWARD_CHAT_QWEN_DISABLED／MIMO_DISABLED／GLM_DISABLED=1：单模型停用，保留历史与账本。

0037_youthful_wolfsbane为追加迁移，只新增五张聊天表。上线先备份、迁移并验证，再启用指定账号。关闭总开关或切回兼容应用不会删除聊天、授权或健康数据；旧应用能继续使用原健康表。不得恢复旧数据库快照回退本功能。
