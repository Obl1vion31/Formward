# 当前实现与验证

Formward 是 Next.js 16.3.7／React／TypeScript 模块化单体，Node.js 24.21.0、pnpm 9.15.9，Neon PostgreSQL／Drizzle 与 Better Auth。`src/app` 只放入口，业务集中在 `src/features`；网页、MCP 和 HTTP API 复用同一规则。代码定位见 [代码索引](code-study.md)，新会话先读 [交接](../handoff.md)。

## 产品状态

- `/dashboard` 保持今日概况：四项已记录摄入、餐次数、最新真实空腹体重／体脂及 7 日变化。全天消耗、盈余、运动与跨图联动暂不推进。
- `/dashboard/meals` 默认今天，营养素每天一根三色堆叠柱，蛋白质／碳水／脂肪连续堆叠，日期间留白；纵轴为克数合计，热量另按 kcal 显示。历史从图表或抽屉进入，切换历史不改变今天摘要。
- 食材库直接显示有效食材与简短规格，蛋白质、碳水化合物、脂肪、热量按真实基准对齐。依据与原图可展开，已删除食材可从次级入口恢复；六项 USDA 基础预设和采用流程保持。
- 饮食审核显示日期、餐次、食物数、分别／整餐／剩余合并、食用量和每项营养，区分引用食材库、新增入库与直接记录。可展开查看食物识别、数量、做法和营养的已保存依据、来源与不确定性；不补造旧记录推理。
- 审核保存后进入明确终态，刷新与加载最新状态仍显示已保存，不继续显示同一提交待确认或保留灰色确认按钮。其他独立未处理操作仍单独保留；过期操作退出待确认入口。
- 原图最多 8 张，每张 20 MiB，JPEG／PNG／WebP，不压缩，Private Blob 经账号鉴权回看。网页使用短期 OIDC 预签名直传，原图不进入函数请求体；MCP 下载临时文件、限制并发与重试，逐图返回错误码、阶段和 requestId，部分成功保留。
- `expectedImageCount` 保留缺图预期；缺图正常确认禁用，网页可补传，或由用户明确选择先保存文字并留下审计。事实核对仍必须通过，AI 不能自行忽略缺图或待补问题。
- `/dashboard/measurements` 保留六项摘要、双图、晨晚 Inspector 和四项录入；最近记录默认展开，独立于图表筛选显示今天及最近 10 日内待补录／待选择日期，完整历史每批 50 个日期。
- 仪表盘预留原生滚动条位置，共用弹窗按实际释放宽度补偿；切换饮食／食材库和开关 Inspector 不横移。窄屏表格局部横向浏览，页面不溢出。

## 数据与权限

schema 共 29 张业务／认证表，另有 Drizzle 迁移账本；0015 新增 nullable `meal_items.review_explanation`，将原图大小约束提高至 20 MiB。旧 migration 保持，0015 前后核对 29 张既有表的全部旧字段和值一致，旧依据为空，账本只新增一次；私有备份与核对报告在 `data/exports/`，权限 0600，被 Git 和部署忽略。

所有用户数据按 user_id 隔离，未知值 null，删除可恢复，历史食材营养／原图快照不随新规格变化。AI 写入先预览，网页登录确认；15 分钟有效期、revision、数据快照、幂等、凭据撤销和审计保护保持。身体 AI 支持批量提交、逐行修改／保存／取消和整批事务确认。

身体规则保持：体重与体脂独立；摘要只用真实空腹代表；晨间只接受空腹，晚间非空腹；凌晨 00:00–05:59 归前日晚间。普通保存不自动估算，normal morning-baseline-v3 只参考此前真实数据，historical-initialization-v1 冻结范围保持，补录只替代对应非空实测指标。来源建议移除不改变健康记录；网页来源可留空，AI 必须询问，不能把 GPT／录入渠道当设备来源。

## 上传问题的证据

实际 GPT 连接能够上传 68 字节虚构 PNG；同一连接上传 5,072,913 字节有效虚构 PNG 时，旧版返回 image_size／最大 4 MiB，说明原上限会拒绝常见大图。用户当时的原图和完整错误响应没有保留，不能断言该次只因文件大小失败。后续午餐传图的实际日志另定位 image_url：ChatGPT 使用 oaisdmntprnznorth.blob.core.windows.net，被旧域名列表拒绝，尚未下载；现按完整主机名兼容这一 Azure 账号，其他云账号／伪装地址仍拒绝，并逐跳验证重定向。新版同时增加分阶段诊断，日志仅记录工具名、参数形状、字节数、错误码和请求标识，不打印健康内容、文件名、下载地址、签名或凭据。

已核对用户提到的正式提交确实存在，同时有另一份独立待处理预览；没有自动删除、合并或代确认这些操作。
