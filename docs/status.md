本文件供后续协作快速恢复上下文。产品边界和阶段顺序以 `product.md`、`milestones.md` 为准；页面细节以 `interface.md` 为准。开始修改前仍需阅读根目录 `README.md`、`AGENTS.md` 和目标目录最近的 `README.md`。

## 已实现

- `code-study.md` 提供以 2026 年 10 月 3 日为基准的整体代码学习路线、文件职责、React / CSS 写法、动画与输入数据流、参数索引及修改验收示例。首页、配置、测试与维护脚本有中文注释，CSS 按功能分组展开。
- 运行框架为 Next.js 16.3.7 App Router、React 19.3、TypeScript 和 Tailwind CSS 4。首页没有 Motion、GSAP 或 WebGL 依赖。
- 首页是深石墨色的中央人物舞台，躯干后方有微弱暖金环境光与宽幅暖色层次，侧下方叠加极淡 petrol；文字和控件使用暖象牙白与哑金。第一屏显示左上角 Logo、居中人物和人物右侧腰部附近的 SCROLL 提示；底部没有箭头。提示为 9px 哑金文字、55% 透明度及 14×20px 鼠标轮廓，滚轮每 1.6s 轻移 3px。仅在图片就绪、INTRO、宽度超过 700px 且支持精细指针悬停时显示。停在 INTRO 时持续显示，鼠标移动或未触发播放的输入不会隐藏；离开 INTRO 后 120ms 淡出，每次倒放完整回到 INTRO 都重新显示。加载期间的操作不影响回到首屏后的显示。加载与失败文字独立保留。
- 人物外层支持极弱反向鼠标视差：INTRO 最大水平 6px、垂直 4px，朝鼠标方向倾转最多 0.6° / 0.3°。90ms 时间常数跟随，静止 180ms 后以 600ms smoothstep 回中，静止后停止 rAF。正放、倒放和最终过渡暂停联动，播放开始时在 100ms 内回中；LOGIN_READY 未填写时与 FINAL 输入框失焦时允许半幅联动，只接收新的鼠标移动。Logo、背景、Login 和提示不随人物移动；触屏、窄屏、reduced motion、窗口失焦及页面隐藏均归零，鼠标离开舞台缓慢回稳。
- 页面滚动区域约 155vh，视觉舞台以 100svh sticky 固定在视口中。桌面和窄屏表单均位于液态尾部前方，保留肩背与腰线；只显示 Email、Password、下划线和 `ENTER`。暖烟色衬底使用 10px 背景模糊，边缘渐隐，没有外框、标题、说明或实心按钮。ENTER 为 15px 哑金文字与短下划线，禁用时仍保持可辨认；表单按视口高度向尾部下方定位。
- `PRE_LOGIN_FRAMES` 包含 1.png 至 12.png，`FINAL_FRAME` 独立指向 13.png。一次明确下滚或手指上滑触发全程 425ms 的自动正放；一次明确上滚或手指下滑触发全程 425ms 的自动倒放。手势结束后动画继续播放；同方向惯性不重启，反方向超过阈值后从当前连续时间游标立即反向，剩余时长按剩余路程缩短。
- 状态为 INTRO、FORWARD_ANIMATING、LOGIN_READY、REVERSE_ANIMATING、FINAL_TRANSITION、FINAL。滚轮在 250ms 内同方向累计 44px，触控累计 40px 后选择目标 0 或 1；手势不提供播放进度。监听一直保留到最终过渡开始，滚动边界不会阻止方向触发。
- 正常 12 帧的 11 个段长为 38 / 36 / 34 / 32 / 30 / 30 / 32 / 38 / 45 / 52 / 58ms，启动快、中段最快、最后三段收住；`animationProgress` 为线性时间游标，没有整段缓动。每段仅在末尾 16ms 按 smoothstep 混合相邻帧，最多同时显示两帧；其他帧数使用等间隔兼容映射。人物容器使用 `isolation: isolate`，所有人物帧使用 `mix-blend-mode: plus-lighter`，先按互补权重合成为透明人物组，再叠到舞台；背景和 Login 不参与人物混合。该合成方式覆盖正放、倒放、reduced motion 和最终过渡，避免交叠中点的亮度凹陷。
- Login 的透明度与位移直接映射 `animationProgress`：前 60% 时间隐藏，接近背面时在最后 170ms 淡入并上移 16px，Frame 12 完整进入。表单本身不缩放或模糊，倒放同步隐藏，只有 LOGIN_READY 可提交。首次聚焦 Email 或 Password 后以 180ms 回中并锁定整个 LOGIN_READY；切换字段、失焦、点击空白或移动到 ENTER 都不解除。完整倒放回 INTRO 或进入 FINAL 后解除阶段锁定，FINAL 的输入焦点仍暂停联动。Email 和 Password 在倒放后仍保留于组件内存。
- 停在 12.png 且两项输入非空时，点击 Enter 确保人物外层归零，再单独进入 700ms 的 FINAL_TRANSITION，交叉过渡到 13.png，伴随轻微 scale / blur。若快速提交时回中未完成，立即归零再开始过渡，不增加等待时间。最终过渡开始后拒绝方向输入并移除手势监听；FINAL 保持 13，刷新才重置为 1。当前表单不发送请求、不保存凭据、不跳转到业务页面。
- 全部 13 张 PNG 通过静态导入获得尺寸及随内容变化的地址，并设置 Next.js `preload`。实际显示图片全部 `decode()` 完成后才播放，加载期间的最近方向会在就绪后自动执行；加载失败显示刷新提示。
- 每张图都有独立的桌面、移动端 scale / x / y 对齐配置。当前 1–4、6–9、13 为 1024×1536，第 5 帧为 793×1983，10–12 为 887×1774。1–12 以 Frame 1 为基准，人工测量头顶、颈根、腰部和实体尾滴，用离线等比缩放和平移优先稳定头顶与躯干；尾部保留自然变化，Frame 13 配置不变。原图、帧顺序不变，运行时不测量图片或拟合。测量数据与残差见 `frame-calibration.md`；素材的姿态、轮廓、清晰度与自身光晕差异仍限制连续性。
- SCROLL 提示仅用于视觉引导；键盘用户可通过聚焦时才显示的“进入登录”入口触发，完成后自动聚焦 Email 并锁定居中。页面方向键、PageUp / PageDown、Home / End 和 Space 支持双向播放，输入框、按钮及可编辑内容中的键盘操作不会改变动画。手机键盘改变视口不会自动倒放。
- reduced motion 保留双向交互：180ms 首尾 crossfade，Login 跟随全程进度仅淡入淡出；Enter 最终过渡为 240ms，省略人物位移、缩放、模糊效果。SCROLL 滚轮保持静止，离开首屏时提示立即隐藏，无鼠标联动。

## 验证与本地查看

- lint、typecheck、32 项单元测试、production build 和目录结构检查通过。
- Chromium 对 production 页面执行 25 项浏览器验收并通过：首屏常驻提示、人物视差、输入焦点锁定与快速 Enter、暂停恢复及能力降级，四种视口校准，三档时长，桌面 / 手机 / reduced motion / 最大视差像素检查，以及 A–E、双向中途反向、刷新、键盘输入保护、手机原生滑动、冷启动与加载失败。逐 rAF 采样确认完整帧顺序、最多两帧相邻交叠、前 60% 时间表单隐藏与最终过渡互补权重。
- 400 / 425 / 450ms 的同一时间线实现均在浏览器中顺序完整，端点记录允许实际 rAF 的采样间隔，当前运行环境中位间隔约 16.7ms。时间线与鼠标跟随均有模拟 60Hz / 120Hz 单元测试；尚未执行 120Hz 实机浏览器验收。
- 87 个交叠截图与两端加权参考的比较通过：桌面和手机全部 11 次初始换帧、12 → 13，reduced motion 的首尾与最终过渡，以及固定最大位移与倾转下的 1 → 2、5 → 6、11 → 12。人物区域最大平均 RGB 误差为桌面 0.659/255、手机 0.654/255、reduced motion 0.622/255、最大视差 0.660/255，均低于 2/255 上限。临时恢复 `normal` 合成的桌面中点对照误差为 39.597/255，并检测到负向亮度偏差，确认检查能识别变暗问题。
- 实际 CSS 变换后的校准检查覆盖 1440×900、390×844、320×568、844×390，每个视口的全部 12 帧均无裁切。桌面平均纵向加权 RMS 为 1.99px，头顶与躯干中心最大偏差为 2.93px、3.14px；四种视口的最大加权 RMS 为 3.73 / 2.81 / 2.02 / 1.41px。桌面 SCROLL 提示与首帧人物至少间隔 30px，触屏和窄屏不显示；键盘入口只在聚焦时出现，进入后自动聚焦 Email。
- 四种视口的首屏、空表单、填写状态及桌面 12 → 13 已视觉复核。表单无越界，肩背和腰线露出，烟色衬底边缘渐隐。表单样式保持既有对比度检查对应配置：标签、有效 ENTER 和输入值区域的最低文字对比度为 7.20:1，高于 4.5:1；该结果仅覆盖上述视口及当前素材，修改素材或对齐后重新复核。
- 文件摘要确认 13 张原图、Logo、人物叠放、逐帧校准和换帧时间线保持一致。实现集中于人物外层联动、首屏常驻提示和登录焦点协作，没有新增依赖或页面公开 API。
- 冷启动验收拦截全部图片请求，确认手势前已请求 13 张图且未解码时保持 Frame 1；解除拦截后无需再次滚动即可到 Frame 12。记录全部 13 张实际图片的 `decode()` 成功，之后正倒放没有新增图片请求或更换 `currentSrc`。加载期间已移动鼠标，倒放回首屏仍重新显示提示；图片失败状态在鼠标移动后仍保持可见且停在 Frame 1。
- 浏览器工具仅临时安装于 `/tmp`，项目依赖不变。复现入口见 `tests/README.md`。
- 本地入口为 `http://localhost:3000` 或 `http://127.0.0.1:3000`。若滚动条移动但人物和表单始终不变，应检查浏览器控制台及 Next.js 开发日志；其他端口转发域名需要加入 `next.config.ts` 的 `allowedDevOrigins` 并重启开发服务。
