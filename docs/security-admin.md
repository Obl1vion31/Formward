# 安全与全站管理

管理员通过账号菜单进入`/admin`，分为用户管理、用量分析、规则设置，安全与操作记录单独进入。用户管理下含账号和邀请；用户概况只放摘要和三个跳转，账号设置、个人额度及模型用量分别在对应页面完成。按用户当前要求，管理员动态码暂时关闭，使用账号密码进入；管理读取、邀请、档位及AI策略修改仍要求有效owner会话和5分钟内的再次验证密码。普通用户可自行启用或关闭动态码。外部AI令牌、OAuth和普通账号没有管理员接口。

临时模式由服务器私有环境变量`FORMWARD_OWNER_MFA_REQUIRED=0`控制，客户端不能设置；未设置时恢复默认强制绑定规则。暂停期间不提供管理员绑定入口，旧页面发起绑定或启用会被服务端拒绝。当前管理员尚未完成绑定，不修改账号、密码、已有会话或恢复码；已经启用MFA的账号仍必须通过原有动态码挑战。苹果“密码”扫码后出现`Invalid code`的根因尚未定位，临时模式不表示已修复该问题。重新启用管理员MFA须另行完成真实设备绑定验证。

## 统计与查看

用量分析默认最近30天，支持今天、7／30／90天及最长366天自定义范围，全部按北京时间归日。用户、模型供应商／实际模型、聊天／识图筛选同步作用于费用和用量。图表悬停立即显示日期、金额／请求、预占／未知及前三位中的前两位模型／用户，点击或键盘回车在图表下展开当日明细，保持外层日期范围；单个用户按实际模型拆分，全站可切换用户与模型，并继续点选筛选，每页50项。用户概况返回保留原列表的日期、筛选、页码和滚动位置。账号列表与用户用量列表均每页50位，账号搜索和状态只影响账号列表。

模型成本唯一来源是`assistant_usage_requests`。请求前预占、返回用量后按当时费率快照结算；中断且没有用量时保留未知费用占用，晚到的可验证用量可补结算。已结算、预占和未知分别呈现。数据库先以numeric聚合，再显示四位小数，小于0.0001元的非零金额明确标注；未知Token不补零。成本是应用计价结果，不是供应商最终账单，不包含外部GPT／豆包推理、主机或存储账单。

AI任务按用户发起的独立消息／识图任务去重，模型请求包含同一任务的多轮调用、失败和中断。输入、其中缓存命中、输出Token分列，缓存不重复加总。识图展示已使用、处理中和退回；业务调用按HTTP、MCP、豆包渠道从上线起累计，协议初始化和站内MCP复用不重复计数。费用图与调用／Token图使用各自单位。最早账本之前的区间明确显示未覆盖，停用用户保留历史。

记录统计只包含当前有效餐次、每日晨晚最新实测身体记录、消耗日、运动及已完成训练。食材、训练模板／计划另列；图片只显示登记数量和字节容量。期间新增按成功保存时间计算，属于当前有效记录中的新增，不等于包含已删除记录的历史操作量。后台服务端聚合，不读取或返回餐食正文、健康数值、照片、聊天内容、提示词及恢复码。

## AI策略与预算

网页会话将刚经数据库复核的账号及会员规则交给业务入口，聊天、识图和模型控制共用同一身份；不再丢失membershipPolicy并误报“会员配置尚未就绪”。每次请求读取最新档位及个人覆盖，仍执行会话撤销、归属、MFA、权限、限流和预算检查。

管理员在“规则设置”的会员档位中新增、改名、调整每日AI金额／识图次数及聊天／识图权限，选择新用户默认档位，或停用、删除档位。删除有成员或当前默认档位时必须指定已启用的普通接替档位；现有用户原子转移，健康记录及历史费用保留。最多50个未删除档位，名称不重复；管理员专用档位可改额度，但不能删除、设默认或分配给普通用户。角色独立于档位，改名或提高额度不能得到owner权限。

迁移初值保留Free（每日4次识图、无单独金额上限、聊天关闭）、内测版（每日1元）、Plus及指定管理员（每日2元）；Pro初始停用，可由管理员改名启用。聊天与识图共用档位每日金额。修改统一影响对应用户，下一次供应商调用前读取数据库策略；个人金额／次数覆盖和暂停保持，从用户概况进入“个人额度”可恢复默认。新账号及邀请激活按当前默认档位分配，旧用户不随默认档位切换而重新分配。

个人AI策略独立于会员档位，支持暂停／恢复、每日金额0–10元、每日识图0–100次或继承档位。0明确禁用对应额度，NULL表示继承；Free默认为4次识图，没有单独金额上限，档位默认值由后台配置，管理员也受其专用档位及个人限制约束。提高额度不新增聊天权限。

全站每天10元，所有模型、免费识图和后台worker共用。每次供应商请求先锁北京时间预算日，再锁账号，从原账本计算并原子预占；上线当天已有费用也计入。预占与未知费用持续占用，80%提示、100%阻止新请求。此限制不能保护泄漏后绕开网站使用的上游Key。

策略修改包含版本、幂等编号、原因及修改前后值。同一请求重试不重复执行，并发旧版本返回冲突。暂停会阻止新模型请求、停止未开始任务，执行中请求由worker尽力取消；已发请求费用未知时继续占用。恢复不自动重放任务，不影响手工记录，不代替外部OAuth撤销。

## 身份与资源保护

新设、重设和修改密码为15–128字符，既有短密码仍能登录。密码重设不移除MFA。TOTP秘密与一次性恢复码由Better Auth加密保存，恢复码原文仅生成时显示；使用恢复码登录后必须重绑。停用、改密和撤销继续通过实时访问版本阻止延迟旧会话。新手动Token默认只读、7天，可选择1／7／30天及身体、饮食、消耗、训练范围；旧授权不自动扩权。创建要求近期验证，普通用户可只再次验证密码。

Nginx提供按可信来源的粗限流；PostgreSQL原子计数提供跨实例、跨区域和多Token共用的账号额度：登录／验证每账号及来源5次／分钟，业务读取120次／分钟、提交30次／分钟、图片凭据20次／分钟。上传凭据预占容量，同时最多4张，每日新增最多200MiB；凭据过期只释放并发槽，无法证明尚未上传的容量仍占用当天额度，避免不登记图片绕过限制，有效待确认根任务最多100个，统一预览的子任务不重复占位。HTTP限流响应为429及Retry-After；已经开始的流保留既有错误事件，Server Action返回结构化错误及原输入。

HTML使用逐请求nonce CSP，禁止嵌入，HTTPS启用HSTS。CSP可通过`FORMWARD_CSP_REPORT_ONLY=1`进行兼容观察，正常验收后强制。安全事件中的来源地址只保留摘要，无凭据及正文，保留30天；原账号、业务与管理审计继续保留。最近10分钟同账号／来源至少3次验证失败会在后台提醒，不发送外部消息。
