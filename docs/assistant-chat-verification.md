# 站内聊天验收

## 验收范围

本轮统一检查MCP2.0.1／18项、HTTP1.15.1兼容、库项改量与食材说明、跨业务字段保留、结构化来源、聊天确认、网络选路、账号档位与图表交接。prompt仍为千问original／小米compact／智谱original，上下文10组；共用修订2026-11-15-preserve-verbatim-v1。

自动验收使用隔离账号、真实业务函数和回复回放；正式健康事实保持与隔离库确认分别核对。收费模型仅千问与小米，共享新增¥5上限，独立旧评测和生产每日账本；每次预占，usage结算，未知费用保留，原答与失败均保全，不使用额外裁判模型。

## 验收门槛

- API正常、重复、失败不变与跨账号，待审修改及正式记录修改预览；字段允许变化在执行前规定，检查关联、精度、null、0和无关对象版本。
- 来源从历史候选或自由原文，经真实任务补充到预览、隔离人工保存及审计快照一致；候选不是白名单。
- 四类确认卡与混合预览的正常、取消、保存失败重试、过期、撤销和版本冲突；正式保存复用原服务，无客户端直接写库。
- Free计次及聊天拒绝、内测／Plus预算、管理版本及即时生效、并发与跨日、授权到期；改档不退出登录或清草稿。
- Chromium／WebKit覆盖320／390／430、矮屏、横屏及1100／1440、深浅主题、200%文字、减少动态效果；图表往返、中断、首次与缓存、失败重试保留连续过程。固定槽位非主动偏差≤1px。
- 同一原图在聊天／饮食和两通道实传，校验进度、登记及逐字节读回；取消、停滞、超时和换通道独立检查。真实iPhone与WebKit分别记录，未取得证据的专项不记通过。
