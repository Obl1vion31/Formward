# 手机交互研究与实施状态

已认可的交互方向来自本轮formward-mobile-focus原型：记录入口同组、状态卡、可见共轴双层趋势、玻璃导航、有限弹性和底部详情。原型为虚构数据演示，样式认可不代表正式业务验收。

本地实现位于codex/mobile-workspace，尚未发布。真实Next.js页面已采用暖雾材质、B横向数据卡、摄入／晨重共享图形转场、专页顶部记录动作；持久导航、集中设置、小助手、手机Inspector及完整业务继续复用。桌面同步颜色和控件，保留左侧导航、完整图表与统计。

迁移对照：

| 模块 | 本批接入或保留 | 后续版式整理 |
| --- | --- | --- |
| 总览 | 同色完整记录动作、三卡横带及真实七日小图、共轴关系图、区间及日期详情；统计／覆盖／缺口仅电脑保留 | 根据用户实际页面验收继续微调 |
| 饮食 | 手机共用摄入图形、同范围进入、顶部记录；P/C/F口径、全部餐次／食物／附件／食材库、编辑与记全保留 | 原表单继续按真实任务验收 |
| 消耗 | 归入首页卡片带、专页顶部记录；全天总数／分项、运动累计／手填、包含关系、编辑／历史／图表保留 | 不将原能力简化成单一补全输入 |
| 身体 | 晨重同范围共享图形、顶部记录；晨晚／双指标双图／估计／实测／来源时区／补录／逐项操作保留 | 卡片进入时先匹配晨间实测，原开关可展开其余系列 |
| 助手 | 待核对、补录建议、真实快捷入口、教程、AI接入、导出和偏好 | 与各批表单的占用状态持续回归 |

主题设置只在账号菜单的设置入口提供，保留已有本设备偏好，跟随系统为真实监听。演示的播放按钮与弹性强度不进入产品。具体规范只维护在design-reference.md，验收结果记录到maintenance-verification.md。

## 可以观看和操作的案例

| 案例与入口 | 建议观察 | 对 Formward 的启发及边界 |
| --- | --- | --- |
| [Apple：Meet Liquid Glass，从 1:29 开始](https://developer.apple.com/videos/play/wwdc2025/219/?time=89) | Dynamics 章节到 6:00：材质响应、形变与元素之间的连续变化 | 底部导航的选中层可以跟手伸缩、带速度地回位；文字与图标仍须稳定可读。网页可以实现相近的交互原则，不能把 CSS 毛玻璃称为系统原生 Liquid Glass。 |
| [Apple：Get to know the new design system，从 6:16 开始](https://developer.apple.com/videos/play/wwdc2025/356/?time=376) | Structure 章节中的内容、控件与 sheet 层级；面板升高后更适合专注阅读 | 短详情从半高进入，长内容向上展开；内容面保持足够不透明度。打开后仍能理解从哪张卡片进入，关闭回到原位。 |
| [Apple：Liquid Glass showcase — Tide Guide](https://developer.apple.com/videos/play/meet-with-apple/257/) | 约 10:52 的真实产品展示，观察数据内容、自定义组件和系统层如何共存；不指定未经核对的片内时间点 | 这是已落地的潮汐与海洋天气产品案例，证明数据型应用可以有鲜明视觉与连续交互。借鉴其分层方法，不照搬主题、资产或布局。 |
| [Vaul 可操作演示](https://vaul.emilkowal.ski/)与[多档位演示](https://vaul.emilkowal.ski/snap-points) | 点击 Open Drawer，再拖动面板、切换高度、滚动内部内容 | 直接体验网页底部面板的可行性，区分“内容在滚动”和“整个面板被拖动”。这是交互参考，不是默认依赖选型。 |

Vaul 的[官方仓库](https://github.com/emilkowalski/vaul)已明确标记 unmaintained；采用前必须评估维护、浏览器兼容及无障碍问题。本轮不安装它。[作者的实现说明](https://emilkowal.ski/ui/building-a-drawer-component)具体讨论了拖动速度、滚动交接、输入键盘及样式重算开销，可用于审查我们自己的实现。

[Apple Fitness 的摘要说明](https://support.apple.com/en-ie/guide/iphone/iph4c34a8a95/ios)可辅助研究健康信息的分组与层级。它不意味着 Formward 应照搬已有训练能力。用户提到的原始案例身份尚未确认；Norg 也未核实为该案例，不据此归因、展示冒名作品或声称某个 skill 制作了这些产品。


## 迁移约定

现有业务的查询、计算、保存、权限和草稿规则继续复用。每批通过实际页面验证后再细化下一个模块，所有未测与待完成项写入维护验收。手机优先，桌面共用外壳与主题但保留其宽屏记录与分析任务。
