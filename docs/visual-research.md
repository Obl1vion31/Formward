# 总览与消耗页视觉调研

调研日期：2026-10-22。状态：“趋势＋单日联动”和“双层关联图”已实现并发布；当前行为以[界面说明](interface.md)和[热量消耗规则](energy.md)为准。

## 建议方向

总览重点是让摄入、消耗、差值与次晨变化之间的对应关系可以直接阅读。采用双层关联图：上层蓝线摄入、红线消耗，线间柔杏金#D8B38A为盈余、雾蓝灰#92B2C2为缺口，填色均为28%；下层暖白线显示相邻次晨变化，两层共享日期及贯穿的选中线。

选中一天后，顶部用“摄入−消耗＝差值”及“两日晨重→次晨变化”两组读数表达关系。桌面并排，手机先突出收支差值与计算式，晨重变化贴近下层图。不增加预测、评分、预算或训练功能，也不改变历史数据和热量计算。消耗页使用单份有效日读数，低频操作按需展开，主页面使用手机底部导航。

## 当前界面的具体问题

已核对用户提供的当前30D截图、仓库样式和虚构账号验收截图。用户截图能看到完整的摄入、消耗、盈余与次晨变化，不能把虚构测试图的稀疏数据误当成用户缺失。

| 观察 | 影响 | 建议 |
| --- | --- | --- |
| 三组数据仅在日期位置上对齐 | 仍需来回看图、自己理解差值和晨重的对应关系 | 将摄入、消耗和差值合并表达，再以同一选中线对照次晨变化 |
| 页面标题18px，图组标题15px，行标题14px；选中读数22px | 主要数字和辅助信息主次不强 | 主要读数28–32px，单位12px，图名13–14px；字号与间距一起调整 |
| 日期独占读数区一列，图形另有标题、图例、单位和分隔线 | 横向空间利用不均，三行像独立报表 | 日期贴近读数组，共用一个图组；只保留必要分隔 |
| 每行独立选中背景仅3.5%不透明度 | 看上下三行时，所选日期不容易追踪 | 共日期淡选中带约6–8%，细竖线对齐，选中点稍放大；其他数据保持可读 |
| 当前三行含标题、绘图区上沿和分隔留白 | 手机上主图前后内容过长 | 两层图紧邻，能量主图较大，次晨变化为较薄对照区 |
| 下方三个入口各有大数字和大内边距，手机逐卡堆叠 | 次要入口比主读数更抢眼，也延长页面 | 桌面紧凑三列摘要；手机使用四栏底部导航，移除重复入口卡 |
| 消耗图超过7天时只显示选中日期 | 无法快速判断其他柱对应哪段时间 | 桌面约5–7个日期标签，手机3–4个；选中日期另作明确标记 |
| 每日列表的编辑、添加活动、删除都使用金色 | 主次操作难区分 | 编辑保留主动作，次动作暖灰；删除移入按需操作区 |

以上是调研时的观察与原则；总览按双层方案实现，手机布局、消耗日期标签与次级操作也已落到实现。代码定位在`src/features/dashboard/overview.module.css`、`overview-trend.tsx`及`src/features/activities/energy-view.tsx`、`energy.module.css`。

## 官方资料与可借鉴原则

### Apple：数据先于网格与说明

Apple建议建立一致的层级，让数据比坐标、网格和说明更突出；使用熟悉的刻度序列，在可交互查值的图中适当减少网格。其图表课程也强调：精确读数、趋势和展开详情应保持上下文连续，逐步展示复杂度。Formward可以采用大读数、弱网格及连贯的日期选择，不必复制Apple的页面构图。[Charts](https://developer.apple.com/design/human-interface-guidelines/charts)、[Design app experiences with charts](https://developer.apple.com/videos/play/wwdc2022/110342/)。

### Oura：用字号区分当前值与区间参考

Oura官方趋势说明明确区分较大的当前指标和较小的区间参考值。对Formward的借鉴是让选中日期的精确读数清晰可见；不因此增加区间均值、健康评分或未经实现的结论。[Using Trends](https://support.ouraring.com/hc/en-us/articles/360055983614-Using-Trends)。

### Carbon：简化结构，保留真实数据

Carbon要求比较柱图从零开始，缺数据的时段不插值补线，时间轴保持一致增量；单一类别可以直接标名，避免不必要图例。配色建议少量明确彩色搭配丰富中性色，避免滥用多重渐变。新方案采用线图，纵轴按完整区间取整并留余量，减少无用空白；刻度与数值明确可读，选日不改变范围。次晨变化保留缺测断线，不为外观平滑身体变化。[坐标与标签](https://www.carbondesignsystem.com/building-blocks/data-visualization/axes-and-labels)、[图例](https://www.carbondesignsystem.com/building-blocks/data-visualization/legends)、[配色](https://www.carbondesignsystem.com/building-blocks/data-visualization/color-palettes)。

双层图、线间差值色带、贯穿日期选择及两组单日读数，是针对Formward的设计推导，不是上述产品必须遵循的统一规则。

## 图表专项边界

通用信息层级与视觉验收统一使用[设计文档](design-reference.md)，以下仅补充图表数据与几何约束。

- 两图共日期、独立单位和整齐刻度，所有数据完整显示；选中日期变化不能改变刻度。
- 两条能量线交叉时先计算交点并分区填色；未知值不能当0，不跨缺日连接。采用直线段，不平滑曲线。
- 摄入、消耗、盈余和晨重配对仍由现有服务端业务计算；不靠客户端补零、平滑或新增推测改善外观。
- 保留估计标记、缺测与未知，不能用颜色或动画掩盖不完整信息。
- 键盘、触屏、日期详情、全部区间、减少动态效果及320px宽度保持可用；选中列高亮不能让其他记录难以辨认。
- 消耗编辑器和列表可统一主次操作及数字格式，不改变来源、版本、审核和事务保存。
- 填色仅在相邻有效段内淡出：边缘宽度不超过段长25%及8px，alpha遮罩只影响填色，不隐藏实线、真实点或命中区域。缺测段下方使用短标记，不能填入虚构记录。
- 两图使用同一SVG和横坐标；视觉验收检查1440／1100／390／320px实际页面，而不只检查参考稿。
