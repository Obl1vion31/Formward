# 训练记录

主导航“训练”打开 /dashboard/training，页内“消耗”保留 /dashboard/energy 的原有图表、来源、补录、编辑与计算。训练首页按今日训练、月历、训练模板组织，今日训练下面直接是月历，不放消耗统计。

## 训练流程

可以自由开始，也可以采用今天的计划或训练模板；每账号同时只有一场进行中训练。添加动作后填写每组重量、次数，完成后勾选。重量可未知或明确为0，完成组必须填写1–999的整数次数；数值不用于估算热量。新动作和新组的实测次数均为空，模板的目标次数不冒充完成事实。

进度在停止输入后自动保存。界面区分等待保存、保存中、已保存和失败；失败保留输入，可重试，关闭前尝试保存。未完成保存时离开页面有保护；载入云端进度需要确认替换当前输入。浏览器不持久保存健康草稿。已保存的训练支持刷新、重新登录后继续；两个页面并发修改时以版本检查阻止覆盖。

暂停与继续由服务端记录时间。结束前确认，仅保留已勾选的组，保存后回看；空训练可以单独确认放弃，不清除模板、计划或其他记录。开始时的当地日期、时区和原始开始时刻保持，跨午夜继续训练不会被拆成两场。

## 月历与模板

月历以完成训练的有效时长显示三档深浅：少于45分钟、45–59分钟、60分钟及以上；实心点代表完成，空心点和虚线边界代表计划。计划不计入完成次数或时长，点击日期可查看计划和已完成记录。

模板保存动作、组数和目标次数，不保存本次实测重量；完成记录可存为模板。排期保存模板内容快照，电脑可拖动模板到可见日期，手机与键盘使用“排期／安排训练”选择日期。同一模板同一天不重复安排，取消安排只改变排期状态。完成对应训练才将计划标记为完成；自由训练不会自动完成同日其他计划。

## 数据与接口

0033_training_sessions 新增 training_sessions、training_templates、training_plans 和 training_events，不改动旧表或旧健康数据。各表均关联 user_id；模板和计划、计划和会话使用包含账号的组合外键。

会话保存当地日期、时区、动作和组次快照、状态、累计有效秒数、开始／恢复／结束时间、版本、来源系统、kg单位、确认状态和创建者。事件在同一事务保存来源、操作者、时间及前后快照，并以账号／请求ID绑定摘要，防止重试重复写入。

网页通过受保护的 Server Actions 调用 training feature；身份从当前会话取得，事务内再次锁定并验证账号及会话。首次开始、保存、暂停、继续、结束、放弃、模板保存、排期与取消均在 feature 中校验。没有新增公开 HTTP、MCP 工具或 AI 权限。

训练独立于全天消耗，本轮不创建活动或增加热量。以后关联设备运动时，需要明确采用来源与包含关系，避免重复累计。
