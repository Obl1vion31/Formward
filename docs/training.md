# 训练记录

主导航“训练”打开 /dashboard/training，顺序为紧凑训练入口、默认收起的模板区和月历。训练／消耗在电脑原页面标题行、手机64px顶栏切换，正文不再另设一行。消耗保留原图表、设备同步、来源、补录、编辑与计算。训练计划和完成事实分开，不自动估算或累加热量。

## 开始、记录与结束

入口按进行中、今日待练计划、今日最近完成、自由训练选择，只展示具体名称及日期／状态；同日多场取实际结束时间最近的一场，其余在日历查看，不重复展示完成次数或泛化提示。无今日计划时只显示“开始训练”；有计划时显示“按计划训练”和“自由训练”，点击计划名称可看动作。已有进行中或暂停训练时显示“继续训练”，每账号同时只有一场。跨午夜不拆分已开始的训练，其原始当地日期、时区和开始时刻保持。

动作库和自定义动作均可多选加入、调整顺序，每次最多50个动作、每项最多100组。记录方式按动作区分：

| 方式 | 实际记录 | 完成条件 |
| --- | --- | --- |
| 次数 | 次数、可选重量kg | 1–999整数次数，重量0–9999或未知 |
| 持续时间 | 秒 | 1–86400整数秒 |
| 有氧 | 秒、距离米 | 至少一项正值；距离可明确为0，未知仍为空 |

模板目标独立保存，开始后实际值保持未知和未完成；不把目标或计划当作已经做完。动作时长与整场有效计时分别保存。停止输入后自动保存，失败保留输入，可重试；关闭前先保存，载入云端进度需确认替换当前输入。浏览器不持久保存健康草稿。

暂停／继续由服务端计时。结束需确认，仅保存已勾选的组并回看；空训练可单独确认放弃，不清除模板或其他计划。已保存训练支持刷新及重新登录后继续，版本检查阻止其他页面覆盖。

## 动作库与模板

统一目录150项：力量／徒手／核心100、有氧20、拉伸与活动度30。每项有稳定catalogId、中文名称、英文与别名、主要部位、器械、动作模式、记录方式和参考链接。模板及训练共用搜索、类型／部位／器械筛选和多选；没有匹配项可添加自定义动作。首版采用文字列表。

目录名称和分类自行整理，部位／器械维度参考[ACE动作库](https://www.acefitness.org/resources/everyone/exercise-library/)，抗阻动作模式参考[NSCA基础动作模式资料](https://www.nsca.com/education/articles/ptq/teaching-resistance-training-movement-patterns/)。不复制说明或媒体，不把通用目录当作个性化训练处方。新增条目须维持稳定标识和记录单位，修改分类不重写已保存快照。

模板保存动作顺序、组数和可选次数／重量／时长／距离目标；完成记录可另存为模板。排期保存模板内容快照，模板后续修改不改旧计划或完成记录。模板区展开后按名称原位查看动作目标，提供开始和排期。电脑与手机均从44px手柄拖到日历，正文保持滚动；名称浮层、落点高亮和边缘自动滚动跟随同一触点，取消或日期外释放不保存。键盘及不使用手势的用户继续通过排期选择日期。同一模板同一天不重复安排；改期须提供版本并避开进行中训练，取消只改变排期状态。

月度次数和时长位于日历底部，为0时不展示；保存反馈短暂显示且不推动正文，错误贴近对应操作。月历固定六周网格，月份变化和加载接管共用结构。实心点表示完成，空心点／虚线表示计划。完成时长少于45分钟、45–59分钟、60分钟及以上对应三档颜色；计划不计入完成次数或时长，只有结束对应训练才完成该计划。

## 删除已完成训练

日历已完成记录行的更多操作提供“删除训练”，经本人明确确认后永久删除正式会话。删除使用网页专用delete_completed、id／version／operationId，复用账号行锁、归属、请求幂等与完整前后审计。最后一场关联完成记录删除后，计划恢复planned并递增版本；仍有其他完成记录时保持completed。模板、其他训练与消耗事实保留，查询及统计即时反映结果。审计失败会回滚会话删除及计划恢复，MCP不提供删除。

## GPT／MCP 排计划

训练使用独立training:read和training:write权限。现有连接需刷新工具定义并重新同意训练授权；不会自动扩展旧令牌。

| 工具 | 能力 |
| --- | --- |
| search_exercises | 按中文／英文／别名、类型、部位或器械查统一动作库 |
| query_training | 查询本人模板、日历计划及实际训练，返回id/version；默认过去30天至未来90天，可指定范围与时区 |
| submit_training_operation | 生成模板及多日排期预览，可新增或修改，不直接保存 |
| get_training_operation | 查询预览与确认状态 |

每项有唯一key；新增模板使用save_training_template，排期使用schedule_training，同批新模板通过templateRef引用key。已有项目修改须携带id/version，日期须为明确的YYYY-MM-DD。多个类别也可用submit_record_operation统一提交。

例如GPT先查询动作，再提交“杠铃卧推3组、每组10次；平板支撑2组、每组30秒；跑步机20分钟／3000米；腘绳肌拉伸2组、每组30秒”的模板，并将模板安排到两个明确日期。输入中的时长换算成秒，距离换算成米；目标不代表实际完成。

工具返回confirmationUrl后，用户在网页查看模板动作、目标和日期，可应用修改或取消待保存项，再统一确认。pending仅为预览，confirmed才已保存到同一训练日历。预览24小时有效，重试使用原operationId及内容；变更提交授权、跨账号引用、撤销授权、过期和版本冲突均阻止保存。取消新模板会阻止依赖该模板的排期，不能通过工具代替用户确认、删除历史或伪造完成训练。

## 存储与维护

training_sessions、training_templates、training_plans和training_events均关联user_id，组合外键保护模板／计划／会话归属。网页与MCP确认调用相同feature事务，前后快照、来源、操作者、时间和请求摘要进入审计。训练记录的weightKg、durationSeconds、distanceMeters分别明确单位；原表的source_unit=kg保留为重量单位。

组次、目标及动作快照使用现有JSONB，旧记录缺少recordingType时按次数解释。本轮不新增表或修改已发布migration。训练AI预览复用record_operations，真实确认才写训练表，模板和计划支持版本更新。加载态与动效的必验标准维护在[设计与视觉验收](design-reference.md)。

## 动作素材与视频评估选型

当前150项目录继续采用文字，本节为后续选型，不代表已购买素材、接入摄像头或部署评估模型。演示素材使用许可与机器学习训练授权分别核对。

| 方向 | 选型建议与来源 |
| --- | --- |
| 授权动画／插画 | 优先用少量[GymVisual](https://gymvisual.com/content/9-license)购买素材匹配现有catalogId，验证GIF／视频在训练详情的效果；购买版许可列明App和网页用途，不直接复用网页缩略图。 |
| 真人演示 | [MuscleWiki](https://api.musclewiki.com/documentation)提供多角度视频；[API条款](https://api.musclewiki.com/api-terms)限制永久存储、要求保留品牌，训练模型需另获书面许可。 |
| 自有3D | 先做统一人物与骨骼，复用少量动作动画并渲染循环视频，教练核对姿态、器械接触和节奏后再扩充。 |
| 现成纠错 | [KinesteX Camera Component](https://www.kinestex.com/docs/integration/camera-component)有计次和动作反馈接口，先用目标场景实拍验证，不把供应商宣传当成本产品准确率。 |
| 自研基础 | [MediaPipe Pose Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker)输出33个人体关键点；先限定动作和机位，结合教练规则评估，再按真实误差决定微调。 |

[FitAQA评测](https://arxiv.org/html/2608.08736v2)显示通用视频大模型对精细姿态证据与错误时间定位仍有限制；优先验证SDK或关键点加规则基线，保留无法判断的情况，不先承诺覆盖150项动作的纠错效果。

[Fitness-AQA](https://github.com/ParitoshParmar/Fitness-AQA)含深蹲、肩上推举、杠铃划船，需要申请且限非商业用途。[MyoMechanix作者项目](https://github.com/HaoYin116/MyoMechanix)整合多视角、3D姿态及专家知识，研究数据需申请，商用另获许可，当前模型发布状态仍需核查。[Fit3D](https://fit3d.imar.ro/fit3d)有多视角、三维姿态及重复次数标注，适合姿态／计次研究；本轮未核实下载授权。商业训练采用另获训练授权或自采并由教练标注的视频，按参与者拆分评估，分别检查误报、漏报和机位遮挡。
