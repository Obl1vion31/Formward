# 身体指标记录

## 可记录内容

目前支持体重与体脂率实测。体重固定开启；账号可关闭体脂，关闭时简化展示、录入和缺测提醒，历史体脂值保留。编辑旧记录时省略隐藏字段，不清空原值。骨骼肌量、骨骼肌率仅作为未开放目录显示，不提供可操作开关。

手机先选晨晚，体重和体脂并排、来源随后，时区按需展开；电脑晨晚两时段并排。已有卡片、单图切换、真实小图及双向转场保持。用户可以只填体重或只填体脂，至少一个主要指标有值；体重必须大于0，体脂范围0–100，未知为null。

## 实测与缺测

系统不估算体重或体脂，不按热量、前后记录或晨晚差补值。缺测保持空白，图形在缺日断开，不跨缺日连接或平滑真实波动。

已退役内容包括单项估算、历史初始化补全、冻结／重建、估计开关与曲线、规则、依据和标记。0035 migration仅归档明确record_kind=estimated的有效行；原始导入、实测和审计保留。归档载体不能恢复为有效记录，不进入网页、查询、统计或导出。

## 晨晚、时间与来源

晨间录入必须明确空腹，晚间固定非空腹；旧晨间非空腹／条件未知记录保持只读。记录日用于业务日历；凌晨测量按既有归属规则放到前一天晚间，实际发生时间不改写。原始当地钟点、准确UTC时间、时区、偏移和精度独立保存。未知准确时间不以保存时间或占位钟点代替。

新录入默认设备当前时区，允许固定GMT-12至GMT+14整数小时；兼容旧非整点偏移和IANA名称。历史修改省略时区保留，明确null清空，修改时区保留当地钟点，只有准确时间重算UTC。未来身体日期禁止写入，按录入时区判断，无上下文以Asia/Shanghai校验；摘要排除未来记录。

来源保存用户提供的真实设备／应用名称快照，也可明确留空。网页新空时段只有目标之前最近3个采用中的实测槽来源连续一致时沿用，晨晚合并，同日同槽只计一次，空来源中断，不覆盖手工输入。成功保存才更新来源建议；移除建议只隐藏建议，不改历史。AI不能自行猜来源，须获得真实名称或明确留空确认。

## 写入、编辑与保护

同日同一时段采用最后保存的实测；新录入和AI确认覆盖当前采用行，遗漏字段保留，显式null清空。原始输入不覆盖。旧候选在正常覆盖或删除时归档，不复活旧值。

每项已保存数值旁的小叉经过确认只删除该指标；另一指标和另一时段保留。最后一个指标删除后退出有效记录。保留本人确认、账号归属、版本冲突、重复请求保护、事务审计、失败回滚和草稿保护。AI不提供整条删除或恢复能力。

只改来源或时区不改变原数值精度、录入渠道及实际测量事实。用户正在编辑时，迟到响应或外部偏好变化不得覆盖草稿。关闭有修改的编辑任务仍需按现有规则保护输入。

## 查看、趋势与统计

查看面板只展示日期、事实、来源、状态与历史，不挂载写入表单。列表提供明确查看和编辑／录入／补录入口，点击范围至少44px；普通日期链接默认查看，intent=edit明确编辑，旧entry录入链接兼容。

体重和体脂共用所选日期及趋势范围。只有体重时显示晨重、相邻日变化、7日均值与7日变化；开启体脂时显示晨重、晨间体脂与两项7日均值。只有相邻两天晨间空腹实测齐全才计算日差；7日窗口包含所选日及前6日，均值排除缺测，变化采用窗口内首末有效实测并注明日期。

总览能量与次晨变化继续保留：D日对应D+1晨重减D晨重，不跨缺日配对，不把缺测补零。身体完整图只保留直接可达的晚间数据开关。选日只改变读数及选中状态，不移动图形。

最近记录与查看全部的固定文字从首帧显示，未知日期与数值局部等待。加载和正式内容共用结构，稳定锚点偏差不超过1 CSS px，骨架交接不重播入场。具体视觉与录像验收见[设计规范](design-reference.md)。

## 导入、维护和接口

三列TSV为测量时间、体重、体脂率，兼容旧四列BMI输入但BMI不进入当前模型；原文件不改。导入按真实来源时间与原始值去重，重复或已删除记录不复活，格式和归属错误整批回滚。维护工具仅处理实测、来源和原有审计，不提供补全或重建估计。

网页、HTTP与MCP调用同一feature规则。身体接口支持save_record、batch和兼容save_day；写入先生成预览，再由用户登录网页确认，15分钟预览、版本校验和幂等保持。未知值为null，不要求AI推测身体数值。

旧estimate_cell请求返回410 feature_removed。含该操作的旧混合任务整批停止，原请求、草稿及审计保留，不静默执行其余项。旧实测预览可刷新继续，但不再展示估计替换快照或计算说明。现有OAuth权限、账号和连接保持，无须重置。

导出只含有效实测、来源与时间；不导出身体估计、计算依据或标记列。饮食与热量估算属于其他业务，保持现有规则。
